# 03db.03s3.04presigned-urls Presigned Uniform Resource Locators (URLs)

## 1. Mechanism

A presigned URL carries a Signature Version 4 (SigV4) signature made with the signer's credentials.

- Holder acts as the signer for that one request
  - Bound: method, key, signed headers
- Signed locally; no network call
- Server never handles the bytes on direct upload

→ Server returns a presigned PUT URL (or POST policy) with short expiry  
→ Browser uploads straight to S3  
→ Event notification → scan / validate the content afterwards  
⇒ The URL holder controls the content, so validation is ours

### 1.1 Expiry

We set the expiry, but the signing credential caps it.

- Identity and Access Management (IAM) user key: up to 7 days
- Role / Security Token Service (STS) session: ends when the session token ends (hours at most)
  - URL dies early, before its stated expiry
  - Fix: sign with longer-lived credentials, or issue URLs just-in-time
- Permissions are the signer's at use time
  - If the signer loses access, the URL fails
- Presign with the shortest useful expiry ⇒ smaller leak window

### 1.2 Presigner Bean

**Java**

```java
// config/_03db_03s3/S3Config.java
// Presigner signs locally with the caller's credentials: no network call, URL dies with the credentials.
@Bean(destroyMethod = "close")
public S3Presigner s3Presigner(Region region, AwsCredentialsProvider credentials) {
    return S3Presigner.builder().region(region).credentialsProvider(credentials).build();
}
```

## 2. Presigned GET

Anyone holding the URL can read until it expires, without Amazon Web Services (AWS) credentials.

**Java**

```java
// infra/_03db_03s3/S3LakeStore.java
@Override
public String presignGet(String key, Duration expiry) {
    return presigner.presignGetObject(GetObjectPresignRequest.builder()
            .signatureDuration(expiry)
            .getObjectRequest(GetObjectRequest.builder().bucket(bucket).key(key).build())
            .build()).url().toString();
}
```

**Python**

```python
# app/infra/_03db_03s3.py
def presign_get(key: str, expires_seconds: int = 300) -> str:
    return _s3().generate_presigned_url(
        "get_object", Params={"Bucket": _bucket(), "Key": key}, ExpiresIn=expires_seconds
    )
```

```python
# app/api/_03db_03s3.py
@router.get("/presign-get")
def presign_get(key: str, seconds: int = 300) -> dict[str, str]:
    if not 1 <= seconds <= 3600:  # cap the leak window at the API edge
        raise HTTPException(status_code=422, detail="seconds must be 1..3600")
    return {"url": infra.presign_get(key, seconds)}
```

**Catch**

- With role / STS credentials the URL dies when the session token expires

## 3. Presigned PUT

A presigned PUT lets a browser or mobile client upload directly; bytes skip our server.

**Java**

```java
// infra/_03db_03s3/S3LakeStore.java
@Override
public String presignPut(String key, String contentType, Duration expiry) {
    return presigner.presignPutObject(PutObjectPresignRequest.builder()
            .signatureDuration(expiry)
            // contentType is signed: the client must send the identical header
            .putObjectRequest(PutObjectRequest.builder().bucket(bucket).key(key).contentType(contentType).build())
            .build()).url().toString();
}
```

**Python**

```python
# app/infra/_03db_03s3.py
def presign_put(key: str, content_type: str, expires_seconds: int = 300) -> str:
    return _s3().generate_presigned_url(
        "put_object",
        Params={"Bucket": _bucket(), "Key": key, "ContentType": content_type},
        ExpiresIn=expires_seconds,
    )
```

**Catch**

→ Client sends a header that differs from the signed one (content-type, Server-Side Encryption (SSE))  
⇒ 403 SignatureDoesNotMatch  
→ Send exactly the signed headers

- PUT URLs cannot restrict size

## 4. Presigned POST

Presigned POST adds a policy, so it can enforce key prefix and max size.

- HyperText Markup Language (HTML) form upload
- `content-length-range` limits size, which PUT cannot
- Java: not shown (Software Development Kit (SDK) v2 has no POST presigner)

**Python**

```python
# app/infra/_03db_03s3.py
def presign_post(key_prefix: str, max_bytes: int, expires_seconds: int = 300) -> dict[str, Any]:
    return _s3().generate_presigned_post(
        Bucket=_bucket(),
        Key=key_prefix + "${filename}",
        Conditions=[["starts-with", "$key", key_prefix], ["content-length-range", 1, max_bytes]],
        ExpiresIn=expires_seconds,
    )
```

**Catch**

- The browser must send the returned fields first and the file field last

## 5. Risks

A presigned URL is a bearer token until it expires.

- Anyone with it can use it
- CloudTrail logs the signer, not the end user
- Mitigations for audit-sensitive downloads
  - Short expiry
  - Bind to Internet Protocol (IP) via a bucket policy condition, if the network allows
  - Prefer CloudFront signed cookies / URLs with an app-level auth check
- Store the S3 key (not a presigned URL) in your database ⇒ URLs expire
