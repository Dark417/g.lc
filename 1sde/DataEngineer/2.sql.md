## 0. Lexical Basics

```sql
statement;                       -- terminator
-- line comment
# line comment                   -- [MY]
/* block comment */
'string literal'                 -- always single quotes
'it''s'                          -- escape by doubling
"col"                            -- identifier quote [STD][PG][OR][MS]
`col`                            -- [MY][SPK]
[col]                            -- [MS]
N'unicode'                       -- [MS]  ·  E'a\nb' [PG]  ·  $$dollar quoted$$ [PG]
```

Keywords are case-insensitive. Identifier case: folded to lower `[PG]`, upper `[OR]`, preserved/case-insensitive `[MS]`, filesystem-dependent `[MY]`. Quoting makes them case-sensitive.

## 1. Database / Schema

```sql
CREATE DATABASE db;

ALTER SESSION SET CURRENT_SCHEMA = s;                 -- [OR]
SHOW DATABASES;  SELECT current_database();  SELECT DB_NAME();
```

## 3. CREATE TABLE

```sql
CREATE TABLE emp (
  id          BIGINT        PRIMARY KEY,
  emp_no      INT           GENERATED ALWAYS AS IDENTITY,
  name        VARCHAR(100)  NOT NULL,
  email       VARCHAR(255)  UNIQUE,
  age         INT           CHECK (age >= 0 AND age < 150),
  status      VARCHAR(20)   NOT NULL DEFAULT 'new',
  salary      NUMERIC(12,2) DEFAULT 0,
  bonus       NUMERIC(12,2),
  total_comp  NUMERIC(12,2) GENERATED ALWAYS AS (salary + COALESCE(bonus,0)) STORED,
  dept_id     INT           REFERENCES dept(id) ON DELETE SET NULL ON UPDATE CASCADE,
  created_at  TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at  TIMESTAMP     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,  -- [MY]
  -- table-level constraints
  CONSTRAINT pk_emp        PRIMARY KEY (id),
  CONSTRAINT uq_name_dept  UNIQUE (name, dept_id),
  CONSTRAINT fk_dept       FOREIGN KEY (dept_id) REFERENCES dept(id),
  CONSTRAINT ck_dates      CHECK (start_dt < end_dt),
  INDEX idx_name (name)                                          -- [MY] inline index
);

CREATE TABLE IF NOT EXISTS t (...);
CREATE OR REPLACE TABLE t (...);                    -- [SPK][Snowflake]
CREATE TABLE t (...) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='...';   -- [MY]
CREATE TABLE t (...) TABLESPACE ts;                 -- [PG][OR]
CREATE TABLE t (...) USING DELTA PARTITIONED BY (dt) LOCATION 's3://b/p'
  TBLPROPERTIES ('delta.enableChangeDataFeed'='true');           -- [SPK]
CREATE UNLOGGED TABLE t (...);                      -- [PG] fast, not crash-safe
CREATE TABLE t (...) WITH (fillfactor=70);          -- [PG] storage params
```

Column clause order: `name TYPE [NOT NULL] [DEFAULT x] [GENERATED ...] [PRIMARY KEY|UNIQUE] [CHECK ...] [REFERENCES ...] [COMMENT '...']`.

<a id="4"></a>

## 4. Constraints

| Constraint | Inline | Table-level | Notes |
| --- | --- | --- | --- |
| PRIMARY KEY | `id INT PRIMARY KEY` | `PRIMARY KEY (a,b)` | implies NOT NULL + unique index; one per table |
| UNIQUE | `email VARCHAR UNIQUE` | `UNIQUE (a,b)` | multiple NULLs usually allowed |
| NOT NULL | `a INT NOT NULL` | — | |
| CHECK | `age INT CHECK (age>0)` | `CHECK (a<b)` | ignored by MySQL < 8.0.16 |
| DEFAULT | `s VARCHAR DEFAULT 'x'` | — | applied on INSERT omission |
| FOREIGN KEY | `d INT REFERENCES dept(id)` | `FOREIGN KEY (d) REFERENCES dept(id)` | referenced col must be PK/UNIQUE |

```sql
-- referential actions
ON DELETE CASCADE | SET NULL | SET DEFAULT | RESTRICT | NO ACTION
ON UPDATE CASCADE | ...
-- deferral
CONSTRAINT c FOREIGN KEY (...) REFERENCES ... DEFERRABLE INITIALLY DEFERRED;  -- [PG][OR]
SET CONSTRAINTS ALL DEFERRED;
-- add/drop later
ALTER TABLE t ADD CONSTRAINT ck CHECK (a > 0);
ALTER TABLE t ADD CONSTRAINT ck CHECK (a > 0) NOT VALID;    -- [PG] skip existing rows
ALTER TABLE t VALIDATE CONSTRAINT ck;
ALTER TABLE t DROP CONSTRAINT ck;                           -- [PG][MS][OR]
ALTER TABLE t DROP FOREIGN KEY fk;  ALTER TABLE t DROP CHECK ck;   -- [MY]
ALTER TABLE t ALTER CONSTRAINT fk DEFERRABLE;               -- [PG]
-- enable/disable
ALTER TABLE t NOCHECK CONSTRAINT ALL;   ALTER TABLE t CHECK CONSTRAINT ALL;    -- [MS]
SET FOREIGN_KEY_CHECKS = 0;                                 -- [MY] bulk load
ALTER TABLE t DISABLE CONSTRAINT c;                         -- [OR]
-- exclusion constraint (no overlapping ranges)
ALTER TABLE booking ADD EXCLUDE USING gist (room WITH =, during WITH &&);   -- [PG]
```

## 5. ALTER TABLE

```sql
-- add / drop columns
ALTER TABLE t ADD COLUMN c INT;
ALTER TABLE t ADD c INT NOT NULL DEFAULT 0;              -- COLUMN keyword optional in [MY][MS][OR]
ALTER TABLE t ADD COLUMN c INT AFTER b;                  -- [MY] position
ALTER TABLE t ADD COLUMN c INT FIRST;                    -- [MY]
ALTER TABLE t ADD (a INT, b VARCHAR(10));                -- [OR] multi-add
ALTER TABLE t ADD COLUMN a INT, ADD COLUMN b TEXT;       -- [PG][MY] multi-add
ALTER TABLE t DROP COLUMN c;
ALTER TABLE t DROP COLUMN c CASCADE;                     -- [PG] drops dependents
-- rename
ALTER TABLE t RENAME COLUMN a TO b;                      -- [PG][MY8+][OR][MS via sp_rename]
EXEC sp_rename 't.a', 'b', 'COLUMN';                     -- [MS]
ALTER TABLE t RENAME TO t2;                              -- [PG][OR][SPK]
RENAME TABLE t TO t2;                                    -- [MY]
-- change type / nullability / default
ALTER TABLE t ALTER COLUMN a TYPE BIGINT;                          -- [PG]
ALTER TABLE t ALTER COLUMN a TYPE int USING a::int;                -- [PG] with conversion
ALTER TABLE t ALTER COLUMN a SET NOT NULL / DROP NOT NULL;         -- [PG]
ALTER TABLE t ALTER COLUMN a SET DEFAULT 0 / DROP DEFAULT;         -- [PG]
ALTER TABLE t MODIFY COLUMN a BIGINT NOT NULL DEFAULT 0;           -- [MY]
ALTER TABLE t MODIFY (a NUMBER(10) DEFAULT 0 NOT NULL);            -- [OR]
ALTER TABLE t CHANGE old_name new_name VARCHAR(50) NOT NULL;       -- [MY] rename+retype
ALTER TABLE t ALTER COLUMN a BIGINT NOT NULL;                      -- [MS]
ALTER TABLE t ADD CONSTRAINT df DEFAULT 0 FOR a;                   -- [MS] defaults are constraints
-- keys & indexes
ALTER TABLE t ADD PRIMARY KEY (a);          ALTER TABLE t DROP PRIMARY KEY;      -- [MY]
ALTER TABLE t ADD INDEX idx (a);            ALTER TABLE t DROP INDEX idx;        -- [MY]
ALTER TABLE t ADD UNIQUE (email);
-- misc
ALTER TABLE t ALTER COLUMN a SET STATISTICS 1000;      -- [PG]
ALTER TABLE t SET SCHEMA s2;                           -- [PG]
ALTER TABLE t OWNER TO u;                              -- [PG]
ALTER TABLE t AUTO_INCREMENT = 1000;                   -- [MY]
ALTER TABLE t ADD COLUMNS (c INT);                     -- [SPK]
ALTER TABLE t ALGORITHM=INPLACE, LOCK=NONE;            -- [MY] online DDL
```

## 6. DROP / TRUNCATE / RENAME

```sql
DROP TABLE t;
DROP TABLE IF EXISTS t;
DROP TABLE IF EXISTS a, b, c;                 -- [MY][PG] multiple
DROP TABLE t CASCADE;                         -- [PG] drop dependent views/FKs
DROP TABLE t CASCADE CONSTRAINTS;             -- [OR]
DROP TABLE t PURGE;                           -- [OR] skip recycle bin
TRUNCATE TABLE t;                             -- TABLE keyword optional in [MY][PG]
TRUNCATE TABLE t RESTART IDENTITY CASCADE;    -- [PG]
DROP VIEW / INDEX / SEQUENCE / TRIGGER / PROCEDURE / FUNCTION / SCHEMA IF EXISTS x;
```

| | DELETE | TRUNCATE | DROP |
| --- | --- | --- | --- |
| Type | DML | DDL | DDL |
| WHERE | yes | no | no |
| Triggers | fire | no | no |
| Rollback | yes | `[PG][MS]` yes, `[MY][OR]` no | `[PG][MS]` yes |
| Identity reset | no | yes (usually) | n/a |
| Structure | kept | kept | removed |
| Speed | slow | fast | fast |

## 7. Index

```sql
CREATE INDEX idx_a ON t (a);
CREATE INDEX idx_ab ON t (a, b);                       -- composite: leftmost-prefix rule
CREATE INDEX idx_d ON t (a DESC, b ASC);
CREATE UNIQUE INDEX uq_email ON t (email);
CREATE INDEX idx_lower ON t (LOWER(email));            -- expression/functional index
CREATE INDEX idx_part ON t (a) WHERE status='active';  -- partial [PG] / filtered [MS]
CREATE INDEX CONCURRENTLY idx ON t (a);                -- [PG] non-blocking
CREATE INDEX idx ON t USING GIN (jsonb_col);           -- [PG] btree|hash|gin|gist|brin|spgist
CREATE INDEX idx ON t (a) INCLUDE (b, c);              -- covering [PG11+][MS]
CREATE CLUSTERED INDEX ci ON t (a);                    -- [MS] one per table
CREATE NONCLUSTERED INDEX ix ON t (a) INCLUDE (b) WHERE b IS NOT NULL;  -- [MS]
CREATE FULLTEXT INDEX ft ON t (body);                  -- [MY][MS]
CREATE INDEX idx ON t (a) INVISIBLE;                   -- [MY8+][OR] test before dropping
ALTER TABLE t ADD INDEX idx (a(10));                   -- [MY] prefix index
DROP INDEX idx;              -- [PG][OR]
DROP INDEX idx ON t;         -- [MY][MS]
ALTER INDEX idx REBUILD;  REINDEX TABLE t;  ANALYZE TABLE t;  UPDATE STATISTICS t;
```

Index is used when: predicate is sargable (`col = x`, `col > x`, `col BETWEEN`, `col LIKE 'a%'`, `col IN (...)`), matches a leftmost prefix, or serves `ORDER BY`/`GROUP BY` order. Skipped when: `WHERE f(col)=x`, `LIKE '%a'`, implicit casts, `OR` across different columns, very low selectivity.

## 8. View / Materialized View

```sql
CREATE VIEW v AS SELECT a, b FROM t WHERE f;
CREATE OR REPLACE VIEW v AS ...;                          -- [PG][MY][OR][MS]
CREATE VIEW v (x, y) AS SELECT a, b FROM t;               -- rename output columns
CREATE VIEW v AS SELECT ... WITH CHECK OPTION;            -- writes must satisfy the WHERE
CREATE VIEW v AS SELECT ... WITH LOCAL|CASCADED CHECK OPTION;
CREATE VIEW v WITH SCHEMABINDING AS SELECT ...;           -- [MS] locks underlying schema
ALTER VIEW v AS SELECT ...;
DROP VIEW IF EXISTS v CASCADE;

CREATE MATERIALIZED VIEW mv AS SELECT ...;                -- [PG][OR]
CREATE MATERIALIZED VIEW mv AS SELECT ... WITH NO DATA;   -- [PG] populate later
REFRESH MATERIALIZED VIEW mv;
REFRESH MATERIALIZED VIEW CONCURRENTLY mv;                -- [PG] needs a UNIQUE index
CREATE MATERIALIZED VIEW mv REFRESH FAST ON COMMIT AS ...;-- [OR]
CREATE MATERIALIZED VIEW mv AS SELECT ...;                -- [SPK] Databricks
-- [MS] equivalent = indexed view
CREATE VIEW v WITH SCHEMABINDING AS ...; CREATE UNIQUE CLUSTERED INDEX ix ON v (id);
CREATE TEMP VIEW / GLOBAL TEMP VIEW v AS ...;             -- [SPK]
```

Views are updatable when simple (single table, no aggregate/DISTINCT/GROUP BY/UNION); otherwise use `INSTEAD OF` triggers.

## 9. Temp Tables / CTAS / Partitions / Sequences

```sql
-- CTAS
CREATE TABLE t2 AS SELECT * FROM t;                    -- with data
CREATE TABLE t2 AS SELECT * FROM t WHERE 1=0;          -- structure only (no constraints)
CREATE TABLE t2 LIKE t;                                -- [MY] structure+indexes, no data
CREATE TABLE t2 (LIKE t INCLUDING ALL);                -- [PG]
SELECT * INTO t2 FROM t;                               -- [MS] CTAS
CREATE TABLE t2 AS SELECT ... WITH NO DATA;            -- [PG]
CREATE TABLE t2 USING DELTA AS SELECT ...;             -- [SPK]

-- temp
CREATE TEMPORARY TABLE tmp (...);                      -- [MY][PG] session-scoped
CREATE TEMP TABLE tmp ON COMMIT DROP AS SELECT ...;    -- [PG] transaction-scoped
CREATE TABLE #tmp (...);                               -- [MS] session
CREATE TABLE ##global (...);                           -- [MS] all sessions
DECLARE @tv TABLE (id INT);                            -- [MS] table variable
CREATE GLOBAL TEMPORARY TABLE tmp (...) ON COMMIT DELETE ROWS;   -- [OR]

-- partitions
CREATE TABLE s (dt DATE, amt INT) PARTITION BY RANGE (dt);                -- [PG]
CREATE TABLE s_2024 PARTITION OF s FOR VALUES FROM ('2024-01-01') TO ('2025-01-01');
CREATE TABLE s_def PARTITION OF s DEFAULT;
ALTER TABLE s DETACH PARTITION s_2024;   ALTER TABLE s ATTACH PARTITION s_2024 FOR VALUES ...;
-- PARTITION BY LIST (region) / HASH (id)                                  [PG]
CREATE TABLE s (...) PARTITION BY RANGE (YEAR(dt))
  (PARTITION p23 VALUES LESS THAN (2024), PARTITION p24 VALUES LESS THAN (2025));  -- [MY]
ALTER TABLE s DROP PARTITION p23;   ALTER TABLE s ADD PARTITION (...);
ALTER TABLE t ADD PARTITION (dt='2024-01-01');         -- [SPK] Hive-style

-- sequences
CREATE SEQUENCE seq START WITH 1 INCREMENT BY 1 CACHE 20 [MINVALUE 1|MAXVALUE n|CYCLE];
SELECT NEXTVAL('seq'), CURRVAL('seq');                 -- [PG]
SELECT seq.NEXTVAL FROM dual;                          -- [OR]
NEXT VALUE FOR seq                                     -- [MS]
ALTER SEQUENCE seq RESTART WITH 100;   DROP SEQUENCE seq;
-- last inserted id
LAST_INSERT_ID() [MY] · lastval()/RETURNING id [PG] · SCOPE_IDENTITY() [MS] · seq.CURRVAL [OR]
```

## 10. INSERT

```sql
INSERT INTO t VALUES (1, 'a');                          -- all columns, positional
INSERT INTO t (a, b) VALUES (1, 'a');                   -- named (preferred)
INSERT INTO t (a, b) VALUES (1,'a'), (2,'b'), (3,'c');  -- multi-row
INSERT INTO t (a, b) VALUES (1, DEFAULT);
INSERT INTO t DEFAULT VALUES;                           -- [PG][MS]
INSERT INTO t () VALUES ();                             -- [MY] all defaults
INSERT INTO t SET a = 1, b = 'x';                       -- [MY] SET form
INSERT INTO t (a, b) SELECT x, y FROM src WHERE f;      -- insert-select
INSERT INTO t SELECT * FROM src;                        -- column order must line up
INSERT INTO t (a) WITH c AS (SELECT ...) SELECT a FROM c;
INSERT INTO t (a) VALUES (1) RETURNING id, created_at;  -- [PG][OR][LT]
INSERT INTO t (a) OUTPUT INSERTED.id, INSERTED.a VALUES (1);   -- [MS]
INSERT INTO t (a) VALUES (1) ON CONFLICT DO NOTHING;    -- [PG]
INSERT IGNORE INTO t (a) VALUES (1);                    -- [MY] swallow dup-key/other errors
INSERT OR IGNORE / OR REPLACE / OR ROLLBACK INTO t ...; -- [LT]
REPLACE INTO t VALUES (1,'x');                          -- [MY] delete-then-insert
INSERT ALL INTO a VALUES(1) INTO b VALUES(2) SELECT * FROM dual;   -- [OR] multi-table
INSERT FIRST WHEN x>10 THEN INTO big ELSE INTO small SELECT * FROM src;  -- [OR] conditional
INSERT INTO t VALUES (...) ON DUPLICATE KEY UPDATE b = VALUES(b);       -- [MY] upsert
INSERT OVERWRITE TABLE t PARTITION (dt='2024-01-01') SELECT ...;        -- [SPK]
INSERT INTO t SELECT /*+ APPEND */ ... ;                -- [OR] direct-path
-- bulk load
LOAD DATA INFILE 'f.csv' INTO TABLE t
  FIELDS TERMINATED BY ',' ENCLOSED BY '"' LINES TERMINATED BY '\n' IGNORE 1 ROWS;  -- [MY]
COPY t (a,b) FROM '/f.csv' WITH (FORMAT csv, HEADER true, DELIMITER ',');           -- [PG]
\copy t FROM 'f.csv' CSV HEADER                                                     -- [PG] psql
BULK INSERT t FROM 'f.csv' WITH (FIELDTERMINATOR=',', FIRSTROW=2);                  -- [MS]
COPY INTO t FROM 's3://...' FILEFORMAT = CSV;                                       -- [SPK]
```

## 11. UPDATE

```sql
UPDATE t SET a = 1;                                     -- EVERY ROW — check the WHERE first
UPDATE t SET a = 1, b = 'x' WHERE id = 5;
UPDATE t SET a = a + 1, updated_at = NOW() WHERE id = 5;
UPDATE t SET a = DEFAULT WHERE id = 5;                  -- [PG]
UPDATE t SET (a, b) = (1, 'x') WHERE id = 5;            -- [PG] row form
UPDATE t SET (a, b) = (SELECT x, y FROM s WHERE s.id = t.id);       -- [PG][OR]
UPDATE t SET a = (SELECT x FROM s WHERE s.id = t.id);               -- correlated scalar
UPDATE t SET status = CASE WHEN x>10 THEN 'hi' WHEN x>5 THEN 'mid' ELSE 'lo' END;
-- join-update per dialect
UPDATE t JOIN s ON t.id = s.id SET t.a = s.x WHERE s.f;             -- [MY]
UPDATE t LEFT JOIN s ON t.id = s.id SET t.a = COALESCE(s.x, 0);     -- [MY]
UPDATE t SET a = s.x FROM s WHERE t.id = s.id;                      -- [PG][LT3.33+]
UPDATE t SET a = s.x FROM t JOIN s ON t.id = s.id;                  -- [MS]
UPDATE (SELECT t.a, s.x FROM t JOIN s ON t.id=s.id) SET a = x;      -- [OR] updatable join view
MERGE INTO t USING s ON (t.id=s.id) WHEN MATCHED THEN UPDATE SET t.a = s.x;   -- [OR][MS][SPK]
-- with CTE
WITH c AS (SELECT id, SUM(x) s FROM d GROUP BY id)
UPDATE t SET total = c.s FROM c WHERE t.id = c.id;                  -- [PG]
-- limits / batching
UPDATE t SET a = 1 ORDER BY id LIMIT 1000;                          -- [MY]
UPDATE TOP (1000) t SET a = 1;                                      -- [MS]
UPDATE t SET a = 1 WHERE id IN (SELECT id FROM t WHERE a<>1 LIMIT 1000);   -- portable
-- returning
UPDATE t SET a = 1 WHERE id = 5 RETURNING *;                        -- [PG]
UPDATE t SET a = 1 OUTPUT DELETED.a AS old, INSERTED.a AS new WHERE id = 5; -- [MS]
```

## 12. DELETE

```sql
DELETE FROM t;                                          -- all rows (logged, rollback-able)
DELETE FROM t WHERE id = 5;
DELETE FROM t WHERE id IN (SELECT id FROM s WHERE f);
DELETE FROM t WHERE EXISTS (SELECT 1 FROM s WHERE s.id = t.id);
DELETE t FROM t JOIN s ON t.id = s.id WHERE s.f;        -- [MY][MS] join-delete
DELETE t1, t2 FROM t1 JOIN t2 ON t1.id=t2.id;           -- [MY] multi-table
DELETE FROM t USING s WHERE t.id = s.id;                -- [PG]
DELETE FROM t WHERE ROWID IN (...);                     -- [OR]
DELETE FROM t ORDER BY created_at LIMIT 1000;           -- [MY] batching
DELETE TOP (1000) FROM t;                               -- [MS]
DELETE FROM t WHERE ctid IN (SELECT ctid FROM t LIMIT 1000);   -- [PG] batching
DELETE FROM t WHERE id = 5 RETURNING *;                 -- [PG]
DELETE FROM t OUTPUT DELETED.* WHERE id = 5;            -- [MS]
WITH c AS (SELECT id FROM t WHERE f) DELETE FROM t WHERE id IN (SELECT id FROM c);
```

## 13. MERGE / UPSERT

```sql
-- ANSI MERGE [MS][OR][PG15+][SPK][Snowflake][DB2]
MERGE INTO target t
USING source s ON t.id = s.id
WHEN MATCHED AND s.f = 1        THEN UPDATE SET t.a = s.a, t.b = s.b
WHEN MATCHED AND s.is_deleted   THEN DELETE
WHEN NOT MATCHED                THEN INSERT (id, a, b) VALUES (s.id, s.a, s.b)
WHEN NOT MATCHED BY SOURCE      THEN DELETE          -- [MS] rows only in target
;                                                    -- [MS] semicolon required

-- source can be a subquery
MERGE INTO t USING (SELECT id, MAX(v) v FROM stg GROUP BY id) s ON t.id = s.id
WHEN MATCHED THEN UPDATE SET v = s.v
WHEN NOT MATCHED THEN INSERT (id, v) VALUES (s.id, s.v);

-- [PG] upsert
INSERT INTO t (id, a) VALUES (1, 'x')
ON CONFLICT (id) DO UPDATE SET a = EXCLUDED.a, updated_at = now();
ON CONFLICT (id) DO NOTHING;
ON CONFLICT ON CONSTRAINT t_pkey DO UPDATE SET a = EXCLUDED.a;
ON CONFLICT (id) WHERE active DO UPDATE SET ...;                  -- partial-index target
ON CONFLICT (id) DO UPDATE SET a = EXCLUDED.a WHERE t.version < EXCLUDED.version;

-- [MY] upsert
INSERT INTO t (id,a) VALUES (1,'x') ON DUPLICATE KEY UPDATE a = VALUES(a);
INSERT INTO t (id,a) VALUES (1,'x') AS new ON DUPLICATE KEY UPDATE a = new.a;  -- 8.0.19+
-- [LT]
INSERT INTO t (id,a) VALUES (1,'x') ON CONFLICT(id) DO UPDATE SET a = excluded.a;
-- [SPK] Delta
MERGE INTO t USING s ON t.id = s.id
WHEN MATCHED THEN UPDATE SET * WHEN NOT MATCHED THEN INSERT *;
```

## 14. Transactions & Locking

```sql
BEGIN;  /  START TRANSACTION;  /  BEGIN TRANSACTION;    -- [MS]
COMMIT;   ROLLBACK;
SAVEPOINT sp1;   ROLLBACK TO SAVEPOINT sp1;   RELEASE SAVEPOINT sp1;
SET AUTOCOMMIT = 0;                                     -- [MY]
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
START TRANSACTION READ ONLY;   START TRANSACTION WITH CONSISTENT SNAPSHOT;   -- [MY]
```

| Level | Dirty read | Non-repeatable read | Phantom |
| --- | --- | --- | --- |
| READ UNCOMMITTED | ✓ | ✓ | ✓ |
| READ COMMITTED (default `[PG][OR][MS]`) | ✗ | ✓ | ✓ |
| REPEATABLE READ (default `[MY]`) | ✗ | ✗ | ✓ (`[MY]` blocks via gap locks) |
| SERIALIZABLE | ✗ | ✗ | ✗ |

```sql
SELECT * FROM t WHERE id=1 FOR UPDATE;            -- exclusive row lock
SELECT ... FOR UPDATE NOWAIT;                     -- error instead of waiting
SELECT ... FOR UPDATE SKIP LOCKED;                -- job-queue pattern
SELECT ... FOR UPDATE OF t1;                      -- lock only one table of a join
SELECT ... FOR SHARE;         /  LOCK IN SHARE MODE;      -- [PG] / [MY]
SELECT ... FOR NO KEY UPDATE / FOR KEY SHARE;             -- [PG] weaker
SELECT ... WITH (UPDLOCK, HOLDLOCK, ROWLOCK);             -- [MS]
SELECT ... WITH (NOLOCK);                                 -- [MS] == READ UNCOMMITTED
LOCK TABLE t IN EXCLUSIVE MODE;                           -- [PG][OR]
LOCK TABLES t WRITE;  UNLOCK TABLES;                      -- [MY]
SET lock_timeout = '5s';  SET LOCK_TIMEOUT 5000;  SET innodb_lock_wait_timeout = 5;
SET statement_timeout = '30s';                            -- [PG]
```

## 15. Execution Order & Skeleton

```sql
WITH cte AS (...)                 -- 0
SELECT   DISTINCT col, agg(x)     -- 5 (SELECT) / 6 (DISTINCT)
FROM     t1                       -- 1
JOIN     t2 ON t1.id = t2.id      -- 1
WHERE    pred                     -- 2  (no aggregates, no SELECT aliases*)
GROUP BY col                      -- 3
HAVING   agg(x) > 1               -- 4  (aggregates allowed)
WINDOW   w AS (PARTITION BY col)  -- 5  (named window)
QUALIFY  ROW_NUMBER() OVER w = 1  -- 6b [SPK][Snowflake]
ORDER BY col DESC                 -- 7  (SELECT aliases allowed)
LIMIT 10 OFFSET 5;                -- 8
```

`FROM → ON → JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → WINDOW → QUALIFY → ORDER BY → LIMIT`.
\*`[MY]`/`[SPK]` allow SELECT aliases in `GROUP BY`/`HAVING`; `[PG]` in `GROUP BY`/`ORDER BY`; `[MS]` in `ORDER BY` only.

## 18. JOIN

```sql
FROM a JOIN        b ON a.id = b.id        -- INNER (JOIN == INNER JOIN)
FROM a INNER JOIN  b ON a.id = b.id
FROM a LEFT  JOIN  b ON a.id = b.id        -- LEFT [OUTER] JOIN
FROM a RIGHT JOIN  b ON a.id = b.id
FROM a FULL  JOIN  b ON a.id = b.id        -- not in [MY]: emulate LEFT UNION RIGHT
FROM a CROSS JOIN  b                       -- cartesian, no ON
FROM a NATURAL JOIN b                      -- joins on all same-named columns (avoid)
FROM a NATURAL LEFT JOIN b
FROM a JOIN b USING (id)                   -- equi-join; id appears once in output
FROM a JOIN b USING (id, dt)
FROM a LEFT JOIN b ON a.id=b.id AND b.f=1  -- extra ON condition keeps all of a
FROM a LEFT JOIN b ON a.id=b.id WHERE b.f=1        -- WHERE makes it effectively inner
FROM a LEFT JOIN b ON a.id=b.id WHERE b.id IS NULL -- anti-join
FROM a, b WHERE a.id = b.id                -- old implicit syntax
FROM a JOIN b ON a.x BETWEEN b.lo AND b.hi -- non-equi join
FROM a JOIN a AS a2 ON a.mgr_id = a2.id    -- self join
FROM a LEFT SEMI JOIN b ON a.id=b.id       -- [SPK] rows of a that match
FROM a LEFT ANTI JOIN b ON a.id=b.id       -- [SPK] rows of a with no match
-- lateral / apply: right side may reference left side's columns
FROM a, LATERAL (SELECT ... WHERE x = a.id) l          -- [PG][MY8+][OR]
FROM a LEFT JOIN LATERAL (...) l ON true               -- [PG] keeps a's rows
FROM a CROSS APPLY (SELECT ... WHERE x = a.id) l       -- [MS]
FROM a OUTER APPLY (...) l                             -- [MS] keeps a's rows
-- chaining / nesting
FROM a JOIN b ON ... JOIN c ON ... LEFT JOIN d ON ...
FROM a JOIN (b JOIN c ON b.k = c.k) ON a.k = b.k
-- hints
SELECT /*+ BROADCAST(b) */ ... ;           -- [SPK]
FROM a INNER MERGE|HASH|LOOP JOIN b ON ... -- [MS]
```

`ON` filters before NULL-padding, `WHERE` filters after — the classic outer-join trap.

## 19. WHERE & Predicates

```sql
WHERE a = 1        <>  !=  >  >=  <  <=
WHERE a <=> b                          -- [MY] NULL-safe equal
WHERE a IS NOT DISTINCT FROM b         -- [PG][STD] NULL-safe equal
WHERE a IS DISTINCT FROM b
WHERE a BETWEEN 1 AND 10               -- inclusive
WHERE a NOT BETWEEN 1 AND 10
WHERE a IN (1,2,3)
WHERE a IN (SELECT id FROM t2)
WHERE (a,b) IN ((1,'x'),(2,'y'))       -- row constructor [PG][MY]
WHERE a NOT IN (...)                   -- DANGER: any NULL ⇒ zero rows
WHERE EXISTS (SELECT 1 FROM t2 WHERE t2.id = t.id)
WHERE NOT EXISTS (...)
WHERE a > ANY (SELECT ...)             -- SOME == ANY
WHERE a > ALL (SELECT ...)
WHERE a IS NULL / IS NOT NULL
WHERE a LIKE 'a%'   '_b'   '%mid%'     -- % any run, _ single char
WHERE a LIKE '50\%' ESCAPE '\'
WHERE a ILIKE 'a%'                     -- [PG] case-insensitive
WHERE a NOT LIKE '...'
WHERE a SIMILAR TO 'a|b%'              -- [PG]
WHERE a ~ 'rx'   ~* 'rx'   !~ 'rx'     -- [PG] regex
WHERE a REGEXP 'x'   RLIKE 'x'         -- [MY][SPK]
WHERE REGEXP_LIKE(a, 'x', 'i')         -- [OR][PG]
WHERE a = 1 AND (b = 2 OR c = 3) AND NOT d = 4
WHERE 1=1 AND ...                      -- query-builder idiom
WHERE dt >= '2024-01-01' AND dt < '2024-02-01'    -- sargable range (beats YEAR(dt)=2024)
```

Precedence: `NOT` > `AND` > `OR` — always parenthesize mixed `AND`/`OR`.

## 20. GROUP BY

```sql
GROUP BY a
GROUP BY a, b
GROUP BY 1, 2                            -- ordinal [MY][PG][SPK]
GROUP BY select_alias                    -- [MY][PG][SPK]
GROUP BY DATE(ts), dept                  -- expression
GROUP BY ALL                             -- [SPK][DuckDB] all non-aggregated select cols
GROUP BY ()                              -- grand total [PG]
GROUP BY ROLLUP(a, b)                    -- (a,b), (a), ()
GROUP BY CUBE(a, b)                      -- (a,b), (a), (b), ()
GROUP BY GROUPING SETS ((a,b), (a), ())  -- explicit

```

## 21. HAVING / QUALIFY

```sql
HAVING COUNT(*) > 1
HAVING SUM(x) > 100 AND MIN(y) < 5
HAVING COUNT(DISTINCT b) = 3
HAVING dept = 'IT'                        -- legal but belongs in WHERE
SELECT a FROM t HAVING COUNT(*) > 1;      -- no GROUP BY ⇒ whole table is one group
QUALIFY ROW_NUMBER() OVER (PARTITION BY a ORDER BY b) = 1   -- [SPK][Snowflake][DuckDB]
```

`WHERE` filters rows · `HAVING` filters groups · `QUALIFY` filters window results.

## 22. ORDER BY

```sql
ORDER BY a
ORDER BY a DESC
ORDER BY a ASC, b DESC, c                 -- per-key direction
ORDER BY 1, 2 DESC                        -- ordinal
ORDER BY alias                            -- SELECT aliases allowed here
ORDER BY LENGTH(name)                     -- expression
ORDER BY a NULLS FIRST / NULLS LAST       -- [PG][OR][SPK][STD]
ORDER BY a IS NULL, a                     -- [MY] emulate NULLS LAST
ORDER BY CASE s WHEN 'high' THEN 1 WHEN 'mid' THEN 2 ELSE 3 END

ORDER BY a COLLATE "C"                    -- [PG]
```

## 23. LIMIT / OFFSET / TOP / FETCH

```sql
-- MySQL / MariaDB / SQLite / Spark / Postgres
LIMIT 1                     -- first 1 row
LIMIT 10                    -- first 10
LIMIT 2, 1                  -- OFFSET 2, COUNT 1 → 3rd row        [MY][LT] only
LIMIT 1 OFFSET 2            -- identical, portable form
LIMIT 2 OFFSET 2            -- skip 2, take 2 → rows 3-4
LIMIT 5, 10                 -- skip 5, take 10 → rows 6-15         [MY][LT]
LIMIT 10 OFFSET 0           -- same as LIMIT 10
LIMIT ?, ?                  -- placeholders
LIMIT 0                     -- no rows (schema probe)

-- PostgreSQL extras
LIMIT ALL                   -- no limit
LIMIT NULL                  -- no limit
OFFSET 5                    -- valid alone
OFFSET 5 ROW / ROWS         -- noise words allowed

-- MySQL: offset without limit needs a sentinel count
LIMIT 5, 18446744073709551615

-- ANSI / [PG] / [MS2012+] / [OR12c+] / [DB2]
OFFSET 0 ROWS FETCH FIRST 1 ROW ONLY
OFFSET 5 ROWS FETCH NEXT 10 ROWS ONLY
FETCH FIRST 10 ROWS ONLY                -- offset omitted
FETCH FIRST 10 ROWS WITH TIES           -- include ties on the last ORDER BY key [PG13+][OR]
FETCH FIRST ROW ONLY                    -- singular = 1
OFFSET 5 ROWS                           -- alone

-- SQL Server
SELECT TOP 1 * FROM t ORDER BY x
SELECT TOP (10) * FROM t                     -- parens required for variables/expressions
SELECT TOP (@n) * FROM t
SELECT TOP 10 PERCENT * FROM t
SELECT TOP 5 WITH TIES * FROM t ORDER BY x   -- WITH TIES needs ORDER BY
DELETE TOP (100) FROM t;  UPDATE TOP (100) t SET a=1;
SELECT * FROM t ORDER BY id OFFSET 10 ROWS FETCH NEXT 10 ROWS ONLY   -- ORDER BY mandatory

-- Oracle pre-12c
SELECT * FROM t WHERE ROWNUM <= 10;                       -- top-N only
SELECT * FROM (SELECT t.*, ROWNUM rn FROM (SELECT * FROM t ORDER BY x) t
               WHERE ROWNUM <= 20) WHERE rn > 10;         -- rows 11-20
-- Oracle 12c+
SELECT * FROM t ORDER BY x OFFSET 10 ROWS FETCH NEXT 10 ROWS ONLY;

-- portable via window function
SELECT * FROM (SELECT t.*, ROW_NUMBER() OVER (ORDER BY x DESC) rn FROM t) s
WHERE rn BETWEEN 11 AND 20;
```

Pagination: page `p` (1-based), size `s` → `LIMIT s OFFSET (p-1)*s`.
Keyset/seek alternative for deep pages: `WHERE (sort_key, id) < (:k, :id) ORDER BY sort_key DESC, id DESC LIMIT 20`.
`LIMIT` without `ORDER BY` is arbitrary; it applies after `DISTINCT`, `GROUP BY`, and window functions.

## 25. CTE & Recursive

```sql
WITH c AS (SELECT ...) SELECT * FROM c;
WITH a AS (...), b AS (SELECT * FROM a) SELECT * FROM b;    -- chained
WITH c (x, y) AS (SELECT 1, 2) SELECT * FROM c;             -- column list
WITH c AS MATERIALIZED (...)      / NOT MATERIALIZED (...)  -- [PG12+]

WITH RECURSIVE r AS (
  SELECT id, parent_id, 1 AS lvl FROM nodes WHERE parent_id IS NULL   -- anchor
  UNION ALL
  SELECT n.id, n.parent_id, r.lvl + 1                                  -- recursive term
  FROM nodes n JOIN r ON n.parent_id = r.id
  -- WHERE r.lvl < 100                                                 -- depth guard

SELECT * FROM r;

... SEARCH DEPTH FIRST BY id SET ord            -- [PG14+]

OPTION (MAXRECURSION 200);                      -- [MS] end of statement
CONNECT BY PRIOR id = parent_id START WITH parent_id IS NULL;   -- [OR] alternative
```

## 26. Window Functions

```sql
fn(...) OVER ()                                       -- entire result = one frame
fn(...) OVER (PARTITION BY a)
fn(...) OVER (ORDER BY b)
fn(...) OVER (PARTITION BY a ORDER BY b)
fn(...) OVER (PARTITION BY a, b ORDER BY c DESC NULLS LAST)
fn(...) OVER w  ... WINDOW w AS (PARTITION BY a ORDER BY b)     -- named window
fn(...) OVER (w ORDER BY c)                                     -- extend a named window
```

Frame clause:

```sql
ROWS   BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
RANGE  BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW       -- default when ORDER BY present
ROWS   BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING  -- default with no ORDER BY
ROWS   BETWEEN 2 PRECEDING AND CURRENT ROW               -- 3-row trailing
ROWS   BETWEEN 1 PRECEDING AND 1 FOLLOWING               -- centered
ROWS   BETWEEN CURRENT ROW AND UNBOUNDED FOLLOWING       -- suffix
ROWS   2 PRECEDING                                       -- shorthand for BETWEEN … AND CURRENT ROW
RANGE  BETWEEN INTERVAL '7 days' PRECEDING AND CURRENT ROW  -- [PG][OR] value-based
GROUPS BETWEEN 1 PRECEDING AND 1 FOLLOWING               -- [PG11+] peer groups
... EXCLUDE CURRENT ROW | GROUP | TIES | NO OTHERS       -- [PG11+][OR]
```

Functions:

```sql
-- ranking (ignore the frame)
ROW_NUMBER()   OVER (ORDER BY x)     -- 1,2,3,4
RANK()         OVER (ORDER BY x)     -- 1,1,3,4  (gaps)
DENSE_RANK()   OVER (ORDER BY x)     -- 1,1,2,3  (no gaps)
PERCENT_RANK() OVER (ORDER BY x)     -- (rank-1)/(n-1)
CUME_DIST()    OVER (ORDER BY x)
NTILE(4)       OVER (ORDER BY x)     -- quartile bucket
-- offset
LAG(x) / LAG(x,2) / LAG(x,1,0)  OVER (ORDER BY t)
LEAD(x,1,0)                     OVER (ORDER BY t)
LAG(x) IGNORE NULLS             OVER (ORDER BY t)      -- [OR][SPK][Snowflake]
-- positional (frame-sensitive)
FIRST_VALUE(x) OVER (PARTITION BY a ORDER BY t)
LAST_VALUE(x)  OVER (PARTITION BY a ORDER BY t
                     ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING)  -- frame required
NTH_VALUE(x, 2) OVER (...)
-- aggregates as windows
SUM(x)   OVER (PARTITION BY a ORDER BY t)          -- running total
SUM(x)   OVER (PARTITION BY a)                     -- partition total on every row
AVG(x)   OVER (ORDER BY t ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)  -- 7-row moving avg
COUNT(*) OVER (PARTITION BY a)                     -- group size, rows preserved
COUNT(*) OVER ()                                   -- total count alongside each row
MAX/MIN/ARRAY_AGG/STRING_AGG(x) OVER (...)
```

Windows run after `WHERE`/`GROUP BY`, so they can't appear in `WHERE`/`HAVING`/`GROUP BY` — wrap in a subquery/CTE, or use `QUALIFY`. They may sit inside `CASE`, but not inside another window function.

## 27. Subqueries

```sql
-- scalar (1 row × 1 col): usable anywhere an expression is
SELECT a, (SELECT MAX(x) FROM t2) AS m FROM t1;
SELECT a, (SELECT COUNT(*) FROM t2 WHERE t2.id = t1.id) AS c FROM t1;   -- correlated
WHERE x > (SELECT AVG(x) FROM t);
UPDATE t SET a = (SELECT b FROM t2 WHERE t2.id = t.id);
WHERE (a,b) = (SELECT a,b FROM t2 LIMIT 1);              -- row comparison
-- derived table
FROM (SELECT a, COUNT(*) c FROM t GROUP BY a) s WHERE s.c > 1;
-- IN / EXISTS / ANY / ALL
WHERE id IN (SELECT id FROM t2 WHERE f = 1);
WHERE EXISTS (SELECT 1 FROM t2 WHERE t2.id = t.id);      -- correlated, short-circuits
WHERE x >= ALL (SELECT x FROM t);                        -- max
WHERE x = ANY (SELECT x FROM t);                         -- == IN
-- lateral
FROM users u, LATERAL (SELECT * FROM orders o WHERE o.uid = u.id ORDER BY ts DESC LIMIT 3) o;
```

## 29. NULL Semantics

| Expression | Result |
| --- | --- |
| `NULL = NULL` | `NULL` (not TRUE) |
| `NULL <> NULL` | `NULL` |
| `1 + NULL`, `'a' \|\| NULL` | `NULL` |
| `NULL AND FALSE` | `FALSE` |
| `NULL OR TRUE` | `TRUE` |
| `NULL AND TRUE` | `NULL` |
| `COUNT(*)` | counts rows containing NULLs |
| `COUNT(col)` / `SUM` / `AVG` | skip NULLs (`AVG` divides by non-NULL count) |
| `GROUP BY` | all NULLs form one group |
| `DISTINCT` | NULLs treated as equal |
| `UNIQUE` constraint | multiple NULLs usually allowed |
| `x IN (1, NULL)` | TRUE or NULL — never FALSE |
| `x NOT IN (1, NULL)` | FALSE or NULL — never TRUE |

Test only with `IS NULL` / `IS NOT NULL` / `IS DISTINCT FROM`.

# Part 5 — Combinations

<a id="40"></a>

## 40. Composed Query Patterns

### 40.1 Top-N per group

```sql
-- window (portable; tie behavior is yours to choose)
SELECT * FROM (
  SELECT e.*, ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY salary DESC, id) rn
  FROM emp e
) s WHERE rn <= 3;
-- keep ties: DENSE_RANK() <= 3
-- [SPK]:  SELECT * FROM emp QUALIFY ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY salary DESC) <= 3;
-- [PG] top-1 only
SELECT DISTINCT ON (dept_id) * FROM emp ORDER BY dept_id, salary DESC;
-- LATERAL (fast with an index on (dept_id, salary DESC))
SELECT d.*, e.* FROM dept d
CROSS JOIN LATERAL (SELECT * FROM emp e WHERE e.dept_id = d.id ORDER BY salary DESC LIMIT 3) e;
-- correlated count (no window functions available)
SELECT * FROM emp e1
WHERE 3 > (SELECT COUNT(*) FROM emp e2 WHERE e2.dept_id = e1.dept_id AND e2.salary > e1.salary);
```

### 40.2 Nth-highest value

```sql
SELECT DISTINCT salary FROM emp ORDER BY salary DESC LIMIT 1 OFFSET 1;   -- 2nd highest
SELECT DISTINCT salary FROM emp ORDER BY salary DESC LIMIT 1, 1;         -- [MY] same
SELECT MAX(salary) FROM emp WHERE salary < (SELECT MAX(salary) FROM emp);
SELECT salary FROM (SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) r FROM emp) s WHERE r = 2;
SELECT salary FROM emp ORDER BY salary DESC OFFSET 1 ROWS FETCH NEXT 1 ROW ONLY;
SELECT (SELECT DISTINCT salary FROM emp ORDER BY salary DESC LIMIT 1 OFFSET :n-1);  -- NULL-safe
```

### 40.3 Pagination

```sql
SELECT * FROM posts ORDER BY created_at DESC, id DESC LIMIT 20 OFFSET 40;   -- page 3
-- keyset/seek — constant cost at any depth
SELECT * FROM posts WHERE (created_at, id) < (:last_created, :last_id)
ORDER BY created_at DESC, id DESC LIMIT 20;
-- page + total in one pass
SELECT *, COUNT(*) OVER () AS total FROM posts ORDER BY id LIMIT 20 OFFSET 40;
-- hasNext without a count: fetch size+1
SELECT * FROM posts ORDER BY id LIMIT 21;
```

### 40.4 Deduplication

```sql
SELECT email, COUNT(*) FROM users GROUP BY email HAVING COUNT(*) > 1;    -- find dups
DELETE FROM users WHERE id NOT IN (SELECT MIN(id) FROM users GROUP BY email);
WITH d AS (SELECT id, ROW_NUMBER() OVER (PARTITION BY email ORDER BY id) rn FROM users)
DELETE FROM users WHERE id IN (SELECT id FROM d WHERE rn > 1);           -- portable
DELETE FROM users a USING users b WHERE a.email = b.email AND a.id > b.id;   -- [PG]
DELETE u1 FROM users u1 JOIN users u2 ON u1.email = u2.email AND u1.id > u2.id;  -- [MY]
-- latest row per key
SELECT * FROM (SELECT *, ROW_NUMBER() OVER (PARTITION BY key ORDER BY ts DESC) rn FROM stg) s
WHERE rn = 1;
```

### 40.5 Running totals, moving averages, shares

```sql
SELECT dt, amt,
  SUM(amt) OVER (ORDER BY dt ROWS UNBOUNDED PRECEDING)                   AS running_total,
  SUM(amt) OVER (PARTITION BY dept ORDER BY dt)                          AS dept_running,
  AVG(amt) OVER (ORDER BY dt ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)   AS ma7,
  amt * 100.0 / SUM(amt) OVER ()                                         AS pct_of_total,
  amt * 100.0 / SUM(amt) OVER (PARTITION BY dept)                        AS pct_of_dept,
  amt - LAG(amt) OVER (ORDER BY dt)                                      AS delta,
  (amt - LAG(amt) OVER (ORDER BY dt)) * 100.0
      / NULLIF(LAG(amt) OVER (ORDER BY dt), 0)                           AS pct_change,
  amt - FIRST_VALUE(amt) OVER (PARTITION BY dept ORDER BY dt)            AS vs_first
FROM sales;
```

### 40.6 CTE + aggregate + window + filter stacked

```sql
WITH monthly AS (
  SELECT dept, DATE_TRUNC('month', dt) AS m,
         SUM(amt)                          AS total,
         COUNT(*) FILTER (WHERE amt > 100) AS big_orders,
         COUNT(DISTINCT cust_id)           AS customers
  FROM sales WHERE dt >= '2024-01-01'
  GROUP BY dept, DATE_TRUNC('month', dt)
), ranked AS (
  SELECT monthly.*,
         SUM(total) OVER (PARTITION BY dept ORDER BY m)          AS cum_total,
         LAG(total) OVER (PARTITION BY dept ORDER BY m)          AS prev_total,
         RANK()     OVER (PARTITION BY m ORDER BY total DESC)    AS rank_in_month
  FROM monthly
)
SELECT * FROM ranked
WHERE rank_in_month <= 5 AND total > COALESCE(prev_total, 0)
ORDER BY m DESC, rank_in_month
LIMIT 20 OFFSET 0;
```

### 40.7 Gaps & islands

```sql
-- consecutive-date streaks (row_number difference)
WITH g AS (
  SELECT user_id, dt, dt - (ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY dt))::int AS grp
  FROM logins)
SELECT user_id, MIN(dt) start_dt, MAX(dt) end_dt, COUNT(*) streak
FROM g GROUP BY user_id, grp HAVING COUNT(*) >= 3 ORDER BY streak DESC;
-- 3+ consecutive equal values
SELECT DISTINCT num FROM (
  SELECT num, LAG(num) OVER (ORDER BY id) p1, LAG(num,2) OVER (ORDER BY id) p2 FROM logs) s
WHERE num = p1 AND num = p2;
-- missing ranges
SELECT id + 1 AS gap_start, next_id - 1 AS gap_end
FROM (SELECT id, LEAD(id) OVER (ORDER BY id) next_id FROM t) s WHERE next_id - id > 1;
-- sessionization: new session after 30 min idle
WITH marked AS (
  SELECT *, CASE WHEN ts - LAG(ts) OVER (PARTITION BY uid ORDER BY ts) > INTERVAL '30 min'
                 OR LAG(ts) OVER (PARTITION BY uid ORDER BY ts) IS NULL THEN 1 ELSE 0 END is_new
  FROM events)
SELECT *, SUM(is_new) OVER (PARTITION BY uid ORDER BY ts) AS session_id FROM marked;
```

### 40.8 Self-join patterns

```sql
SELECT e.name AS emp, m.name AS mgr FROM emp e LEFT JOIN emp m ON e.mgr_id = m.id;
SELECT a.id, b.id FROM t a JOIN t b ON a.id < b.id AND a.city = b.city;   -- unique pairs
SELECT c.*, p.amt AS prev FROM sales c LEFT JOIN sales p ON p.dt = c.dt - 1;
SELECT CASE WHEN id % 2 = 1 AND id = (SELECT MAX(id) FROM seat) THEN id
            WHEN id % 2 = 1 THEN id + 1 ELSE id - 1 END AS id, student
FROM seat ORDER BY id;                                                    -- swap adjacent
```

### 40.9 Anti-join, four ways

```sql
SELECT c.* FROM cust c LEFT JOIN ord o ON c.id = o.cust_id WHERE o.id IS NULL;
SELECT * FROM cust WHERE NOT EXISTS (SELECT 1 FROM ord WHERE ord.cust_id = cust.id);
SELECT * FROM cust WHERE id NOT IN (SELECT cust_id FROM ord WHERE cust_id IS NOT NULL);
```

### 40.10 Pivot + rollup + rank together

```sql
SELECT COALESCE(dept, 'ALL')                  AS dept,
       SUM(CASE WHEN q='Q1' THEN amt END)     AS q1,
       SUM(CASE WHEN q='Q2' THEN amt END)     AS q2,
       SUM(amt)                               AS total,
       GROUPING(dept)                         AS is_total
FROM sales WHERE yr = 2024
GROUP BY ROLLUP(dept)
HAVING SUM(amt) > 0
```

### 40.11 Date spine (fill missing days)

```sql
WITH RECURSIVE days(d) AS (
  SELECT DATE '2024-01-01' UNION ALL SELECT d + 1 FROM days WHERE d < DATE '2024-01-31')
SELECT days.d, COALESCE(SUM(s.amt), 0) AS amt
FROM days LEFT JOIN sales s ON s.dt = days.d
GROUP BY days.d ORDER BY days.d;
-- [PG] shortcut: FROM generate_series('2024-01-01'::date, '2024-01-31', '1 day') d
-- carry the last known value forward
SELECT d, COALESCE(v, LAG(v) IGNORE NULLS OVER (ORDER BY d)) AS filled FROM spine;
```

### 40.12 Report via conditional aggregation

```sql
SELECT dept,
  COUNT(*)                                          AS headcount,
  COUNT(*) FILTER (WHERE salary > 100000)           AS high_earners,
  SUM(CASE WHEN gender='F' THEN 1 ELSE 0 END)       AS female,
  ROUND(AVG(CASE WHEN active THEN salary END), 2)   AS avg_active_salary,
  MAX(CASE WHEN rn = 1 THEN name END)               AS top_earner
FROM (SELECT e.*, ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC) rn FROM emp e) e
GROUP BY dept
HAVING COUNT(*) >= 5
ORDER BY avg_active_salary DESC NULLS LAST

```

### 40.13 CTE chain + UNION + window + limit

```sql
WITH base AS (
  SELECT id, cat, amt, dt FROM sales WHERE dt >= CURRENT_DATE - INTERVAL '90 days'
), agg AS (
  SELECT cat, SUM(amt) amt, COUNT(*) n FROM base GROUP BY cat
), top5 AS (
  SELECT cat, amt, n FROM agg ORDER BY amt DESC LIMIT 5
), rest AS (
  SELECT 'OTHER' AS cat, SUM(amt) amt, SUM(n) n FROM agg WHERE cat NOT IN (SELECT cat FROM top5)
)
SELECT cat, amt, n, ROUND(100.0 * amt / SUM(amt) OVER (), 1) AS pct
FROM (SELECT * FROM top5 UNION ALL SELECT * FROM rest) u
ORDER BY (cat = 'OTHER'), amt DESC;
```

### 40.14 Staging load: dedupe → merge

```sql
WITH deduped AS (
  SELECT * FROM (SELECT s.*, ROW_NUMBER() OVER (PARTITION BY id ORDER BY updated_at DESC) rn
                 FROM staging s) x WHERE rn = 1
)
MERGE INTO target t USING deduped s ON t.id = s.id
WHEN MATCHED AND s.updated_at > t.updated_at THEN UPDATE SET t.v = s.v, t.updated_at = s.updated_at
WHEN MATCHED AND s.is_deleted THEN DELETE
WHEN NOT MATCHED AND NOT s.is_deleted THEN INSERT (id, v, updated_at) VALUES (s.id, s.v, s.updated_at);
```

### 40.19 Everything at once (reference query)

```sql
WITH RECURSIVE org AS (
    SELECT id, mgr_id, name, 1 AS lvl FROM emp WHERE mgr_id IS NULL
    UNION ALL
    SELECT e.id, e.mgr_id, e.name, o.lvl + 1 FROM emp e JOIN org o ON e.mgr_id = o.id
),
sales_agg AS (
    SELECT emp_id, SUM(amt) AS total, COUNT(*) FILTER (WHERE amt > 500) AS big
    FROM sales WHERE dt BETWEEN '2024-01-01' AND '2024-12-31'
    GROUP BY emp_id HAVING SUM(amt) > 0
)
SELECT o.lvl, o.name,
       COALESCE(s.total, 0)                                          AS total,
       RANK()       OVER (PARTITION BY o.lvl ORDER BY s.total DESC)  AS rank_in_level,
       SUM(s.total) OVER (PARTITION BY o.lvl)                        AS level_total,
       LAG(s.total) OVER (PARTITION BY o.lvl ORDER BY s.total DESC)  AS next_higher,
       CASE WHEN s.total > 10000 THEN 'A' WHEN s.total > 1000 THEN 'B' ELSE 'C' END AS tier,
       r.score AS latest_review
FROM org o
LEFT JOIN sales_agg s ON s.emp_id = o.id
LEFT JOIN LATERAL (SELECT * FROM reviews r WHERE r.emp_id = o.id ORDER BY r.dt DESC LIMIT 1) r ON TRUE
WHERE o.lvl <= 4 AND (s.big > 0 OR s.big IS NULL)
ORDER BY o.lvl, rank_in_level NULLS LAST
LIMIT 50 OFFSET 0;
```

<a id="gotchas"></a>

## Gotchas

- `NOT IN (subquery containing NULL)` → always empty. Use `NOT EXISTS`.
- `COUNT(col)` ≠ `COUNT(*)` when NULLs exist.
- A `WHERE` on a left-joined table's column silently converts the join to inner (except `IS NULL`).
- `LIMIT` without `ORDER BY` is non-deterministic; `ORDER BY` on non-unique keys is non-deterministic across pages — always add a tiebreaker.
- `AVG(int_col)` can do integer division in `[PG][MS]` — cast: `AVG(x::numeric)` or `AVG(x*1.0)`.
- `LAST_VALUE` needs an explicit `ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING`.
- Window functions cannot appear in `WHERE`/`HAVING`/`GROUP BY`.
- `UNION` deduplicates (sort/hash cost); use `UNION ALL` unless the dedupe is needed.
- Functions on an indexed column (`WHERE YEAR(dt)=2024`) block index use — rewrite as a range.
- `DISTINCT` is not a function: `SELECT DISTINCT(a), b` still applies to the whole row.
- `HAVING` without `GROUP BY` treats the whole table as one group.
- `TRUNCATE` skips triggers and often can't be rolled back.
- Adding a `NOT NULL` column without a default fails on a non-empty table.
- Dropping a column referenced by a view/FK needs `CASCADE` or fails.
- String comparison case sensitivity comes from the collation, not from SQL.
