## 0. Core Concepts

- 这一组是"零件原理"，不是完整设计题
- 每个要能讲：problem → mechanism（3–5 步）→ catch → 🗣

<a id="s0-1"></a>
### 0.1 Partitioning ★★★

- Consistent hashing
  - 解决：节点增减时，只迁移少量 key
  - 要点：hash ring、virtual nodes
- Sharding 策略
  - range / hash / directory
  - 热点 key 和 resharding

<a id="s0-2"></a>
### 0.2 Replication & quorum ★★★

- Leader-follower（sync / async）、multi-leader、leaderless
- W + R > N 为什么能读到最新写
- Replication lag 带来的问题：read-your-writes

<a id="s0-3"></a>
### 0.3 Consensus & leader election ★★

- Raft 大意：term、log replication、majority
- Lease 选主 + fencing token

<a id="s0-4"></a>
### 0.4 CAP / PACELC & consistency models ★★★

- 分区时：C 还是 A
- 无分区时：latency 还是 consistency
- Strong / linearizable、eventual、read-your-writes、causal

<a id="s0-5"></a>
### 0.5 Distributed ID generation ★★

- UUID、DB auto-increment、Snowflake（时间戳 + 机器号 + 序列）
- 时钟回拨问题

<a id="s0-6"></a>
### 0.6 Rate limiting algorithms ★★★

- Token bucket、leaky bucket、fixed window、sliding window log / counter
- 分布式计数：Redis + Lua

<a id="s0-7"></a>
### 0.7 Caching strategies & eviction ★★★

- Cache-aside、read/write-through、write-behind
- LRU / LFU / TTL
- Thundering herd、penetration、avalanche

<a id="s0-8"></a>
### 0.8 Idempotency & delivery semantics ★★★

- At-most-once、at-least-once、effectively-once
- Idempotency key 存哪里、存多久

<a id="s0-9"></a>
### 0.9 Distributed lock & fencing ★★

- Redis lock 的问题（GC 暂停、时钟）
- etcd / ZooKeeper lease + fencing token

<a id="s0-10"></a>
### 0.10 Outbox / CDC ★★★

- Dual write 为什么错
- Outbox 表 + relay；Debezium CDC

<a id="s0-11"></a>
### 0.11 Backpressure, retry, circuit breaker ★★

- 超时、指数退避 + jitter、重试预算
- Circuit breaker 三态

<a id="s0-12"></a>
### 0.12 Probabilistic structures ★

- Bloom filter：判断"一定不存在"
- Count-min sketch：近似计数、heavy hitters

<a id="s0-13"></a>
### 0.13 Geo indexing ★★

- Geohash（前缀 = 区域）
- Quadtree（按密度切分）

<a id="s0-14"></a>
### 0.14 Windowed aggregation & top-K ★★

- Tumbling / sliding window
- 精确 top-K（heap）vs 近似（count-min + heap）

## 1. Core Components

- 这一组是"把一个节点本身设计出来"
- 每题只写最核心的需求，后面再加

<a id="s1-1"></a>
### 1.1 Distributed cache ★★★

- Features
  - get / set / delete，TTL
  - 水平扩展到多节点
  - 节点挂掉不丢全部数据
- Key challenges：分片（consistent hashing）、复制、热点 key
- Uses：0.1、0.2、0.7

<a id="s1-2"></a>
### 1.2 Message queue / log ★★★

- Features
  - publish / subscribe，topic + partition
  - 消费组，offset 管理
  - 持久化，可重放
- Key challenges：分区有序、副本同步、消费者 rebalance
- Uses：0.2、0.8

<a id="s1-3"></a>
### 1.3 Rate limiter (per-tenant) ★★★

- Features
  - 按 user / tenant / API 限流
  - 规则可配置
  - 超限返回 429
- Key challenges：分布式计数精度、低延迟、Redis 挂了怎么办
- Uses：0.6

<a id="s1-4"></a>
### 1.4 Load balancer ★★

- Features
  - L4 / L7 转发
  - health check，自动摘除
  - 多种算法
- Key challenges：LB 自身高可用、长连接、配置下发
- Uses：0.1

<a id="s1-5"></a>
### 1.5 Distributed KV store ★★

- Features
  - put / get，按 key
  - 可调一致性
  - 扩缩容
- Key challenges：分区、quorum、冲突解决、节点故障
- Uses：0.1、0.2、0.4

<a id="s1-6"></a>
### 1.6 Object storage ★★

- Features
  - put / get 大对象，bucket + key
  - multipart upload
  - 高耐久
- Key challenges：metadata 与数据分离、副本 / erasure coding
- Uses：0.2

<a id="s1-7"></a>
### 1.7 Distributed job scheduler ★★★

- Features
  - 提交任务（立即 / 定时 / cron）
  - 每个任务恰好执行一次（语义上）
  - 失败重试，查询状态
- Key challenges：调度器高可用、防重复执行、任务依赖
- Uses：0.3、0.8、0.9

<a id="s1-8"></a>
### 1.8 Unique ID service ★★

- Features
  - 全局唯一，大致按时间递增
  - 高 QPS、低延迟
- Key challenges：时钟回拨、机器号分配
- Uses：0.5

<a id="s1-9"></a>
### 1.9 Metrics / logging system ★★★

- Features
  - 采集大量 metrics / logs
  - 按时间范围查询、聚合
  - 告警
- Key challenges：写入量大、存储成本、降采样
- Uses：0.14

<a id="s1-10"></a>
### 1.10 Config service (staged rollout) ★★

- Features
  - 版本化配置
  - 分批发布、回滚
  - 客户端快速拿到新配置
- Key challenges：一致性、推 vs 拉、坏配置爆炸半径
- Uses：0.3

<a id="s1-11"></a>
### 1.11 Distributed lock service ★★

- Features
  - acquire / release，带 lease
  - 持有者挂了自动释放
- Key challenges：fencing、脑裂
- Uses：0.3、0.9

<a id="s2"></a>
## 2. Product Questions By Type

- 每题：核心 features（3–5 条）+ key challenge + 用到的模式（见 1.sd.md 第 6 节）

<a id="s2-1"></a>
### 2.1 Realtime messaging

<a id="h1"></a>
#### Chat (WhatsApp) ★★★

- Features
  - 1:1 消息，发送 / 送达 / 已读
  - 群聊
  - 离线消息，上线后收到
  - 消息历史
- Key challenges：长连接路由、消息有序、离线存储
- Patterns：realtime fan-out、write-heavy

<a id="h2"></a>
#### Live comments ★★★（上次挂的题）

- Features
  - 在直播 / 视频下发评论
  - 所有观众实时看到
  - 新加入的观众看到最近评论
- Key challenges：热门直播 fan-out、SSE vs WebSocket、推送频率
- Patterns：realtime fan-out

<a id="h3"></a>
#### Notification system ★★★

- Features
  - 多渠道：push、email、SMS
  - 用户偏好、退订
  - 可靠送达，重试
- Key challenges：第三方失败、去重、限流
- Patterns：async job

<a id="h4"></a>
#### Presence (online status) ★★

- Features
  - 显示好友在线 / 离线
  - 最后在线时间
- Key challenges：心跳规模、状态 fan-out
- Patterns：realtime fan-out

<a id="s2-2"></a>
### 2.2 Media streaming

<a id="h5"></a>
#### YouTube ★★

- Features
  - 上传视频
  - 转码成多码率
  - 播放（自适应码率）
  - 观看计数
- Key challenges：转码流水线、CDN、大文件上传
- Patterns：media pipeline

<a id="h6"></a>
#### Live streaming (Twitch) ★

- Features
  - 主播推流
  - 低延迟分发给大量观众
  - 聊天（见 live comments）
- Key challenges：低延迟 vs 规模、实时转码
- Patterns：media pipeline、realtime fan-out

<a id="s2-3"></a>
### 2.3 Feed & social

<a id="h7"></a>
#### News feed ★★★

- Features
  - 发帖
  - 看关注的人的帖子，按时间 / 排序
  - 分页
- Key challenges：fan-out on write vs on read、大 V 问题
- Patterns：read-heavy、async job

<a id="h8"></a>
#### Instagram ★★

- Features
  - 上传图片
  - Feed
  - 点赞、评论
- Key challenges：图片存储 + CDN、feed 生成
- Patterns：media pipeline、read-heavy

<a id="s2-4"></a>
### 2.4 Search & discovery

<a id="h9"></a>
#### Typeahead / autocomplete ★★

- Features
  - 输入前缀返回 top 建议
  - 低延迟
  - 按热度排序
- Key challenges：trie 与更新、缓存
- Patterns：read-heavy、derived view

<a id="h10"></a>
#### Web crawler ★★

- Features
  - 从种子 URL 抓取
  - 去重
  - 礼貌性（每个域名限速）
- Key challenges：URL frontier、去重规模、DNS
- Patterns：async job、write-heavy

<a id="s2-5"></a>
### 2.5 Location

<a id="h11"></a>
#### Uber ★★

- Features
  - 司机上报位置
  - 乘客叫车，匹配附近司机
  - 行程状态
- Key challenges：高频位置写入、附近查询、匹配一致性
- Patterns：write-heavy、geo index

<a id="h12"></a>
#### Proximity search (Yelp) ★★

- Features
  - 搜索附近商家
  - 按距离 / 评分
- Key challenges：geo index、读多
- Patterns：read-heavy

<a id="s2-6"></a>
### 2.6 Storage & collaboration

<a id="h13"></a>
#### Dropbox / Google Drive ★★

- Features
  - 上传 / 下载文件
  - 多设备同步
  - 分享
- Key challenges：分块、增量同步、冲突
- Patterns：media pipeline（上传）、async job

<a id="h14"></a>
#### Google Docs ★

- Features
  - 多人同时编辑
  - 实时看到别人修改
- Key challenges：OT / CRDT、冲突合并
- Patterns：realtime fan-out

<a id="s2-7"></a>
### 2.7 Transactions

<a id="h15"></a>
#### Ticket booking (Ticketmaster) ★★★

- Features
  - 浏览场次
  - 选座、锁座一段时间
  - 支付确认
- Key challenges：不超卖、热门开售瞬时流量
- Patterns：rate limit、async job

<a id="h16"></a>
#### Payment system ★★

- Features
  - 发起支付
  - 对接第三方 PSP
  - 对账
- Key challenges：幂等、exactly-once 语义、状态机
- Patterns：async job、outbox

<a id="h17"></a>
#### E-commerce checkout / inventory ★★

- Features
  - 购物车
  - 下单扣库存
  - 订单状态
- Key challenges：库存一致性、分布式事务（saga）
- Patterns：outbox、async job

<a id="s2-8"></a>
### 2.8 Analytics & ingestion

<a id="h18"></a>
#### Ad click aggregation ★★★

- Features
  - 接收点击事件
  - 按分钟聚合每个广告的点击数
  - 查询
- Key challenges：高写入、去重、窗口聚合、延迟数据
- Patterns：write-heavy ingestion

<a id="h19"></a>
#### Top-K trending ★★

- Features
  - 实时热门 top-K（话题 / 视频）
  - 按时间窗口
- Key challenges：近似计数、窗口滑动
- Patterns：write-heavy ingestion

<a id="s2-9"></a>
### 2.9 Simple read-heavy

<a id="h20"></a>
#### URL shortener ★★（热身题）

- Features
  - 长链接 → 短链接
  - 短链接跳转
  - 可选：过期、统计
- Key challenges：ID 生成、读多缓存
- Patterns：read-heavy

<a id="h21"></a>
#### Pastebin ★

- Features
  - 存文本，返回链接
  - 过期
- Key challenges：大文本存对象存储
- Patterns：read-heavy

<a id="s2-10"></a>
### 2.10 Cloud infra (OCI flavor)

<a id="h22"></a>
#### Async control-plane resource API ★★★

- Features
  - Create / update / delete 资源，立即返回 work request id
  - 查询 work request 状态
  - 失败重试，幂等
- Key challenges：状态机、长任务、幂等 token
- Patterns：async job

<a id="h23"></a>
#### Multi-tenant rate limiter ★★★

- 见 1.3，加上
  - Per-tenant quota
  - 公平性：一个租户不能拖垮其他租户

<a id="h24"></a>
#### Health monitoring for many hosts ★★

- Features
  - 大量主机上报心跳 / 指标
  - 检测失联
  - 告警
- Key challenges：心跳规模、误报
- Patterns：write-heavy ingestion

<a id="h25"></a>
#### Config rollout ★★

- 见 1.10
