# mock-sd-interview

1. Read `1sd/AGENTS.md`, `1sd/build.md`, and `1sd/0flow.md`.
2. Pick level, role, and a canonical question from `1sd/1index.md`.
3. Give only the prompt and let the candidate drive; do not reveal the reference packet before the attempt.
4. Interrupt with mechanism, scale/failure, cost/security, and premise-reversal follow-ups.
5. Score all seven rubric dimensions, gate on the weakest score, and output one focused corrective drill.
