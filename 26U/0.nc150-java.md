### 1.1 Primitives, wrappers, overflow

```java
// 8 primitives; only these 4 matter for interviews
int    i = 0;                 // 32-bit signed, [-2^31, 2^31 - 1]
long   l = 0L;                // 64-bit signed
double d = 0.0;               // use for averages / medians
boolean b = false;            // NOT 0/1 — Java has no truthiness
char   c = 'a';               // 16-bit UNSIGNED, acts like a small int

Integer.MAX_VALUE;            //  2147483647   (use as "infinity" sentinel)
Integer.MIN_VALUE;            // -2147483648
Long.MAX_VALUE;               //  9223372036854775807
Double.MAX_VALUE;
Double.POSITIVE_INFINITY;     // real infinity, survives comparisons
Double.NEGATIVE_INFINITY;

// Overflow is SILENT — it wraps around. This is the #1 Java interview bug.
int mid = (lo + hi) / 2;          // BAD: lo + hi can overflow
int mid = lo + (hi - lo) / 2;     // GOOD
long product = (long) a * b;      // GOOD: cast BEFORE multiplying, not after

// Integer division truncates toward ZERO (not toward -infinity like Python)
 7 / 2;   //  3
-7 / 2;   // -3      (Python gives -4)
-7 % 2;   // -1      (Python gives 1)
Math.floorDiv(-7, 2);   // -4   <- Python-style floor division
Math.floorMod(-7, 2);   //  1   <- Python-style modulo, always non-negative

// Ceiling division of non-negative ints without floating point
int ceil = (a + b - 1) / b;

// Wrappers: Integer / Long / Double / Character / Boolean
Integer boxed = 5;                    // autoboxing
int raw = boxed;                      // auto-unboxing (NPE if boxed is null!)
Integer.parseInt("42");               // String -> int
Integer.valueOf("42");                // String -> Integer
Integer.toString(42);                 // int -> String  (also: "" + 42)
Integer.toBinaryString(10);           // "1010"
Integer.parseInt("1010", 2);          // 10
String.valueOf(42);                   // works for any type
```

⚠️ **Integer cache**: `Integer` values in `[-128, 127]` are interned, so `==` accidentally works there and silently breaks outside it. **Always use `.equals()` for wrapper comparison**, or unbox to `int` first.

```java
Integer a = 127, b = 127;   a == b;        // true  (cached)
Integer c = 128, d = 128;   c == d;        // false (different objects!)
c.equals(d);                               // true  <- always use this
```

### 1.3 Strings

`String` is **immutable**. Every `+` in a loop allocates a new string — use `StringBuilder`.

```java
String s = "hello";
s.length();                      // 5     — a METHOD (arrays use .length field)
s.charAt(0);                     // 'h'   — no s[0] indexing in Java
s.isEmpty();                     // length == 0
s.isBlank();                     // empty or only whitespace (Java 11)

// ---- Slicing (Python s[i:j]) ----
s.substring(1);                  // "ello"   — Python s[1:]
s.substring(1, 3);               // "el"     — Python s[1:3], end EXCLUSIVE
s.substring(s.length() - 2);     // "lo"     — Python s[-2:]
// there is no negative indexing; compute the index yourself

s.indexOf("ll");                 // 2, or -1 if absent
s.lastIndexOf('l');              // 3
s.contains("ell");               // true    — Python `in`
s.startsWith("he");
s.endsWith("lo");

s.equals("hello");               // ALWAYS use equals, never ==
s.equalsIgnoreCase("HELLO");
s.compareTo("hellp");            // <0, 0, >0 — lexicographic ordering

s.toUpperCase();
s.toLowerCase();
s.trim();                        // strip whitespace on both ends
s.strip();                       // Unicode-aware trim (Java 11)
s.replace('l', 'L');
s.replace("ll", "LL");
s.repeat(3);                     // "hellohellohello" (Java 11)

s.split(",");                    // String[]  — regex! escape metachars
s.split("\\s+");                 // split on runs of whitespace
s.split("");                     // array of 1-char strings
String.join(",", listOfStrings); // Python ",".join(...)

s.toCharArray();                 // char[] — the workhorse for scanning
new String(charArray);           // char[] -> String
String.valueOf(charArray);       // same

// ---- StringBuilder: mutable string, the one to use in loops ----
StringBuilder sb = new StringBuilder();
sb.append("ab").append(1).append('c');
sb.length();
sb.charAt(0);
sb.setCharAt(0, 'z');
sb.deleteCharAt(sb.length() - 1);        // pop the last char (backtracking!)
sb.setLength(sb.length() - 1);           // same, slightly cheaper
sb.insert(0, "x");
sb.reverse();
sb.toString();
new StringBuilder(s).reverse().toString();   // reverse a String
```

⚠️ `sb.deleteCharAt(sb.length() - 1)` is the Java equivalent of `path.pop()` in backtracking. Forgetting it is the classic bug.

### 1.4 Arrays

Fixed length, `.length` is a **field** (no parentheses). Default values: `0` / `0.0` / `false` / `null`.

```java
int[] a = new int[5];                    // [0,0,0,0,0]
int[] b = {1, 2, 3};                     // literal (only at declaration)
int[] c = new int[]{1, 2, 3};            // literal anywhere
a.length;                                // field, not method

int[][] g = new int[3][4];               // 3 rows, 4 cols, all 0
int[][] h = {{1, 2}, {3, 4}};
g.length;                                // rows
g[0].length;                             // cols
int[][] jag = new int[3][];              // jagged: rows allocated separately

Arrays.fill(a, -1);                      // fill 1-D
for (int[] row : g) Arrays.fill(row, -1); // fill 2-D (must loop)

Arrays.sort(a);                          // ascending, in place (dual-pivot quicksort)
Arrays.sort(boxed, Collections.reverseOrder());  // descending needs Integer[]
Arrays.sort(g, (x, y) -> x[0] - y[0]);   // sort rows of a 2-D array by col 0
Arrays.sort(a, 2, 5);                    // sort subrange [2, 5)

Arrays.copyOf(a, a.length);              // clone
Arrays.copyOfRange(a, 1, 4);             // Python a[1:4]
System.arraycopy(src, srcPos, dst, dstPos, len);

Arrays.equals(a, b);                     // element-wise (1-D)
Arrays.deepEquals(g, h);                 // element-wise (nested)
Arrays.toString(a);                      // "[1, 2, 3]" — for debugging
Arrays.deepToString(g);                  // "[[1, 2], [3, 4]]"
Arrays.stream(a).sum();                  // also .max().getAsInt(), .min(), .average()
Arrays.asList(1, 2, 3);                  // FIXED-SIZE List<Integer> view

// Grid traversal idiom
int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
for (int[] d : DIRS) {
    int nr = r + d[0], nc = c + d[1];
    if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
    // ...
}
```

⚠️ `Arrays.sort(int[])` is quicksort (O(n²) adversarial worst case, no stability); `Arrays.sort(Object[])` is TimSort (stable, guaranteed O(n log n)). If an interviewer raises anti-quicksort inputs, box to `Integer[]`.

### 1.5 Loops and control flow

```java
for (int i = 0; i < n; i++) { }              // classic
for (int i = n - 1; i >= 0; i--) { }         // reverse — Python range(n-1,-1,-1)
for (int i = 0; i < n; i += 2) { }           // step

for (int x : nums) { }                       // for-each over array
for (String w : list) { }                    // for-each over Collection
for (char ch : s.toCharArray()) { }          // for-each over a String
for (Map.Entry<String, Integer> e : map.entrySet()) {
    e.getKey(); e.getValue();
}

while (cond) { }
do { } while (cond);                         // runs at least once

// Two pointers
int l = 0, r = n - 1;
while (l < r) { ... }

// Labeled break — escape nested loops (Java's answer to Python's flag/else)
outer:
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        if (found) break outer;              // also: continue outer;
    }
}

// Ternary and switch expression
int max = a > b ? a : b;
int v = switch (op) {                        // Java 14+
    case "+" -> x + y;
    case "-" -> x - y;
    default  -> throw new IllegalArgumentException();
};
```

⚠️ `if (x)` requires a `boolean`. `if (list.size())` and `if (node)` do **not** compile — write `if (!list.isEmpty())` and `if (node != null)`.

### 1.7 `Map`

```java
Map<String, Integer> map = new HashMap<>();     // no order guarantee
Map<Integer, List<Integer>> adj = new HashMap<>();

map.put(k, v);
map.get(k);                                     // null if absent (NOT KeyError)
map.getOrDefault(k, 0);                         // Python dict.get(k, 0)
map.containsKey(k);
map.containsValue(v);
map.remove(k);
map.size();
map.isEmpty();
map.keySet();                                   // Set<K>
map.values();                                   // Collection<V>
map.entrySet();                                 // Set<Map.Entry<K,V>>

// --- The three idioms worth memorizing ---
map.put(k, map.getOrDefault(k, 0) + 1);         // counter, explicit
map.merge(k, 1, Integer::sum);                  // counter, idiomatic
map.computeIfAbsent(k, x -> new ArrayList<>()).add(v);   // Python setdefault

map.putIfAbsent(k, v);
map.compute(k, (key, val) -> val == null ? 1 : val + 1);

for (Map.Entry<String, Integer> e : map.entrySet()) {
    String key = e.getKey();
    int val = e.getValue();
}
map.forEach((k, v) -> { ... });

// --- TreeMap: sorted by key, O(log n) — replaces Python's SortedDict/bisect ---
TreeMap<Integer, String> tm = new TreeMap<>();
tm.firstKey(); tm.lastKey();
tm.firstEntry(); tm.lastEntry();
tm.pollFirstEntry(); tm.pollLastEntry();        // remove and return
tm.floorKey(x);        // greatest key <= x     (bisect_right - 1)
tm.ceilingKey(x);      // smallest key >= x     (bisect_left)
tm.lowerKey(x);        // greatest key <  x
tm.higherKey(x);       // smallest key >  x
tm.headMap(x); tm.tailMap(x); tm.subMap(a, b);
tm.descendingMap();

// --- LinkedHashMap: insertion order; accessOrder=true gives you a free LRU ---
LinkedHashMap<Integer, Integer> lru =
    new LinkedHashMap<>(16, 0.75f, true) {            // true = access order
        protected boolean removeEldestEntry(Map.Entry<Integer, Integer> e) {
            return size() > capacity;
        }
    };
```

⚠️ `map.get(k)` returns `Integer`, so `int x = map.get(k)` throws `NullPointerException` when the key is missing. Use `getOrDefault`.

### 1.9 Stack, Queue, Deque

**Use `ArrayDeque` for all three.** `java.util.Stack` is a legacy synchronized `Vector`, and `LinkedList` allocates a node per element.

```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(x);          // == addFirst
stack.pop();            // == removeFirst — throws if empty
stack.peek();           // == peekFirst — null if empty
stack.isEmpty();
stack.size();

Deque<Integer> queue = new ArrayDeque<>();
queue.offer(x);         // == addLast   (Python append)
queue.poll();           // == removeFirst (Python popleft) — null if empty
queue.peek();           // head without removing

Deque<Integer> dq = new ArrayDeque<>();       // monotonic-deque problems
dq.addFirst(x);  dq.addLast(x);
dq.pollFirst();  dq.pollLast();
dq.peekFirst();  dq.peekLast();

// BFS level-by-level (the single most reused Java snippet)
Deque<TreeNode> q = new ArrayDeque<>();
q.offer(root);
while (!q.isEmpty()) {
    int size = q.size();                 // freeze the level boundary FIRST
    for (int i = 0; i < size; i++) {
        TreeNode node = q.poll();
        if (node.left != null)  q.offer(node.left);
        if (node.right != null) q.offer(node.right);
    }
}
```

⚠️ `ArrayDeque` **does not allow `null`** elements — `poll()` returning `null` is how it signals empty. If your BFS legitimately enqueues nulls (some serialize/deserialize solutions), use `LinkedList` instead.

⚠️ `Stack.push/pop` append at the *end*; `Deque.push/pop` work at the *front*. Iterating a `Deque` used as a stack goes top-to-bottom; iterating a `Stack` goes bottom-to-top. Don't mix the two mental models.

### 1.10 `PriorityQueue` (heap)

```java
PriorityQueue<Integer> minHeap = new PriorityQueue<>();                       // min by default
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
PriorityQueue<Integer> maxHeap2 = new PriorityQueue<>((a, b) -> b - a);       // careful: overflow
PriorityQueue<Integer> maxHeap3 = new PriorityQueue<>((a, b) -> Integer.compare(b, a)); // safe

pq.offer(x);       // add     — O(log n)
pq.poll();         // pop min — O(log n), null if empty
pq.peek();         // min without removing — O(1)
pq.size();
pq.isEmpty();
new PriorityQueue<>(collection);                  // O(n) heapify

// Tuples: use int[] plus a comparator (this replaces Python's tuple heap)
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{dist, node});

// Multi-key comparator
PriorityQueue<int[]> pq2 = new PriorityQueue<>(
    (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);   // asc by [0], desc by [1]

// Comparator.comparingInt is the readable form
PriorityQueue<int[]> pq3 = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
PriorityQueue<int[]> pq4 = new PriorityQueue<>(
    Comparator.<int[]>comparingInt(a -> a[0]).thenComparingInt(a -> -a[1]));
```

⚠️ Java has a **real max-heap** via comparator, so the Python "negate everything" trick is unnecessary. Don't port it.

⚠️ Iterating a `PriorityQueue` (for-each, `toString`) does **not** give sorted order — only `poll()` does.

⚠️ `(a, b) -> a - b` overflows when values straddle `Integer.MAX_VALUE`. Prefer `Integer.compare(a, b)`.

### 1.11 Sorting and `Comparator`

```java
Arrays.sort(intArr);                                 // primitives, ascending only
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);       // 2-D by first column
Arrays.sort(strs, (a, b) -> (a + b).compareTo(b + a));  // custom string ordering

Collections.sort(list);                              // natural order
Collections.sort(list, cmp);
list.sort(cmp);                                      // preferred
list.sort(null);                                     // natural order

// Comparator builders — read like English, no overflow risk
Comparator.comparingInt(int[] a -> a[0]);
Comparator.comparingInt((int[] a) -> a[0]).reversed();
Comparator.comparing(Person::getName).thenComparingInt(Person::getAge);
Comparator.naturalOrder();
Comparator.reverseOrder();

// Sort a Map by value, descending
List<Map.Entry<String, Integer>> es = new ArrayList<>(map.entrySet());
es.sort((a, b) -> b.getValue() - a.getValue());

// Comparable: natural ordering on your own class
class Task implements Comparable<Task> {
    int p;
    public int compareTo(Task o) { return Integer.compare(this.p, o.p); }
}
```

Contract: the comparator returns negative when `a` comes first, `0` when tied, positive when `b` comes first.

### 1.12 Binary search built-ins

```java
Arrays.binarySearch(sortedArr, key);
// >= 0 : index of a match
// <  0 : -(insertionPoint) - 1  ->  insertionPoint = -result - 1

// Hand-rolled — know both templates cold
// Template A: exact match
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == target) return mid;
    if (a[mid] < target) lo = mid + 1;
    else hi = mid - 1;
}
return -1;

// Template B: leftmost index satisfying a predicate (binary search on answer)
int lo = 0, hi = n;                 // hi is EXCLUSIVE
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (ok(mid)) hi = mid;
    else lo = mid + 1;
}
return lo;                          // == n if nothing satisfies
```

### 1.15 Custom classes, records, generics

```java
// Standard LeetCode node definitions
class ListNode {
    int val; ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class TreeNode {
    int val; TreeNode left, right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val; this.left = left; this.right = right;
    }
}

// Nested helper — mark it `static` unless it needs the outer instance
private static class Node {
    int key, val;
    Node prev, next;
    Node(int key, int val) { this.key = key; this.val = val; }
}

// record: immutable data carrier, auto equals/hashCode/toString (Java 16)
record Point(int x, int y) {}
Point p = new Point(1, 2);
p.x();                                     // accessor, not p.x
Set<Point> seen = new HashSet<>();         // works as a HashSet key for free

// Any class used as a Map key or Set element MUST override both:
@Override public boolean equals(Object o) { ... }
@Override public int hashCode() { return Objects.hash(a, b); }
```

⚠️ If you override `equals` without `hashCode`, equal objects land in different buckets and your `HashMap` silently misbehaves. `record` handles both for you — prefer it for coordinate/pair keys.

### 1.16 Recursion, lambdas, and mutable capture

Java has no `nonlocal`. A lambda/inner class can only capture **effectively final** variables, so accumulate through a field, a 1-element array, or a return value.

```java
// Option A: instance field (cleanest for a single DFS result)
class Solution {
    private int best = 0;
    public int diameterOfBinaryTree(TreeNode root) {
        best = 0;                       // reset — LeetCode reuses the instance
        depth(root);
        return best;
    }
    private int depth(TreeNode n) {
        if (n == null) return 0;
        int l = depth(n.left), r = depth(n.right);
        best = Math.max(best, l + r);
        return 1 + Math.max(l, r);
    }
}

// Option B: 1-element array (the "box" trick), for locals inside one method
int[] count = {0};
dfs(root, count);

// Option C: return the value up the stack (preferred when it's natural)

// Backtracking skeleton
private void dfs(int start, List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));          // COPY — path keeps mutating
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);                   // choose
        dfs(i + 1, path, res);               // explore
        path.remove(path.size() - 1);        // un-choose
    }
}
```

⚠️ `res.add(path)` without the copy stores a reference to the live list — every entry ends up empty. This is the single most common Java backtracking bug.

### 1.17 Gotchas cheat sheet

| Python habit | Java reality |
| --- | --- |
| `s[i]` | `s.charAt(i)` |
| `s[i:j]` | `s.substring(i, j)` |
| `s[-1]` | `s.charAt(s.length() - 1)` |
| `a == b` for strings | `a.equals(b)` — `==` compares references |

| `x in dict` | `map.containsKey(x)` |
| `d[k]` raises KeyError | `map.get(k)` returns `null` |
| `d.get(k, 0)` | `map.getOrDefault(k, 0)` |

| `-7 // 2 == -4` | `-7 / 2 == -3`; use `Math.floorDiv` |
| `-7 % 2 == 1` | `-7 % 2 == -1`; use `Math.floorMod` |
| unbounded ints | `int` overflows silently — cast to `long` |

#### 1. [Two Sum](https://leetcode.com/problems/two-sum/) [E]

Description: Find two indices whose values add up to a target.

Idea: Keep a hash map `value -> index`; for each number `x`, check whether `target - x` was seen before.

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> index = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (index.containsKey(need)) return new int[]{index.get(need), i};
            index.put(nums[i], i);
        }
        return new int[0];
    }
}
// Time: O(n), Space: O(n)
```

#### 217. [Contains Duplicate](https://leetcode.com/problems/contains-duplicate/) [E]

Description: Determine if any value appears at least twice in an array.

Idea: Track seen values in a set. `HashSet.add` returns `false` when the value is already present, so the check and the insert are one call.

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int x : nums) {
            if (!seen.add(x)) return true;
        }
        return false;
    }
}
// Time: O(n), Space: O(n)
```

#### 242. [Valid Anagram](https://leetcode.com/problems/valid-anagram/) [E]

Description: Check whether two strings are permutations of each other.

Idea: Two strings are anagrams iff their character counts match. Java has no `Counter`, but a 26-slot array is faster anyway.

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i) - 'a']++;
            cnt[t.charAt(i) - 'a']--;
        }
        for (int c : cnt) if (c != 0) return false;
        return true;
    }
}
// Time: O(n), Space: O(1) for a fixed alphabet
```

#### 49. [Group Anagrams](https://leetcode.com/problems/group-anagrams/) [M]

Description: Group a list of strings into collections of anagrams.

Idea: Use a hash map keyed by a canonical signature for each word. Java arrays hash by identity, so serialize the 26-count into a `String` key instead of using the array directly.

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();
        for (String s : strs) {
            int[] counts = new int[26];
            for (char ch : s.toCharArray()) counts[ch - 'a']++;

            StringBuilder key = new StringBuilder();
            for (int c : counts) key.append(c).append('#');

            groups.computeIfAbsent(key.toString(), k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(groups.values());
    }
}
// Time: O(n * k) where k is word length, Space: O(n * k)
```

#### 347. [Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/) [M]

Description: Return the k most frequent elements from an array.

##### Approach 1: Bucket sort

Idea: Count frequencies, then bucket numbers by frequency and scan buckets from high to low. Same frequency means same bucket.

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int n : nums) freq.merge(n, 1, Integer::sum);

        List<Integer>[] buckets = new List[nums.length + 1];
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            int c = e.getValue();
            if (buckets[c] == null) buckets[c] = new ArrayList<>();
            buckets[c].add(e.getKey());
        }

        int[] res = new int[k];
        int idx = 0;
        for (int c = buckets.length - 1; c > 0 && idx < k; c--) {
            if (buckets[c] == null) continue;
            for (int num : buckets[c]) {
                res[idx++] = num;
                if (idx == k) break;
            }
        }
        return res;
    }
}
// Time: O(n), Space: O(n)
```

##### Approach 2: Min-heap of size `k`

Idea: Keep only the `k` most frequent entries in a min-heap ordered by count.

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int n : nums) freq.merge(n, 1, Integer::sum);

        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[1] - b[1]);
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            heap.offer(new int[]{e.getKey(), e.getValue()});
            if (heap.size() > k) heap.poll();
        }

        int[] res = new int[k];
        for (int i = 0; i < k; i++) res[i] = heap.poll()[0];
        return res;
    }
}
// Time: O(n log k), Space: O(n)
```

<a id="lc-0238"></a>

#### 238. [Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/) [M]

Description: For each index, compute the product of all other elements without division.

##### Approach 1: Two passes, output array as scratch

Idea: Build prefix products left-to-right into `res`, then multiply by suffix products right-to-left.

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];

        int pre = 1;
        for (int i = 0; i < n; i++) {
            res[i] = pre;
            pre *= nums[i];
        }

        int suf = 1;
        for (int i = n - 1; i >= 0; i--) {
            res[i] *= suf;
            suf *= nums[i];
        }
        return res;
    }
}
// Time: O(n), Space: O(1) extra (not counting the output array)
```

##### Approach 2: Explicit prefix and suffix arrays

Idea: Same recurrence, materialized. Easier to explain on a whiteboard.

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] pref = new int[n];
        int[] suff = new int[n];
        int[] res = new int[n];

        pref[0] = 1;
        suff[n - 1] = 1;
        for (int i = 1; i < n; i++) pref[i] = nums[i - 1] * pref[i - 1];
        for (int i = n - 2; i >= 0; i--) suff[i] = nums[i + 1] * suff[i + 1];
        for (int i = 0; i < n; i++) res[i] = pref[i] * suff[i];
        return res;
    }
```

#### 36. [Valid Sudoku](https://leetcode.com/problems/valid-sudoku/) [M]

Description: Validate a partially filled Sudoku board without violating row, column, or 3x3 box constraints.

##### Approach 1: Hash sets per row / column / box

Idea: Keep one set per row, column, and box. When a digit repeats in any of them, the board is invalid immediately.

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        Set<Character>[] rows = new Set[9];
        Set<Character>[] cols = new Set[9];
        Set<Character>[] boxes = new Set[9];
        for (int i = 0; i < 9; i++) {
            rows[i] = new HashSet<>();
            cols[i] = new HashSet<>();
            boxes[i] = new HashSet<>();

                if (val == '.') continue;
                int box = (r / 3) * 3 + c / 3;
                if (!rows[r].add(val) || !cols[c].add(val) || !boxes[box].add(val)) {
                    return false;
                }
            }
        }
        return true;
    }
}
// Time: O(81), Space: O(81)
```

##### Approach 2: Bitmasks

Idea: Nine digits fit in an `int`, so each row/column/box is one bitmask. No allocation at all.

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        int[] rows = new int[9], cols = new int[9], boxes = new int[9];

        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                if (board[r][c] == '.') continue;
                int bit = 1 << (board[r][c] - '1');

                if ((rows[r] & bit) != 0 || (cols[c] & bit) != 0 || (boxes[box] & bit) != 0) {
                    return false;
                }
                rows[r] |= bit;
                cols[c] |= bit;
                boxes[box] |= bit;
            }
        }
        return true;
    }
}
// Time: O(81), Space: O(1)
```

#### 128. [Longest Consecutive Sequence](https://leetcode.com/problems/longest-consecutive-sequence/) [M]

Description: Find the length of the longest run of consecutive integers in an array.

##### Approach 1: Hash set, count only from run heads

Idea: Put everything in a set; only start counting from numbers that have no predecessor (`x-1` not in the set), so each run is walked once.

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> s = new HashSet<>();
        for (int x : nums) s.add(x);

        int best = 0;
        for (int x : s) {
            if (s.contains(x - 1)) continue;   // not the start of a run
            int y = x;
            while (s.contains(y)) y++;
            best = Math.max(best, y - x);
        }
        return best;
    }
}
// Time: O(n) average, Space: O(n)
```

#### 15. [3Sum](https://leetcode.com/problems/3sum/) [M]

Description: Find unique triplets in an array which sum to zero.

Idea: Sort; fix `i`, then run a 2-sum with two pointers on `i+1..n-1`, skipping duplicates at every level so no result repeats.

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n - 2; i++) {
            if (nums[i] > 0) break;                        // sorted: no way back to 0
            if (i > 0 && nums[i] == nums[i - 1]) continue; // skip duplicate anchors

            int l = i + 1, r = n - 1;
            while (l < r) {
                int s = nums[i] + nums[l] + nums[r];
                if (s < 0) {
                    l++;
                } else if (s > 0) {
                    r--;
                } else {
                    res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    l++;
                    r--;
                    while (l < r && nums[l] == nums[l - 1]) l++;
                    while (l < r && nums[r] == nums[r + 1]) r--;
                }
            }
        }
        return res;
    }
}
```

#### 42. [Trapping Rain Water](https://leetcode.com/problems/trapping-rain-water/) [H]

Description: Compute how much rain water can be trapped between elevation bars.

##### Approach 1: Two pointers with running maxima

Idea: Water at an index depends on `min(maxLeft, maxRight)`. If `height[l] < height[r]`, the right side is already a sufficient boundary, so water at `l` depends only on `leftMax`. Symmetric on the other side.

```java
class Solution {
    public int trap(int[] height) {
        int l = 0, r = height.length - 1;
        int leftMax = 0, rightMax = 0, water = 0;

        while (l < r) {
            if (height[l] < height[r]) {
                leftMax = Math.max(leftMax, height[l]);
                water += leftMax - height[l];
                l++;
            } else {
                rightMax = Math.max(rightMax, height[r]);
                water += rightMax - height[r];
                r--;
            }
        }
        return water;
    }
}
// Time: O(n), Space: O(1)
```

##### Approach 2: Prefix maxima arrays

Idea: Precompute `leftMax[i]` and `rightMax[i]`, then each column contributes `min(leftMax, rightMax) - height`.

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n == 0) return 0;

        int[] leftMax = new int[n], rightMax = new int[n];
        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) leftMax[i] = Math.max(leftMax[i - 1], height[i]);
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) rightMax[i] = Math.max(rightMax[i + 1], height[i]);

        int res = 0;
        for (int i = 0; i < n; i++) res += Math.min(leftMax[i], rightMax[i]) - height[i];
        return res;
    }
}
// Time: O(n), Space: O(n)
```

##### Approach 3: Monotonic stack

Idea: Pop a bar when a taller bar arrives; the popped bar is the floor of a horizontal water slab bounded by its two taller neighbours.

```java
class Solution {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>();
        int res = 0;

        for (int i = 0; i < height.length; i++) {
            while (!stack.isEmpty() && height[i] >= height[stack.peek()]) {
                int mid = height[stack.pop()];
                if (stack.isEmpty()) break;
                int h = Math.min(height[i], height[stack.peek()]) - mid;
                int w = i - stack.peek() - 1;
                res += h * w;
            }
            stack.push(i);
        }
        return res;
    }
}
// Time: O(n), Space: O(n)
```

##### Approach 1: Fixed-size sliding window over two count arrays

Idea: Because lowercase letters are bounded, compare two frequency arrays over a window of length `s1.length()`.

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int n = s1.length(), m = s2.length();
        if (n > m) return false;

        int[] need = new int[26], window = new int[26];
        for (int i = 0; i < n; i++) {
            need[s1.charAt(i) - 'a']++;
            window[s2.charAt(i) - 'a']++;
        }
        if (Arrays.equals(need, window)) return true;

        for (int i = n; i < m; i++) {
            window[s2.charAt(i) - 'a']++;
            window[s2.charAt(i - n) - 'a']--;
            if (Arrays.equals(need, window)) return true;
        }
        return false;
    }
}
// Time: O(26 * n), Space: O(1)
```

##### Approach 2: Matched-letter counter, O(1) per step

Idea: Maintain how many of the 26 letters currently have the exact required count, so no array comparison is needed per slide.

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int n = s1.length(), m = s2.length();
        if (n > m) return false;

        int[] need = new int[26], window = new int[26];
        for (int i = 0; i < n; i++) {
            need[s1.charAt(i) - 'a']++;
            window[s2.charAt(i) - 'a']++;
        }

        int matches = 0;
        for (int i = 0; i < 26; i++) if (need[i] == window[i]) matches++;

        for (int r = n; r < m; r++) {
            if (matches == 26) return true;

            int in = s2.charAt(r) - 'a';
            window[in]++;
            if (window[in] == need[in]) matches++;
            else if (window[in] == need[in] + 1) matches--;

            int out = s2.charAt(r - n) - 'a';
            window[out]--;
            if (window[out] == need[out]) matches++;
            else if (window[out] == need[out] - 1) matches--;
        }
        return matches == 26;
    }
}
// Time: O(n + m), Space: O(1)
```

#### 76. [Minimum Window Substring](https://leetcode.com/problems/minimum-window-substring/) [H]

Description: Find the smallest substring that contains all characters of a target string.

Idea: Sliding window with counts; expand right until all required chars are satisfied, then shrink left while staying valid. `formed` counts how many distinct required chars have hit their quota.

```java
class Solution {
    public String minWindow(String s, String t) {
        if (s.isEmpty() || t.isEmpty()) return "";

        Map<Character, Integer> need = new HashMap<>();
        for (char ch : t.toCharArray()) need.merge(ch, 1, Integer::sum);

        Map<Character, Integer> have = new HashMap<>();
        int required = need.size(), formed = 0;
        int bestLen = Integer.MAX_VALUE, bestL = 0;
        int l = 0;

        for (int r = 0; r < s.length(); r++) {
            char ch = s.charAt(r);
            if (need.containsKey(ch)) {
                have.merge(ch, 1, Integer::sum);
                if (have.get(ch).intValue() == need.get(ch).intValue()) formed++;
            }

            while (formed == required && l <= r) {
                if (r - l + 1 < bestLen) {
                    bestLen = r - l + 1;
                    bestL = l;
                }
                char leftCh = s.charAt(l);
                if (need.containsKey(leftCh)) {
                    have.merge(leftCh, -1, Integer::sum);
                    if (have.get(leftCh) < need.get(leftCh)) formed--;
                }
                l++;
            }
        }
        return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestL, bestL + bestLen);
    }
}
// Time: O(|s| + |t|), Space: O(k) distinct chars in t
```

⚠️ `have.get(ch) == need.get(ch)` compares `Integer` references and breaks above 127. Unbox with `.intValue()` (or compare `int` locals).

#### 239. [Sliding Window Maximum](https://leetcode.com/problems/sliding-window-maximum/) [H]

Description: Return the maximum value in every sliding window of size `k`.

##### Approach 1: Monotonic deque

Idea: Maintain indices in decreasing value order. The deque front is always the maximum for the current window; indices that fall out of the window are dropped from the front.

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] ans = new int[n - k + 1];
        Deque<Integer> dq = new ArrayDeque<>();   // stores indices

        for (int i = 0; i < n; i++) {
            while (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();
            while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) dq.pollLast();
            dq.offerLast(i);
            if (i >= k - 1) ans[i - k + 1] = nums[dq.peekFirst()];
        }
        return ans;
    }
}
// Time: O(n), Space: O(k)
```

##### Approach 2: Max-heap with lazy deletion

Idea: Push `(value, index)`, and discard heap-top entries whose index has expired. Java's comparator gives a real max-heap, so no value negation is needed.

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] res = new int[n - k + 1];
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> b[0] - a[0]);

        for (int i = 0; i < n; i++) {
            heap.offer(new int[]{nums[i], i});
            while (heap.peek()[1] <= i - k) heap.poll();
            if (i >= k - 1) res[i - k + 1] = heap.peek()[0];
        }
        return res;
    }
}
// Time: O(n log n), Space: O(n)
```

##### Approach 1: Store value with running minimum

Idea: Each stack frame stores both the pushed value and the minimum seen up to that point.

```java
        stack.push(new int[]{val, curMin});
    }

    public void pop() { stack.pop(); }

    public int top() { return stack.peek()[0]; }

    public int getMin() { return stack.peek()[1]; }
}
```

##### Approach 2: Single stack of deltas

Idea: Store `val - min` instead of `val`. A negative entry means this push lowered the minimum, so popping it restores the previous minimum. Uses `long` because the delta can overflow `int`.

```java
class MinStack {
    private final Deque<Long> stack = new ArrayDeque<>();
    private long min;

    public MinStack() {}

    public void push(int val) {
        if (stack.isEmpty()) {
            stack.push(0L);
            min = val;
        } else {
            stack.push(val - min);
            if (val < min) min = val;
        }
    }

    public void pop() {
        long popped = stack.pop();
        if (popped < 0) min = min - popped;
    }

    public int top() {
        long t = stack.peek();
        return (int) (t > 0 ? t + min : min);
    }

    public int getMin() { return (int) min; }
}
// Time: O(1) per operation, Space: O(n)
```

#### 150. [Evaluate Reverse Polish Notation](https://leetcode.com/problems/evaluate-reverse-polish-notation/) [M]

Description: Evaluate an arithmetic expression written in Reverse Polish Notation.

Idea: Push numbers. When you see an operator, pop the last two operands, evaluate, and push the result back. Java's `int` division already truncates toward zero, which is exactly what the problem wants (Python needed `int(a / b)`).

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (String token : tokens) {
            switch (token) {
                case "+" -> stack.push(stack.pop() + stack.pop());
                case "*" -> stack.push(stack.pop() * stack.pop());
                case "-" -> {
                    int b = stack.pop(), a = stack.pop();
                    stack.push(a - b);

                case "/" -> {
                    int b = stack.pop(), a = stack.pop();
                    stack.push(a / b);
                }
                default -> stack.push(Integer.parseInt(token));
            }
        }
        return stack.pop();
    }
}
```

#### 22. [Generate Parentheses](https://leetcode.com/problems/generate-parentheses/) [M]

Description: Generate all valid combinations of `n` pairs of parentheses.

##### Approach 1: Backtracking with open/close counts

Idea: You can place `(` while openings remain, and `)` only when it will not invalidate the prefix (`closed < opened`).

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> ans = new ArrayList<>();
        dfs(0, 0, n, new StringBuilder(), ans);
        return ans;
    }

    private void dfs(int opened, int closed, int n, StringBuilder path, List<String> ans) {
        if (path.length() == 2 * n) {
            ans.add(path.toString());
            return;
        }
        if (opened < n) {
            path.append('(');
            dfs(opened + 1, closed, n, path, ans);
            path.deleteCharAt(path.length() - 1);
        }
        if (closed < opened) {
            path.append(')');
            dfs(opened, closed + 1, n, path, ans);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
// Time: O(Catalan(n) * n), Space: O(n) recursion
```

##### Approach 2: DP over pair counts

Idea: Every valid string of `k` pairs is `"(" + inner + ")" + rest` where `inner` uses `i` pairs and `rest` uses `k-i-1`.

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<List<String>> dp = new ArrayList<>();
        dp.add(List.of(""));

        for (int k = 1; k <= n; k++) {
            List<String> cur = new ArrayList<>();
            for (int i = 0; i < k; i++) {
                for (String left : dp.get(i)) {
                    for (String right : dp.get(k - i - 1)) {
                        cur.add("(" + left + ")" + right);
                    }
                }
            }
            dp.add(cur);
        }
        return dp.get(n);
    }
}
// Time: O(Catalan(n) * n), Space: O(Catalan(n) * n)
```

#### 739. [Daily Temperatures](https://leetcode.com/problems/daily-temperatures/) [M]

Description: For each day, return how many days you must wait until a warmer temperature.

Idea: Monotonic decreasing stack of indices whose answer has not been found yet. Resolve them when a hotter day arrives.

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int[] ans = new int[temperatures.length];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < temperatures.length; i++) {
            while (!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]) {
                int j = stack.pop();
                ans[j] = i - j;
            }
            stack.push(i);
        }
        return ans;
    }
}
```

#### 853. [Car Fleet](https://leetcode.com/problems/car-fleet/) [M]

Description: Count how many car fleets reach the destination.

Idea: Process cars from nearest to the target backward. A car that would arrive later than the fleet ahead of it can never catch up, so it starts a new fleet.

```java
class Solution {

        int n = position.length;
        int[][] cars = new int[n][2];
        for (int i = 0; i < n; i++) cars[i] = new int[]{position[i], speed[i]};
        Arrays.sort(cars, (a, b) -> b[0] - a[0]);          // nearest to target first

        int fleets = 0;
        double slow = 0.0;
        for (int[] car : cars) {
            double t = (double) (target - car[0]) / car[1];
            if (t > slow) {
                fleets++;
                slow = t;
            }
        }
        return fleets;
    }
}
// Time: O(n log n), Space: O(n)
```

#### 84. [Largest Rectangle in Histogram](https://leetcode.com/problems/largest-rectangle-in-histogram/) [H]

Description: Find the area of the largest rectangle in a histogram.

Idea: Monotonic increasing stack of `(startIndex, height)`. When a shorter bar arrives, finalize every rectangle that must end before this index, and inherit the leftmost popped start so the new bar extends back as far as it can.

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        Deque<int[]> stack = new ArrayDeque<>();   // {startIndex, height}
        int best = 0;

        for (int i = 0; i < heights.length; i++) {
            int start = i;
            while (!stack.isEmpty() && stack.peek()[1] > heights[i]) {
                int[] top = stack.pop();
                best = Math.max(best, top[1] * (i - top[0]));
                start = top[0];
            }
            stack.push(new int[]{start, heights[i]});
        }

        int n = heights.length;
        for (int[] rem : stack) best = Math.max(best, rem[1] * (n - rem[0]));
        return best;
    }
}
// Time: O(n), Space: O(n)
```

##### Approach 1: Binary search over the flattened index space

Idea: Treat the matrix as one sorted array of length `rows * cols` and map a 1-D midpoint back to `(row, col)`.

```java

            int mid = left + (right - left) / 2;
            int value = matrix[mid / cols][mid % cols];
            if (value == target) return true;
            if (value < target) left = mid + 1;
            else right = mid - 1;
        }
        return false;
    }
}
```

```java
            if (matrix[row][m] < target) l = m + 1;

        }
```

```java
            else left = mid + 1;
```

##### Approach 1: One pass, decide which half is sorted

Idea: At each step exactly one half is sorted. Check whether the target lies inside that sorted half; if it does, recurse there, otherwise the other half.

```java
class Solution {
    public int search(int[] nums, int target) {
        int l = 0, r = nums.length - 1;

        while (l <= r) {
            int m = l + (r - l) / 2;
            if (nums[m] == target) return m;

            if (nums[l] <= nums[m]) {                        // left half sorted
                if (nums[l] <= target && target < nums[m]) r = m - 1;
                else l = m + 1;
            } else {                                          // right half sorted
                if (nums[m] < target && target <= nums[r]) l = m + 1;
                else r = m - 1;
            }
        }
        return -1;
    }
}
// Time: O(log n), Space: O(1)
```

Idea: Locate the rotation point first (LC 153), pick the side that can contain the target, and run a textbook binary search there.

```java
        r = nums.length - 1;
```

Description: Support setting values by timestamp and retrieving the latest value at or before a query timestamp.

##### Approach 1: Append + binary search

Idea: Timestamps arrive in increasing order, so each key's list is already sorted; binary search for the rightmost timestamp `<= query`.

```java
class TimeMap {
    private final Map<String, List<int[]>> times = new HashMap<>();   // key -> {timestamp, valueIndex}
    private final Map<String, List<String>> vals = new HashMap<>();

    public TimeMap() {}

    public void set(String key, String value, int timestamp) {
        List<String> vs = vals.computeIfAbsent(key, k -> new ArrayList<>());
        times.computeIfAbsent(key, k -> new ArrayList<>()).add(new int[]{timestamp, vs.size()});
        vs.add(value);

        List<int[]> arr = times.get(key);
        if (arr == null) return "";

        int left = 0, right = arr.size() - 1, ans = -1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (arr.get(mid)[0] <= timestamp) {
                ans = arr.get(mid)[1];
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ans < 0 ? "" : vals.get(key).get(ans);
    }
}
```

#### 4. [Median of Two Sorted Arrays](https://leetcode.com/problems/median-of-two-sorted-arrays/) [H]

Description: Find the median of two sorted arrays in logarithmic time.

Idea: Binary search the partition of the **smaller** array so the combined left half holds exactly half the elements and every left value is `<=` every right value.

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        if (nums1.length > nums2.length) return findMedianSortedArrays(nums2, nums1);

        int x = nums1.length, y = nums2.length;
        int left = 0, right = x;

        while (left <= right) {
            int partX = left + (right - left) / 2;
            int partY = (x + y + 1) / 2 - partX;

            int maxLeftX  = partX == 0 ? Integer.MIN_VALUE : nums1[partX - 1];
            int minRightX = partX == x ? Integer.MAX_VALUE : nums1[partX];
            int maxLeftY  = partY == 0 ? Integer.MIN_VALUE : nums2[partY - 1];
            int minRightY = partY == y ? Integer.MAX_VALUE : nums2[partY];

            if (maxLeftX <= minRightY && maxLeftY <= minRightX) {
                if ((x + y) % 2 == 1) return Math.max(maxLeftX, maxLeftY);
                return (Math.max(maxLeftX, maxLeftY) + Math.min(minRightX, minRightY)) / 2.0;
            }
            if (maxLeftX > minRightY) right = partX - 1;
            else left = partX + 1;
        }
        return 0.0;
    }
}
// Time: O(log(min(m, n))), Space: O(1)
```

#### 287. [Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/) [M]

##### Approach 1: Floyd cycle detection

Idea: Interpret `nums[i]` as a next pointer. Since values lie in `[1, n]` and there are `n+1` slots, the functional graph must contain a cycle, and its entry point is the duplicate.

```java
class Solution {

        int slow = nums[0], fast = nums[0];
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        slow = nums[0];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }
        return slow;
    }
}
// Time: O(n), Space: O(1)
```

Idea: For a candidate `mid`, count how many values are `<= mid`. If that count exceeds `mid`, the duplicate is in the lower half.

```java
class Solution {
    public int findDuplicate(int[] nums) {
        int low = 1, high = nums.length - 1;
        while (low < high) {
            int mid = low + (high - low) / 2;
            int lessOrEqual = 0;
            for (int num : nums) if (num <= mid) lessOrEqual++;

            if (lessOrEqual <= mid) low = mid + 1;
            else high = mid;
        }
        return low;
    }
}
// Time: O(n log n), Space: O(1)
```

#### 146. [LRU Cache](https://leetcode.com/problems/lru-cache/) [M]

Description: Design an LRU cache with O(1) average `get` and `put`.

##### Approach 1: `LinkedHashMap` in access order

Idea: `LinkedHashMap` with `accessOrder = true` reorders on every `get`, and overriding `removeEldestEntry` evicts automatically. This is Java's built-in answer to Python's `OrderedDict`.

```java
class LRUCache extends LinkedHashMap<Integer, Integer> {
    private final int capacity;

    public LRUCache(int capacity) {
        super(capacity, 0.75f, true);          // true = access order
        this.capacity = capacity;
    }

    public int get(int key) {
        return super.getOrDefault(key, -1);
    }

    public void put(int key, int value) {
        super.put(key, value);
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        return size() > capacity;
    }
}
// Time: O(1) average per operation, Space: O(capacity)
```

##### Approach 2: Hash map + doubly-linked list (write it yourself)

Idea: What an interviewer usually wants. Sentinel head/tail nodes remove every null check from the splice logic.

```java
class LRUCache {
    private static class Node {
        int key, val;
        Node prev, next;
        Node(int key, int val) { this.key = key; this.val = val; }
    }

    private final int cap;
    private final Map<Integer, Node> cache = new HashMap<>();
    private final Node head = new Node(0, 0);   // most recent side
    private final Node tail = new Node(0, 0);   // least recent side

    public LRUCache(int capacity) {
        this.cap = capacity;
        head.next = tail;
        tail.prev = head;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void addFront(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    public int get(int key) {
        Node node = cache.get(key);
        if (node == null) return -1;
        remove(node);
        addFront(node);
        return node.val;
    }

    public void put(int key, int value) {
        Node node = cache.get(key);
        if (node != null) {
            node.val = value;
            remove(node);
            addFront(node);
            return;
        }
        node = new Node(key, value);
        cache.put(key, node);
        addFront(node);
        if (cache.size() > cap) {
            Node lru = tail.prev;
            remove(lru);
            cache.remove(lru.key);
        }
    }
}
// Time: O(1) per operation, Space: O(capacity)
```

#### 23. [Merge K Sorted Lists](https://leetcode.com/problems/merge-k-sorted-lists/) [H]

Description: Merge k sorted linked lists into one sorted list efficiently.

##### Approach 1: Min-heap of the current heads

Idea: Always pop the smallest current head among the `k` lists. Java compares nodes with an explicit comparator, so no tie-breaker index is needed (Python needed one because tuples fall through to comparing nodes).

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        PriorityQueue<ListNode> heap = new PriorityQueue<>((a, b) -> a.val - b.val);
        for (ListNode node : lists) if (node != null) heap.offer(node);

        ListNode dummy = new ListNode();
        ListNode cur = dummy;
        while (!heap.isEmpty()) {
            ListNode node = heap.poll();
            cur.next = node;
            cur = cur.next;
            if (node.next != null) heap.offer(node.next);
        }
        cur.next = null;
        return dummy.next;
    }
}
// Time: O(N log k) where N is total nodes, Space: O(k)
```

##### Approach 2: Divide and conquer

Idea: Recursively merge the left and right halves, then merge the two results — merge sort over the array of lists.

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists.length == 0) return null;
        return helper(lists, 0, lists.length - 1);
    }

    private ListNode helper(ListNode[] lists, int l, int r) {
        if (l > r) return null;
        if (l == r) return lists[l];
        int m = l + (r - l) / 2;
        return merge(helper(lists, l, m), helper(lists, m + 1, r));
    }

    private ListNode merge(ListNode a, ListNode b) {
        ListNode dummy = new ListNode();
        ListNode cur = dummy;
        while (a != null && b != null) {
            if (a.val <= b.val) { cur.next = a; a = a.next; }
            else { cur.next = b; b = b.next; }
            cur = cur.next;
        }
        cur.next = a != null ? a : b;
        return dummy.next;
    }
}
// Time: O(N log k), Space: O(log k) recursion stack
```

##### Approach 3: Pairwise rounds (iterative)

Idea: Merge lists in pairs, doubling the interval each round. Same complexity as approach 2 with no recursion.

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists.length == 0) return null;

        int interval = 1;
        while (interval < lists.length) {
            for (int i = 0; i + interval < lists.length; i += interval * 2) {
                lists[i] = merge(lists[i], lists[i + interval]);
            }
            interval *= 2;
        }
        return lists[0];
    }

    private ListNode merge(ListNode a, ListNode b) {
        ListNode dummy = new ListNode();
        ListNode cur = dummy;
        while (a != null && b != null) {
            if (a.val <= b.val) { cur.next = a; a = a.next; }
            else { cur.next = b; b = b.next; }
            cur = cur.next;
        }
        cur.next = a != null ? a : b;
        return dummy.next;
    }
}
// Time: O(N log k), Space: O(1) extra
```

#### 25. [Reverse Nodes in k-Group](https://leetcode.com/problems/reverse-nodes-in-k-group/) [H]

Description: Reverse linked-list nodes in groups of size `k`, leaving an incomplete suffix unchanged.

##### Approach 1: Recursive group reversal

Idea: First confirm `k` nodes exist. Then reverse that segment, and recursively attach the reversed remainder to the old head (which is now the group's tail).

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode cur = head;
        for (int i = 0; i < k; i++) {
            if (cur == null) return head;      // fewer than k nodes left
            cur = cur.next;
        }

        cur = head;
        ListNode prev = null;
        for (int i = 0; i < k; i++) {
            ListNode nxt = cur.next;
            cur.next = prev;
            prev = cur;
            cur = nxt;
        }
        head.next = reverseKGroup(cur, k);     // head is now the group tail
        return prev;
    }
}
// Time: O(n), Space: O(n / k) recursion stack
```

##### Approach 2: Iterative with a group anchor

Idea: Count nodes up front, then reverse `k` at a time, using `p0` as the node preceding the current group so reconnection is mechanical.

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        int n = 0;
        for (ListNode cur = head; cur != null; cur = cur.next) n++;

        ListNode dummy = new ListNode(0, head);
        ListNode p0 = dummy, prev = null, cur = head;

        while (n >= k) {
            n -= k;
            for (int i = 0; i < k; i++) {
                ListNode nxt = cur.next;
                cur.next = prev;
                prev = cur;
                cur = nxt;
            }
            ListNode groupTail = p0.next;      // old head == new tail
            groupTail.next = cur;
            p0.next = prev;
            p0 = groupTail;
        }
        return dummy.next;
    }
}
// Time: O(n), Space: O(1)
```

```java
class Solution {
```

```java
                cur = cur.left;

            prev = cur.val;
            cur = cur.right;
        }
```

```java
public class Codec {
    public String serialize(TreeNode root) {
        if (root == null) return "N";
        StringBuilder sb = new StringBuilder();
        Deque<TreeNode> q = new LinkedList<>();     // LinkedList: nulls allowed
        q.offer(root);

        while (!q.isEmpty()) {
            TreeNode node = q.poll();
            if (node == null) {
                sb.append("N,");
            } else {
                sb.append(node.val).append(',');
                q.offer(node.left);
                q.offer(node.right);
            }
        }
        return sb.toString();
    }

    public TreeNode deserialize(String data) {
        String[] vals = data.split(",");
        if (vals[0].equals("N")) return null;

        TreeNode root = new TreeNode(Integer.parseInt(vals[0]));
        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        int index = 1;

        while (!q.isEmpty()) {
            TreeNode node = q.poll();
            if (!vals[index].equals("N")) {
                node.left = new TreeNode(Integer.parseInt(vals[index]));
                q.offer(node.left);
            }
            index++;
            if (!vals[index].equals("N")) {
                node.right = new TreeNode(Integer.parseInt(vals[index]));
                q.offer(node.right);
            }
            index++;
        }
        return root;
    }
}
// Time: O(n) for both, Space: O(n)
```

⚠️ `ArrayDeque` rejects `null`, so the BFS serializer that enqueues null children must use `LinkedList`.

#### 208. [Implement Trie Prefix Tree](https://leetcode.com/problems/implement-trie-prefix-tree/) [M]

Description: Implement a trie supporting insert, search, and prefix queries.

Idea: Each node stores 26 child slots and an `end` flag. A fixed array beats a `HashMap` here because the alphabet is known and small.

```java
class Trie {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean end;
    }

    private final TrieNode root = new TrieNode();

    public Trie() {}

    public void insert(String word) {
        TrieNode node = root;
        for (char ch : word.toCharArray()) {
            int i = ch - 'a';
            if (node.children[i] == null) node.children[i] = new TrieNode();
            node = node.children[i];
        }
        node.end = true;
    }

    public boolean search(String word) {
        TrieNode node = walk(word);
        return node != null && node.end;
    }

    public boolean startsWith(String prefix) {
        return walk(prefix) != null;
    }

    private TrieNode walk(String s) {
        TrieNode node = root;
        for (char ch : s.toCharArray()) {
            node = node.children[ch - 'a'];
            if (node == null) return null;
        }
        return node;
    }
}
// Time: O(L) per operation, Space: O(total chars inserted)
```

#### 211. [Design Add And Search Words Data Structure](https://leetcode.com/problems/design-add-and-search-words-data-structure/) [M]

Description: Trie that supports adding words and searching with `.` wildcards.

Idea: Trie plus DFS. A `.` branches into every non-null child; a concrete letter follows a single edge.

```java
class WordDictionary {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean end;
    }

    private final TrieNode root = new TrieNode();

    public WordDictionary() {}

    public void addWord(String word) {
        TrieNode node = root;
        for (char ch : word.toCharArray()) {
            int i = ch - 'a';
            if (node.children[i] == null) node.children[i] = new TrieNode();
            node = node.children[i];
        }
        node.end = true;
    }

    public boolean search(String word) {
        return dfs(word, 0, root);
    }

    private boolean dfs(String word, int i, TrieNode node) {
        if (node == null) return false;
        if (i == word.length()) return node.end;

        char ch = word.charAt(i);
        if (ch == '.') {
            for (TrieNode child : node.children) {
                if (dfs(word, i + 1, child)) return true;
            }
            return false;
        }
        return dfs(word, i + 1, node.children[ch - 'a']);
    }
}
// Time: O(L) average, O(26^L) worst-case with many wildcards, Space: O(total chars)
```

#### 212. [Word Search II](https://leetcode.com/problems/word-search-ii/) [H]

Description: Find all words from a list that appear on a letter board using a trie + DFS.

Idea: Insert every word into a trie, then DFS from each cell walking the trie in lockstep. Storing the full word on terminal nodes avoids rebuilding strings. After exploring a node, drop it from its parent if it has become a leaf with no word — that prunes branches already fully harvested.

```java
class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        String word;                     // full word at terminal nodes
        int childCount;                  // number of non-null children
    }

    private char[][] board;
    private int rows, cols;
    private final List<String> res = new ArrayList<>();

    public List<String> findWords(char[][] board, String[] words) {
        this.board = board;
        this.rows = board.length;
        this.cols = board[0].length;

        TrieNode root = new TrieNode();
        for (String w : words) {
            TrieNode node = root;
            for (char ch : w.toCharArray()) {
                int i = ch - 'a';
                if (node.children[i] == null) {
                    node.children[i] = new TrieNode();
                    node.childCount++;
                }
                node = node.children[i];
            }
            node.word = w;
        }

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) dfs(r, c, root);
        }
        return res;
    }

    private void dfs(int r, int c, TrieNode node) {
        if (r < 0 || r >= rows || c < 0 || c >= cols) return;

        char ch = board[r][c];
        if (ch == '#') return;                       // already on the current path
        int i = ch - 'a';
        TrieNode nxt = node.children[i];
        if (nxt == null) return;

        if (nxt.word != null) {
            res.add(nxt.word);
            nxt.word = null;                         // avoid duplicates
        }

        board[r][c] = '#';
        dfs(r - 1, c, nxt);
        dfs(r + 1, c, nxt);
        dfs(r, c - 1, nxt);
        dfs(r, c + 1, nxt);
        board[r][c] = ch;

        if (nxt.childCount == 0 && nxt.word == null) {   // dead branch, prune it
            node.children[i] = null;
            node.childCount--;
        }
    }
}
// Time: O(R * C * 4^L) worst case, far less with trie pruning, Space: O(total chars)
```

#### 1046. [Last Stone Weight](https://leetcode.com/problems/last-stone-weight/) [E]

Description: Repeatedly smash the two heaviest stones until at most one remains.

Idea: A max-heap gives the two heaviest in O(log n). Java supports max-heaps directly via a comparator — the Python negation trick is unnecessary.

```java
class Solution {
    public int lastStoneWeight(int[] stones) {
        PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder());
        for (int s : stones) heap.offer(s);

        while (heap.size() > 1) {
            int a = heap.poll();
            int b = heap.poll();
            if (a != b) heap.offer(a - b);
        }
        return heap.isEmpty() ? 0 : heap.peek();
    }
}
```

##### Approach 2: Quickselect

Idea: Partition around a pivot and recurse only into the side containing the k-th index. Average O(n); the randomized pivot guards against sorted adversarial input.

```java
class Solution {
    private final Random rand = new Random();

    public int findKthLargest(int[] nums, int k) {
        int target = nums.length - k;                 // k-th largest == target-th smallest
        int lo = 0, hi = nums.length - 1;
        while (true) {
            int p = partition(nums, lo, hi);
            if (p == target) return nums[p];
            if (p < target) lo = p + 1;
            else hi = p - 1;
        }
    }

    private int partition(int[] a, int lo, int hi) {
        swap(a, hi, lo + rand.nextInt(hi - lo + 1));
        int pivot = a[hi], i = lo;
        for (int j = lo; j < hi; j++) {
            if (a[j] < pivot) swap(a, i++, j);
        }
        swap(a, i, hi);
        return i;
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
}
// Time: O(n) average, O(n^2) worst case, Space: O(1)
```

#### 621. [Task Scheduler](https://leetcode.com/problems/task-scheduler/) [M]

Description: Compute the least number of intervals required to execute all tasks with cooldown `n`.

##### Approach 1: Greedy counting formula

Idea: The tight lower bound comes from laying out the most frequent task into `maxFreq - 1` full blocks of width `n + 1`, plus one final row holding every task that ties for the maximum. If tasks are plentiful enough to fill all the idle slots, the answer is just the task count.

```java
class Solution {
    public int leastInterval(char[] tasks, int n) {
        int[] cnt = new int[26];
        for (char t : tasks) cnt[t - 'A']++;

        int maxFreq = 0;
        for (int c : cnt) maxFreq = Math.max(maxFreq, c);

        int maxCount = 0;
        for (int c : cnt) if (c == maxFreq) maxCount++;

        return Math.max(tasks.length, (maxFreq - 1) * (n + 1) + maxCount);
    }
}
// Time: O(n), Space: O(1)
```

##### Approach 2: Max-heap simulation with a cooldown queue

Idea: Run the clock. Each tick, execute the most frequent available task and park it in a cooldown queue until `time + n`. Slower, but it also produces the actual schedule.

```java
class Solution {
    public int leastInterval(char[] tasks, int n) {
        int[] cnt = new int[26];
        for (char t : tasks) cnt[t - 'A']++;

        PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder());
        for (int c : cnt) if (c > 0) heap.offer(c);

        Deque<int[]> cooldown = new ArrayDeque<>();   // {remainingCount, readyTime}
        int time = 0;

        while (!heap.isEmpty() || !cooldown.isEmpty()) {
            time++;
            if (heap.isEmpty()) {
                time = cooldown.peekFirst()[1];      // fast-forward through idle
            } else {
                int remaining = heap.poll() - 1;
                if (remaining > 0) cooldown.offerLast(new int[]{remaining, time + n});
            }
            if (!cooldown.isEmpty() && cooldown.peekFirst()[1] == time) {
                heap.offer(cooldown.pollFirst()[0]);
            }
        }
        return time;
    }
}
// Time: O(total * log 26), Space: O(26)
```

#### 355. [Design Twitter](https://leetcode.com/problems/design-twitter/) [M]

Description: Design Twitter with posting, following, unfollowing, and a 10-tweet news feed.

Idea: Store each user's tweets with a global timestamp. To build the feed, merge the latest tweet streams from followed users with a max-heap — this is "merge k sorted lists, take 10".

```java
class Twitter {
    private int time = 0;
    private final Map<Integer, List<int[]>> tweets = new HashMap<>();      // user -> {time, tweetId}
    private final Map<Integer, Set<Integer>> following = new HashMap<>();

    public Twitter() {}

    public void postTweet(int userId, int tweetId) {
        tweets.computeIfAbsent(userId, k -> new ArrayList<>()).add(new int[]{++time, tweetId});
    }

    public List<Integer> getNewsFeed(int userId) {
        Set<Integer> followed = following.computeIfAbsent(userId, k -> new HashSet<>());
        followed.add(userId);

        // {time, tweetId, ownerId, nextIndex}
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        for (int followee : followed) {
            List<int[]> posts = tweets.get(followee);
            if (posts == null || posts.isEmpty()) continue;
            int idx = posts.size() - 1;
            heap.offer(new int[]{posts.get(idx)[0], posts.get(idx)[1], followee, idx - 1});
        }

        List<Integer> feed = new ArrayList<>();
        while (!heap.isEmpty() && feed.size() < 10) {
            int[] top = heap.poll();
            feed.add(top[1]);
            int idx = top[3];
            if (idx >= 0) {
                int[] prev = tweets.get(top[2]).get(idx);
                heap.offer(new int[]{prev[0], prev[1], top[2], idx - 1});
            }
        }
        return feed;
    }

    public void follow(int followerId, int followeeId) {
        following.computeIfAbsent(followerId, k -> new HashSet<>()).add(followeeId);
    }

    public void unfollow(int followerId, int followeeId) {
        if (followerId == followeeId) return;
        Set<Integer> s = following.get(followerId);
        if (s != null) s.remove(followeeId);
    }
}
// Time: post O(1), follow/unfollow O(1), feed O((f + 10) log f), Space: O(tweets + follows)
```

#### 295. [Find Median From Data Stream](https://leetcode.com/problems/find-median-from-data-stream/) [H]

Description: Maintain a running median as numbers are added using two heaps.

Idea: A max-heap holds the lower half and a min-heap the upper half. Push into `small`, spill its top into `large`, then rebalance so `small` never has fewer elements than `large`. The median is either `small`'s top or the average of both tops.

```java
class MedianFinder {
    private final PriorityQueue<Integer> small = new PriorityQueue<>(Collections.reverseOrder());
    private final PriorityQueue<Integer> large = new PriorityQueue<>();

    public MedianFinder() {}

    public void addNum(int num) {
        small.offer(num);
        large.offer(small.poll());                    // keeps ordering invariant
        if (large.size() > small.size()) small.offer(large.poll());
    }

    public double findMedian() {
        if (small.size() > large.size()) return small.peek();
        return (small.peek() + large.peek()) / 2.0;
    }
}
// Time: O(log n) per insert, O(1) median, Space: O(n)
```

#### 78. [Subsets](https://leetcode.com/problems/subsets/) [M]

Description: Return all subsets of the input array.

##### Approach 1: Backtracking from a start index

Idea: Every state of `path` is already a valid subset, so record it on entry and then extend with each remaining element.

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), res);
        return res;
    }

    private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
        res.add(new ArrayList<>(path));            // COPY, not the live list
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);                     // choose
            dfs(nums, i + 1, path, res);           // explore
            path.remove(path.size() - 1);          // un-choose
        }
    }
}
// Time: O(n * 2^n), Space: O(n) recursion
```

Idea: Each new number doubles the answer set: keep every existing subset and add a copy extended by that number.

#### 39. [Combination Sum](https://leetcode.com/problems/combination-sum/) [M]

Description: Find all combinations of candidates that sum to target (reuse allowed).

Idea: DFS from a start index; recursing with the **same** `i` is what allows a candidate to be reused. Sorting lets you stop the loop as soon as a candidate exceeds the remainder.

```java
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> res = new ArrayList<>();
        dfs(candidates, 0, target, new ArrayList<>(), res);
        return res;
    }

    private void dfs(int[] nums, int start, int rem, List<Integer> cur, List<List<Integer>> res) {
        if (rem == 0) {
            res.add(new ArrayList<>(cur));
            return;
        }
        for (int i = start; i < nums.length; i++) {
            if (nums[i] > rem) break;              // sorted: nothing later fits either
            cur.add(nums[i]);
            dfs(nums, i, rem - nums[i], cur, res); // i, not i + 1 -> reuse allowed
            cur.remove(cur.size() - 1);
        }
    }
}
```

#### 79. [Word Search](https://leetcode.com/problems/word-search/) [M]

Description: Determine if a single word exists in a 2D board by backtracking.

Idea: Backtrack from each cell; mark visited cells in place with a sentinel during the current path and restore them on the way out — no separate visited matrix needed.

```java
class Solution {
    private char[][] board;
    private String word;
    private int rows, cols;

    public boolean exist(char[][] board, String word) {
        this.board = board;
        this.word = word;
        this.rows = board.length;
        this.cols = board[0].length;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (dfs(r, c, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs(int r, int c, int i) {
        if (i == word.length()) return true;
        if (r < 0 || r >= rows || c < 0 || c >= cols) return false;
        if (board[r][c] != word.charAt(i)) return false;

        char tmp = board[r][c];
        board[r][c] = '#';
        boolean found = dfs(r - 1, c, i + 1) || dfs(r + 1, c, i + 1)
                     || dfs(r, c - 1, i + 1) || dfs(r, c + 1, i + 1);
        board[r][c] = tmp;
        return found;
    }
}
// Time: O(R * C * 4^L) worst case, Space: O(L) recursion stack
```

#### 131. [Palindrome Partitioning](https://leetcode.com/problems/palindrome-partitioning/) [M]

Description: Partition a string so every piece is a palindrome.

Idea: Try every possible end index, but recurse only when the current substring is a palindrome. Precomputing `isPal[i][j]` with interval DP replaces Python's `@cache`.

```java
class Solution {
    private boolean[][] isPal;
    private String s;

    public List<List<String>> partition(String s) {
        this.s = s;
        int n = s.length();
        isPal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                isPal[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 2 || isPal[i + 1][j - 1]);
            }
        }

        List<List<String>> res = new ArrayList<>();
        dfs(0, new ArrayList<>(), res);
        return res;
    }

    private void dfs(int i, List<String> cur, List<List<String>> res) {
        if (i == s.length()) {
            res.add(new ArrayList<>(cur));
            return;
        }
        for (int j = i; j < s.length(); j++) {
            if (!isPal[i][j]) continue;
            cur.add(s.substring(i, j + 1));
            dfs(j + 1, cur, res);
            cur.remove(cur.size() - 1);
        }
    }
```

Idea: Each digit contributes a small branching factor, so a simple recursive product works. Passing an immutable `String` down means there is nothing to un-choose on the way back.

```java
        {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

            return;

        }
    }
```

#### 51. [N-Queens](https://leetcode.com/problems/n-queens/) [H]

Description: Place `n` queens on an `n x n` board so that no two queens attack each other.

Idea: Place queens row by row. Track blocked columns and both diagonals (`r - c` and `r + c`) in sets for O(1) placement checks. `r - c` can be negative, so shift it by `n` when using an array.

```java
class Solution {
    public List<List<String>> solveNQueens(int n) {
        boolean[] cols = new boolean[n];
        boolean[] diag1 = new boolean[2 * n];      // r - c + n
        boolean[] diag2 = new boolean[2 * n];      // r + c

        char[][] board = new char[n][n];
        for (char[] row : board) Arrays.fill(row, '.');

        List<List<String>> ans = new ArrayList<>();
        dfs(0, n, cols, diag1, diag2, board, ans);
        return ans;
    }

    private void dfs(int r, int n, boolean[] cols, boolean[] diag1, boolean[] diag2,
                     char[][] board, List<List<String>> ans) {
        if (r == n) {
            List<String> snapshot = new ArrayList<>(n);
            for (char[] row : board) snapshot.add(new String(row));
            ans.add(snapshot);
            return;
        }
        for (int c = 0; c < n; c++) {
            if (cols[c] || diag1[r - c + n] || diag2[r + c]) continue;

            cols[c] = diag1[r - c + n] = diag2[r + c] = true;
            board[r][c] = 'Q';
            dfs(r + 1, n, cols, diag1, diag2, board, ans);
            board[r][c] = '.';
            cols[c] = diag1[r - c + n] = diag2[r + c] = false;
        }
    }
}
// Time: O(n!), Space: O(n^2)
```

#### 200. [Number of Islands](https://leetcode.com/problems/number-of-islands/) [M]

Description: Count connected groups of `'1'`s (islands) in a grid.

##### Approach 1: DFS flood-fill

Idea: For every land cell, flood-fill (turn `'1'` into `'0'`) to mark the entire island, so each island is counted exactly once.

```java
class Solution {
    public int numIslands(char[][] grid) {
        if (grid.length == 0) return 0;
        int islands = 0;

        for (int r = 0; r < grid.length; r++) {
            for (int c = 0; c < grid[0].length; c++) {
                if (grid[r][c] == '1') {
                    islands++;
                    dfs(grid, r, c);
                }
            }
        }
        return islands;
    }

    private void dfs(char[][] grid, int r, int c) {
        if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length || grid[r][c] != '1') return;
        grid[r][c] = '0';
        dfs(grid, r + 1, c);
        dfs(grid, r - 1, c);
        dfs(grid, r, c + 1);
        dfs(grid, r, c - 1);
    }
}
// Time: O(R * C), Space: O(R * C) recursion stack worst case
```

##### Approach 2: BFS flood-fill

Idea: Same flood-fill, iterative with a queue. Encode `(r, c)` as `r * cols + c` to avoid allocating a pair per cell.

```java
class Solution {
    private static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public int numIslands(char[][] grid) {
        if (grid.length == 0) return 0;
        int rows = grid.length, cols = grid[0].length, islands = 0;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] != '1') continue;
                islands++;
                grid[r][c] = '0';

                Deque<Integer> q = new ArrayDeque<>();
                q.offer(r * cols + c);
                while (!q.isEmpty()) {
                    int cell = q.poll();
                    int x = cell / cols, y = cell % cols;
                    for (int[] d : DIRS) {
                        int nx = x + d[0], ny = y + d[1];
                        if (nx < 0 || nx >= rows || ny < 0 || ny >= cols) continue;
                        if (grid[nx][ny] != '1') continue;
                        grid[nx][ny] = '0';
                        q.offer(nx * cols + ny);
                    }
                }
            }
        }
        return islands;
    }
}
// Time: O(R * C), Space: O(R * C) queue worst case
```

#### 133. [Clone Graph](https://leetcode.com/problems/clone-graph/) [M]

Description: Create a deep copy of an undirected graph.

##### Approach 1: DFS + hash map

Idea: Keep an `original -> clone` map. Registering the clone *before* recursing is what stops cycles from looping forever.

```java
class Solution {
    private final Map<Node, Node> clones = new HashMap<>();

    public Node cloneGraph(Node node) {
        if (node == null) return null;
        if (clones.containsKey(node)) return clones.get(node);

        Node copy = new Node(node.val);
        clones.put(node, copy);                     // register BEFORE recursing
        for (Node nei : node.neighbors) {
            copy.neighbors.add(cloneGraph(nei));
        }
        return copy;
    }
}
// Time: O(V + E), Space: O(V)
```

##### Approach 2: BFS + hash map

Idea: Build clones level by level, wiring edges as each original is dequeued.

```java
class Solution {
    public Node cloneGraph(Node node) {
        if (node == null) return null;

        Map<Node, Node> clones = new HashMap<>();
        clones.put(node, new Node(node.val));
        Deque<Node> q = new ArrayDeque<>();
        q.offer(node);

        while (!q.isEmpty()) {
            Node cur = q.poll();
            for (Node nei : cur.neighbors) {
                if (!clones.containsKey(nei)) {
                    clones.put(nei, new Node(nei.val));
                    q.offer(nei);
                }
                clones.get(cur).neighbors.add(clones.get(nei));
            }
        }
        return clones.get(node);
    }
}
// Time: O(V + E), Space: O(V)
```

```java
class Solution {
```

#### 994. [Rotting Oranges](https://leetcode.com/problems/rotting-oranges/) [M]

Description: Return the minimum minutes needed until all fresh oranges rot, or `-1` if impossible.

Idea: Multi-source BFS from every initially rotten orange, expanding exactly one minute per level. Counting fresh oranges up front makes the "impossible" check trivial.

```java
class Solution {
    private static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public int orangesRotting(int[][] grid) {
        int rows = grid.length, cols = grid[0].length;
        int fresh = 0, time = 0;
        Deque<int[]> q = new ArrayDeque<>();

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == 1) fresh++;
                else if (grid[r][c] == 2) q.offer(new int[]{r, c});
            }
        }

        while (!q.isEmpty() && fresh > 0) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                int[] cell = q.poll();
                for (int[] d : DIRS) {
                    int nr = cell[0] + d[0], nc = cell[1] + d[1];
                    if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
                    if (grid[nr][nc] != 1) continue;
                    grid[nr][nc] = 2;
                    fresh--;
                    q.offer(new int[]{nr, nc});
                }
            }
            time++;
        }
        return fresh == 0 ? time : -1;
    }
}
```

Idea: Reverse the flow. Start DFS from each ocean border moving only to equal-or-higher neighbours; the intersection of the two reachable sets is the answer.

```java
class Solution {

    private int rows, cols;
    private int[][] heights;

    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        this.heights = heights;
        rows = heights.length;
        cols = heights[0].length;

        boolean[][] pac = new boolean[rows][cols];
        boolean[][] atl = new boolean[rows][cols];

        for (int c = 0; c < cols; c++) {
            dfs(0, c, pac);
            dfs(rows - 1, c, atl);

        for (int r = 0; r < rows; r++) {
            dfs(r, 0, pac);
            dfs(r, cols - 1, atl);
        }

        List<List<Integer>> res = new ArrayList<>();
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (pac[r][c] && atl[r][c]) res.add(List.of(r, c));
            }
        }
        return res;
    }

    private void dfs(int r, int c, boolean[][] seen) {
        seen[r][c] = true;
        for (int[] d : DIRS) {
            int nr = r + d[0], nc = c + d[1];
            if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
            if (seen[nr][nc] || heights[nr][nc] < heights[r][c]) continue;
            dfs(nr, nc, seen);
        }
    }
}
```

#### 207. [Course Schedule](https://leetcode.com/problems/course-schedule/) [M]

Description: Determine if all courses can be finished given prerequisite pairs (cycle check).

##### Approach 1: DFS three-colour cycle detection

Idea: `0 = unvisited, 1 = visiting, 2 = done`. Reaching a `visiting` node means a back edge, i.e. a cycle. Marking `done` memoizes fully cleared subgraphs.

```java
class Solution {
    private static final int UNVISITED = 0, VISITING = 1, DONE = 2;

    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
        for (int[] p : prerequisites) graph.get(p[0]).add(p[1]);

        int[] state = new int[numCourses];
        for (int c = 0; c < numCourses; c++) {
            if (!dfs(c, graph, state)) return false;
        }
        return true;
    }

    private boolean dfs(int course, List<List<Integer>> graph, int[] state) {
        if (state[course] == VISITING) return false;
        if (state[course] == DONE) return true;

        state[course] = VISITING;
        for (int pre : graph.get(course)) {
            if (!dfs(pre, graph, state)) return false;
        }
        state[course] = DONE;
        return true;
    }
}
// Time: O(V + E), Space: O(V + E)
```

##### Approach 2: Kahn's algorithm (BFS topological sort)

Idea: Repeatedly take nodes with indegree 0 and remove their edges. If every course gets taken, there was no cycle.

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        int[] degree = new int[numCourses];
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());

        for (int[] p : prerequisites) {
            adj.get(p[0]).add(p[1]);
            degree[p[1]]++;
        }

        Deque<Integer> q = new ArrayDeque<>();
        for (int c = 0; c < numCourses; c++) if (degree[c] == 0) q.offer(c);

        int finished = 0;
        while (!q.isEmpty()) {
            int crs = q.poll();
            finished++;
            for (int nei : adj.get(crs)) {
                if (--degree[nei] == 0) q.offer(nei);
            }
        }
        return finished == numCourses;
    }
}
// Time: O(V + E), Space: O(V + E)
```

#### 210. [Course Schedule II](https://leetcode.com/problems/course-schedule-ii/) [M]

Description: Return one valid order to finish all courses, or `[]` if impossible.

Idea: Topological sort with indegrees. Edges point course -> prerequisite, so the order comes out prerequisite-last and gets reversed at the end. Fewer than `numCourses` processed means a cycle.

```java
class Solution {

        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());

        for (int[] p : prerequisites) {
            adj.get(p[0]).add(p[1]);
            degree[p[1]]++;

            int crs = q.poll();
            order[idx--] = crs;
            count++;
            for (int pre : adj.get(crs)) {
                if (--degree[pre] == 0) q.offer(pre);
            }
        }
        return count == numCourses ? order : new int[0];
    }
}
```

#### 684. [Redundant Connection](https://leetcode.com/problems/redundant-connection/) [M]

Description: Return the extra edge that creates a cycle in an otherwise tree-like graph.

Idea: Union-find with path compression and union by rank. If two endpoints already share a root, the current edge closes a cycle and is the answer.

```java
class Solution {
    private int[] parent;
    private int[] rank;

    public int[] findRedundantConnection(int[][] edges) {
        int n = edges.length + 1;
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        for (int[] e : edges) {
            if (!union(e[0], e[1])) return e;
        }
        return new int[0];
    }

    private int find(int x) {
        while (x != parent[x]) {
            parent[x] = parent[parent[x]];            // path halving
            x = parent[x];
        }
        return x;
    }

    private boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (rank[ra] < rank[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;
        if (rank[ra] == rank[rb]) rank[ra]++;
        return true;
    }
}
// Time: O(n * alpha(n)), Space: O(n)
```

```java
        words.add(beginWord);

        int L = beginWord.length();
        Map<String, List<String>> patterns = new HashMap<>();
        for (String word : words) {
            for (int i = 0; i < L; i++) {
                String pattern = word.substring(0, i) + '*' + word.substring(i + 1);
                patterns.computeIfAbsent(pattern, k -> new ArrayList<>()).add(word);
            }
        }

        Deque<String> q = new ArrayDeque<>();
        Set<String> seen = new HashSet<>();
        q.offer(beginWord);
        seen.add(beginWord);
        int dist = 1;

        while (!q.isEmpty()) {
            int size = q.size();
            for (int s = 0; s < size; s++) {
                String word = q.poll();
                if (word.equals(endWord)) return dist;

                for (int i = 0; i < L; i++) {
                    String key = word.substring(0, i) + '*' + word.substring(i + 1);
                    List<String> bucket = patterns.get(key);
                    if (bucket == null) continue;
                    for (String nei : bucket) {
                        if (seen.add(nei)) q.offer(nei);
                    }
                    bucket.clear();                   // never needed again
                }
            }
            dist++;
        }
        return 0;
    }
}
// Time: O(n * L^2), Space: O(n * L)
```

#### 332. [Reconstruct Itinerary](https://leetcode.com/problems/reconstruct-itinerary/) [H]

Description: Reconstruct the itinerary using all tickets exactly once, choosing the lexicographically smallest valid answer.

Idea: This is an Eulerian path (Hierholzer). Sort each destination list in reverse so removing the last element yields the smallest next airport; append airports post-order and reverse at the end.

```java
class Solution {
    public List<String> findItinerary(List<List<String>> tickets) {
        Map<String, List<String>> graph = new HashMap<>();
        for (List<String> t : tickets) {
            graph.computeIfAbsent(t.get(0), k -> new ArrayList<>()).add(t.get(1));
        }
        for (List<String> dests : graph.values()) {
            dests.sort(Comparator.reverseOrder());     // pop from the end == smallest
        }

        LinkedList<String> route = new LinkedList<>();
        dfs("JFK", graph, route);
        return route;
    }

    private void dfs(String airport, Map<String, List<String>> graph, LinkedList<String> route) {
        List<String> dests = graph.get(airport);
        while (dests != null && !dests.isEmpty()) {
            dfs(dests.remove(dests.size() - 1), graph, route);
        }
        route.addFirst(airport);                       // post-order, reversed in place
    }
}
// Time: O(E log E), Space: O(E)
```

#### 1584. [Min Cost to Connect All Points](https://leetcode.com/problems/min-cost-to-connect-all-points/) [M]

Description: Connect all points with minimum total Manhattan distance.

Idea: Prim's MST. The graph is complete, so the dense O(n²) Prim (no heap) is actually optimal: grow the tree one point at a time, always attaching the unused point with the cheapest current connection.

```java
class Solution {
    public int minCostConnectPoints(int[][] points) {
        int n = points.length;
        boolean[] used = new boolean[n];
        int[] minDist = new int[n];
        Arrays.fill(minDist, Integer.MAX_VALUE);
        minDist[0] = 0;
        int total = 0;

        for (int it = 0; it < n; it++) {
            int node = -1;
            for (int i = 0; i < n; i++) {
                if (!used[i] && (node == -1 || minDist[i] < minDist[node])) node = i;
            }

            used[node] = true;
            total += minDist[node];
            int x1 = points[node][0], y1 = points[node][1];

            for (int nei = 0; nei < n; nei++) {
                if (used[nei]) continue;
                int dist = Math.abs(x1 - points[nei][0]) + Math.abs(y1 - points[nei][1]);
                if (dist < minDist[nei]) minDist[nei] = dist;
            }
        }
        return total;
    }
}
// Time: O(n^2), Space: O(n)
```

#### 743. [Network Delay Time](https://leetcode.com/problems/network-delay-time/) [M]

Description: Compute the time needed for a signal to reach all nodes, or `-1` if some node is unreachable.

Idea: Dijkstra. Edge weights are non-negative, so the first time a node is popped its distance is final; a `dist` set doubles as the visited marker.

```java
class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        Map<Integer, List<int[]>> graph = new HashMap<>();
        for (int[] t : times) {
            graph.computeIfAbsent(t[0], key -> new ArrayList<>()).add(new int[]{t[1], t[2]});
        }

        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);  // {time, node}
        heap.offer(new int[]{0, k});
        Map<Integer, Integer> dist = new HashMap<>();

        while (!heap.isEmpty()) {
            int[] top = heap.poll();
            int time = top[0], node = top[1];
            if (dist.containsKey(node)) continue;
            dist.put(node, time);

            for (int[] e : graph.getOrDefault(node, List.of())) {
                if (!dist.containsKey(e[0])) heap.offer(new int[]{time + e[1], e[0]});
            }
        }

        if (dist.size() != n) return -1;
        int max = 0;
        for (int d : dist.values()) max = Math.max(max, d);
        return max;
    }
}
// Time: O((V + E) log V), Space: O(V + E)
```

#### 787. [Cheapest Flights Within K Stops](https://leetcode.com/problems/cheapest-flights-within-k-stops/) [M]

Description: Find the cheapest price from `src` to `dst` using at most `k` stops.

Idea: Bellman-Ford. Each relaxation round allows one more edge, so exactly `k + 1` rounds enforce the stop budget. Relaxing from a snapshot of the previous round is what keeps a single round from chaining multiple edges.

```java
class Solution {
    public int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
        int[] dist = new int[n];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[src] = 0;

        for (int round = 0; round <= k; round++) {
            int[] next = dist.clone();                 // snapshot of the previous round
            for (int[] f : flights) {
                int u = f[0], v = f[1], price = f[2];
                if (dist[u] == Integer.MAX_VALUE) continue;
                if (dist[u] + price < next[v]) next[v] = dist[u] + price;
            }
            dist = next;
        }
        return dist[dst] == Integer.MAX_VALUE ? -1 : dist[dst];
    }
}
// Time: O((k + 1) * E), Space: O(V)
```

#### 778. [Swim in Rising Water](https://leetcode.com/problems/swim-in-rising-water/) [H]

Description: Find the earliest time when you can reach the bottom-right cell as water rises.

Idea: Dijkstra where a path's cost is the **maximum** elevation on it, not the sum. Pushing neighbours with `max(currentTime, nextHeight)` preserves optimality under that cost function.

```java
class Solution {
    private static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public int swimInWater(int[][] grid) {
        int n = grid.length;
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]); // {time, r, c}
        boolean[][] seen = new boolean[n][n];

        heap.offer(new int[]{grid[0][0], 0, 0});
        seen[0][0] = true;

        while (!heap.isEmpty()) {
            int[] top = heap.poll();
            int time = top[0], r = top[1], c = top[2];
            if (r == n - 1 && c == n - 1) return time;

            for (int[] d : DIRS) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= n || nc < 0 || nc >= n || seen[nr][nc]) continue;
                seen[nr][nc] = true;
                heap.offer(new int[]{Math.max(time, grid[nr][nc]), nr, nc});
            }
        }
        return -1;
    }
}
// Time: O(n^2 log n), Space: O(n^2)
```

#### 269. [Alien Dictionary](https://leetcode.com/problems/alien-dictionary/) [H]

Description: Given words sorted by an unknown alphabet, recover one valid character ordering, or `""` if the input is inconsistent.

Idea: Each adjacent word pair reveals exactly one edge — the first position where they differ. Topologically sort the resulting character graph; a cycle means no ordering exists. The invalid-prefix case (`"abc"` before `"ab"`) must be rejected explicitly.

```java
class Solution {
    public String alienOrder(String[] words) {
        Map<Character, Set<Character>> adj = new HashMap<>();
        Map<Character, Integer> degree = new HashMap<>();
        for (String w : words) {
            for (char c : w.toCharArray()) {
                adj.putIfAbsent(c, new HashSet<>());
                degree.putIfAbsent(c, 0);
            }
        }

        for (int i = 0; i + 1 < words.length; i++) {
            String a = words[i], b = words[i + 1];
            int min = Math.min(a.length(), b.length());
            if (a.length() > b.length() && a.startsWith(b)) return "";   // invalid prefix

            for (int j = 0; j < min; j++) {
                char x = a.charAt(j), y = b.charAt(j);
                if (x == y) continue;
                if (adj.get(x).add(y)) degree.merge(y, 1, Integer::sum);
                break;                                   // only the FIRST difference counts
            }
        }

        Deque<Character> q = new ArrayDeque<>();
        for (Map.Entry<Character, Integer> e : degree.entrySet()) {
            if (e.getValue() == 0) q.offer(e.getKey());
        }

        StringBuilder sb = new StringBuilder();
        while (!q.isEmpty()) {
            char c = q.poll();
            sb.append(c);
            for (char nei : adj.get(c)) {
                if (degree.merge(nei, -1, Integer::sum) == 0) q.offer(nei);
            }
        }
        return sb.length() == degree.size() ? sb.toString() : "";        // cycle -> ""
    }
}
// Time: O(total chars + V + E), Space: O(V + E)
```

#### 5. [Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/) [M]

Description: Find the longest palindromic substring in a given string.

Idea: Expand around each of the `2n - 1` centers (odd length and even length) and keep the widest window found.

```java
class Solution {
    private int bestL = 0, bestR = 0;      // inclusive bounds

    public String longestPalindrome(String s) {
        if (s.isEmpty()) return "";
        bestL = 0;
        bestR = 0;
        for (int i = 0; i < s.length(); i++) {
            expand(s, i, i);               // odd length
            expand(s, i, i + 1);           // even length
        }
        return s.substring(bestL, bestR + 1);
    }

    private void expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        l++;
        r--;
        if (r - l > bestR - bestL) {
            bestL = l;
            bestR = r;
        }
    }
}
// Time: O(n^2), Space: O(1)
```

#### 322. [Coin Change](https://leetcode.com/problems/coin-change/) [M]

Description: Compute the minimum number of coins needed to make a given amount.

##### Approach 1: Bottom-up DP

Idea: `dp[a]` = minimum coins to make amount `a`; try every coin at every amount. Using `amount + 1` as the "unreachable" sentinel avoids `Integer.MAX_VALUE + 1` overflow.

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int INF = amount + 1;
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int a = 1; a <= amount; a++) {
            for (int c : coins) {
                if (a - c >= 0) dp[a] = Math.min(dp[a], dp[a - c] + 1);
            }
        }
        return dp[amount] == INF ? -1 : dp[amount];
    }
}
// Time: O(amount * numCoins), Space: O(amount)
```

##### Approach 2: Top-down DFS + memo

Idea: Try subtracting each coin and memoize the best result per remaining amount. `memo[rem] == 0` means "not computed", so use a separate sentinel for "unreachable".

```java
class Solution {
    private int[] memo;
    private int[] coins;
    private static final int UNREACHABLE = Integer.MAX_VALUE - 1;

    public int coinChange(int[] coins, int amount) {
        this.coins = coins;
        memo = new int[amount + 1];
        Arrays.fill(memo, -1);
        int ans = dfs(amount);
        return ans == UNREACHABLE ? -1 : ans;
    }

    private int dfs(int rem) {
        if (rem == 0) return 0;
        if (memo[rem] != -1) return memo[rem];

        int best = UNREACHABLE;
        for (int c : coins) {
            if (rem - c < 0) continue;
            int sub = dfs(rem - c);
            if (sub != UNREACHABLE) best = Math.min(best, sub + 1);
        }
        memo[rem] = best;
        return best;
    }
}
// Time: O(amount * numCoins), Space: O(amount)
```

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> words = new HashSet<>(wordDict);
        int maxLen = 0;
        for (String w : words) maxLen = Math.max(maxLen, w.length());

        Boolean[] memo = new Boolean[s.length() + 1];
        return dfs(s, 0, words, maxLen, memo);
    }

    private boolean dfs(String s, int i, Set<String> words, int maxLen, Boolean[] memo) {
        if (i == s.length()) return true;
        if (memo[i] != null) return memo[i];

        for (int j = i + 1; j <= Math.min(s.length(), i + maxLen); j++) {
            if (words.contains(s.substring(i, j)) && dfs(s, j, words, maxLen, memo)) {
                return memo[i] = true;
            }
        }
        return memo[i] = false;
    }
}
```

#### 300. [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/) [M]

Description: Length of the longest strictly increasing subsequence.

##### Approach 1: O(n log n) patience sorting

Idea: `tails[k]` is the smallest possible tail of an increasing subsequence of length `k + 1`. Binary search for the first tail `>= x` and overwrite it; the array length is the answer.

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;

        for (int x : nums) {
            int lo = 0, hi = size;
            while (lo < hi) {                     // leftmost tail >= x
                int mid = lo + (hi - lo) / 2;
                if (tails[mid] < x) lo = mid + 1;
                else hi = mid;
            }
            tails[lo] = x;
            if (lo == size) size++;
        }
        return size;
    }
}
// Time: O(n log n), Space: O(n)
```

Idea: `dp[i]` = LIS ending at `i`; extend from any earlier `j` with `nums[j] < nums[i]`.

#### 416. [Partition Equal Subset Sum](https://leetcode.com/problems/partition-equal-subset-sum/) [M]

Description: Determine whether the array can be partitioned into two subsets with equal sum.

Idea: An odd total is immediately impossible. Otherwise it reduces to subset-sum reachability of `total / 2`. Iterating the inner loop downward is what stops a number from being reused.

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int total = 0;
        for (int x : nums) total += x;
        if (total % 2 == 1) return false;

        int target = total / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int x : nums) {
            for (int cur = target; cur >= x; cur--) {   // downward: use each number once
                if (dp[cur - x]) dp[cur] = true;
            }
            if (dp[target]) return true;
        }
        return dp[target];
    }
}
// Time: O(n * target), Space: O(target)
```

```java
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m + 1][n + 1];

            for (int j = n - 1; j >= 0; j--) {
                if (text1.charAt(i) == text2.charAt(j)) dp[i][j] = 1 + dp[i + 1][j + 1];

    }
```

#### 494. [Target Sum](https://leetcode.com/problems/target-sum/) [M]

Description: Count the ways to assign `+` and `-` signs so the expression equals `target`.

Idea: After each number, every reachable sum branches into two new sums. Sums range over `[-total, total]`, so offset by `total` to index a plain array.

```java

        int total = 0;
        for (int x : nums) total += x;
        if (Math.abs(target) > total) return 0;

        int[] dp = new int[2 * total + 1];
        dp[total] = 1;                              // index = sum + total

        for (int x : nums) {
            int[] next = new int[2 * total + 1];
            for (int sum = 0; sum <= 2 * total; sum++) {
                if (dp[sum] == 0) continue;
                next[sum + x] += dp[sum];
                next[sum - x] += dp[sum];
            }
            dp = next;
        }
        return dp[target + total];
    }
}
// Time: O(n * total), Space: O(total)
```

#### 329. [Longest Increasing Path in a Matrix](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/) [H]

Description: Find the length of the longest strictly increasing path in a matrix.

Idea: Strictly increasing edges make the grid a DAG, so there are no cycles and every cell's answer can be cached. `memo[r][c] == 0` doubles as "not computed".

```java
class Solution {
    private static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    private int[][] matrix, memo;
    private int rows, cols;

    public int longestIncreasingPath(int[][] matrix) {
        this.matrix = matrix;
        rows = matrix.length;
        cols = matrix[0].length;
        memo = new int[rows][cols];

        int ans = 0;
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) ans = Math.max(ans, dfs(r, c));
        }
        return ans;
    }

    private int dfs(int r, int c) {
        if (memo[r][c] != 0) return memo[r][c];

        int best = 1;
        for (int[] d : DIRS) {
            int nr = r + d[0], nc = c + d[1];
            if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
            if (matrix[nr][nc] <= matrix[r][c]) continue;
            best = Math.max(best, 1 + dfs(nr, nc));
        }
        memo[r][c] = best;
        return best;
    }
}
// Time: O(m * n), Space: O(m * n)
```

```java
        vals.add(1);
        for (int x : nums) if (x > 0) vals.add(x);
        vals.add(1);

        int n = vals.size();
        int[][] dp = new int[n][n];

        for (int length = 2; length < n; length++) {
            for (int left = 0; left + length < n; left++) {
                int right = left + length;

                    dp[left][right] = Math.max(dp[left][right],
                        dp[left][mid]
                        + vals.get(left) * vals.get(mid) * vals.get(right)
                        + dp[mid][right]);
                }
            }
        }
        return dp[0][n - 1];
    }
}
```

#### 846. [Hand of Straights](https://leetcode.com/problems/hand-of-straights/) [M]

Idea: Always start groups from the smallest remaining card — anything else strands that card. A `TreeMap` keeps the counts in sorted order for free.

```java
class Solution {
    public boolean isNStraightHand(int[] hand, int groupSize) {
        if (hand.length % groupSize != 0) return false;

        TreeMap<Integer, Integer> count = new TreeMap<>();
        for (int c : hand) count.merge(c, 1, Integer::sum);

        while (!count.isEmpty()) {
            int start = count.firstKey();
            int need = count.get(start);
            for (int x = start; x < start + groupSize; x++) {
                Integer have = count.get(x);
                if (have == null || have < need) return false;
                if (have == need) count.remove(x);
                else count.put(x, have - need);
            }
        }
        return true;
    }
}
```

#### 253. [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/) [M]

Description: Compute the minimum number of meeting rooms required to hold all meetings.

##### Approach 1: Min-heap of end times

Idea: Process meetings by start time. If the earliest-ending room is free before the next meeting starts, reuse it; otherwise open a new room. The heap size is the answer.

```java
class Solution {
    public int minMeetingRooms(int[][] intervals) {
        if (intervals.length == 0) return 0;
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        PriorityQueue<Integer> heap = new PriorityQueue<>();   // end times
        for (int[] it : intervals) {
            if (!heap.isEmpty() && heap.peek() <= it[0]) heap.poll();
            heap.offer(it[1]);
        }
        return heap.size();
    }
}
// Time: O(n log n), Space: O(n)
```

##### Approach 2: Sweep line

Idea: Turn each interval into a `+1` at its start and a `-1` at its end, sort the events, and take the maximum running sum. Ties must process endings first so back-to-back meetings share a room.

```java
class Solution {
    public int minMeetingRooms(int[][] intervals) {
        int n = intervals.length;
        int[] starts = new int[n], ends = new int[n];
        for (int i = 0; i < n; i++) {
            starts[i] = intervals[i][0];
            ends[i] = intervals[i][1];
        }
        Arrays.sort(starts);
        Arrays.sort(ends);

        int rooms = 0, best = 0, e = 0;
        for (int s = 0; s < n; s++) {
            while (e < n && ends[e] <= starts[s]) {     // free rooms first
                rooms--;
                e++;
            }
            rooms++;
            best = Math.max(best, rooms);
        }
        return best;
    }
}
// Time: O(n log n), Space: O(n)
```

#### 1851. [Minimum Interval to Include Each Query](https://leetcode.com/problems/minimum-interval-to-include-each-query/) [H]

Description: For each query, return the size of the smallest interval containing it, or `-1` if none exists.

Idea: Answer the queries offline in increasing order. Push newly eligible intervals (start `<= q`) into a min-heap keyed by size, discard intervals that already ended before `q`, and the heap top is the answer.

```java
class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        int[][] ordered = new int[queries.length][2];   // {query, originalIndex}
        for (int i = 0; i < queries.length; i++) ordered[i] = new int[]{queries[i], i};
        Arrays.sort(ordered, (a, b) -> Integer.compare(a[0], b[0]));

        int[] ans = new int[queries.length];
        Arrays.fill(ans, -1);

        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]); // {size, end}
        int i = 0;

        for (int[] oq : ordered) {
            int q = oq[0];
            while (i < intervals.length && intervals[i][0] <= q) {
                heap.offer(new int[]{intervals[i][1] - intervals[i][0] + 1, intervals[i][1]});
                i++;
            }
            while (!heap.isEmpty() && heap.peek()[1] < q) heap.poll();
            if (!heap.isEmpty()) ans[oq[1]] = heap.peek()[0];
        }
        return ans;
    }
}
// Time: O((n + q) log n), Space: O(n + q)
```

```java
        }

        for (int[] row : matrix) {                    // reverse each row
            for (int l = 0, r = n - 1; l < r; l++, r--) {
                int tmp = row[l];
                row[l] = row[r];
                row[r] = tmp;
            }
        }
    }
}
// Time: O(n^2), Space: O(1)
```

#### 54. [Spiral Matrix](https://leetcode.com/problems/spiral-matrix/) [M]

Description: Return the elements of a matrix in spiral order.

Idea: Maintain four boundaries and peel one layer at a time, re-checking the bounds before the bottom and left passes so a single leftover row or column is not emitted twice.

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> res = new ArrayList<>();
        if (matrix.length == 0 || matrix[0].length == 0) return res;

        int top = 0, bottom = matrix.length - 1;
        int left = 0, right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {
            for (int c = left; c <= right; c++) res.add(matrix[top][c]);
            top++;

            for (int r = top; r <= bottom; r++) res.add(matrix[r][right]);
            right--;

            if (top <= bottom) {
                for (int c = right; c >= left; c--) res.add(matrix[bottom][c]);
                bottom--;
            }
            if (left <= right) {
                for (int r = bottom; r >= top; r--) res.add(matrix[r][left]);
                left++;
            }
        }
        return res;
    }
}
// Time: O(R * C), Space: O(1) extra (output aside)
```

#### 73. [Set Matrix Zeroes](https://leetcode.com/problems/set-matrix-zeroes/) [M]

Description: If a cell is zero, set its entire row and column to zero.

##### Approach 1: In-place markers, O(1) extra space

Idea: Use row 0 and column 0 as the marker arrays. Their own original state must be captured first, and they must be written last, or the markers overwrite themselves.

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int R = matrix.length, C = matrix[0].length;

        boolean firstRowZero = false, firstColZero = false;
        for (int c = 0; c < C; c++) if (matrix[0][c] == 0) firstRowZero = true;
        for (int r = 0; r < R; r++) if (matrix[r][0] == 0) firstColZero = true;

        for (int r = 1; r < R; r++) {
            for (int c = 1; c < C; c++) {
                if (matrix[r][c] == 0) {
                    matrix[r][0] = 0;
                    matrix[0][c] = 0;
                }
            }
        }

        for (int r = 1; r < R; r++) {
            for (int c = 1; c < C; c++) {
                if (matrix[r][0] == 0 || matrix[0][c] == 0) matrix[r][c] = 0;
            }
        }

        if (firstRowZero) for (int c = 0; c < C; c++) matrix[0][c] = 0;
        if (firstColZero) for (int r = 0; r < R; r++) matrix[r][0] = 0;
    }
}
// Time: O(R * C), Space: O(1)
```

##### Approach 2: Row/column sets

Idea: First pass records which rows and columns must be zeroed; second pass writes the zeros.

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int R = matrix.length, C = matrix[0].length;
        boolean[] rows = new boolean[R], cols = new boolean[C];

        for (int r = 0; r < R; r++) {
            for (int c = 0; c < C; c++) {
                if (matrix[r][c] == 0) {
                    rows[r] = true;
                    cols[c] = true;
                }
            }
        }

        for (int r = 0; r < R; r++) {
            for (int c = 0; c < C; c++) {
                if (rows[r] || cols[c]) matrix[r][c] = 0;
            }
        }
    }
}
// Time: O(R * C), Space: O(R + C)
```

#### 202. [Happy Number](https://leetcode.com/problems/happy-number/) [E]

Description: Determine whether repeatedly summing the squares of the digits eventually reaches 1.

Idea: If the process never reaches 1 it must eventually loop, so a seen-set detects the cycle. (Floyd's slow/fast works too and uses O(1) space.)

```java
class Solution {
    public boolean isHappy(int n) {
        Set<Integer> seen = new HashSet<>();
        while (n != 1 && seen.add(n)) {
            n = squareDigits(n);
        }
        return n == 1;
    }

    private int squareDigits(int n) {
        int total = 0;
        while (n > 0) {
            int digit = n % 10;
            total += digit * digit;
            n /= 10;
        }
        return total;
    }
}
// Time: O(log n) per step with a small cycle bound, Space: O(log n)
```

#### 66. [Plus One](https://leetcode.com/problems/plus-one/) [E]

Description: Add one to an integer represented as an array of digits.

Idea: Walk backward until a digit can absorb the carry. Falling out of the loop means the number was all nines, so the answer is `1` followed by zeros.

```java
class Solution {
    public int[] plusOne(int[] digits) {
        for (int i = digits.length - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits;
            }
            digits[i] = 0;
        }
        int[] res = new int[digits.length + 1];
        res[0] = 1;
        return res;
    }
}
// Time: O(n), Space: O(1) amortized
```

#### 50. [Pow(x, n)](https://leetcode.com/problems/powx-n/) [M]

Description: Compute `x^n` efficiently for an integer exponent `n`.

Idea: Square the base each step and consume one exponent bit at a time. `n` must be widened to `long` before negating — `-Integer.MIN_VALUE` overflows back to itself.

```java
class Solution {
    public double myPow(double x, int n) {
        long power = n;
        if (power < 0) {
            x = 1 / x;
            power = -power;
        }

        double ans = 1;
        while (power > 0) {
            if ((power & 1) == 1) ans *= x;
            x *= x;
            power >>= 1;
        }
        return ans;
    }
}
// Time: O(log n), Space: O(1)
```

#### 43. [Multiply Strings](https://leetcode.com/problems/multiply-strings/) [M]

Description: Multiply two non-negative integers represented as strings without converting them to integers directly.

Idea: Grade-school multiplication. The product of digits `i` and `j` lands at positions `i + j` and `i + j + 1`, so a result array of length `m + n` always fits.

```java
class Solution {
    public String multiply(String num1, String num2) {
        if (num1.equals("0") || num2.equals("0")) return "0";

        int m = num1.length(), n = num2.length();
        int[] res = new int[m + n];

        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int mul = (num1.charAt(i) - '0') * (num2.charAt(j) - '0');
                int total = mul + res[i + j + 1];
                res[i + j + 1] = total % 10;
                res[i + j] += total / 10;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int d : res) {
            if (sb.length() == 0 && d == 0) continue;    // skip leading zeros
            sb.append(d);
        }
        return sb.toString();
    }
}
// Time: O(m * n), Space: O(m + n)
```

#### 2013. [Detect Squares](https://leetcode.com/problems/detect-squares/) [M]

Description: Support adding points and counting axis-aligned squares that use a query point as one corner.

Idea: For a query `(x, y)`, iterate the points sharing row `y`. Each such point fixes the side length, leaving exactly two candidate squares (above and below) whose two remaining corners are direct lookups.

```java
class DetectSquares {
    private final Map<Long, Integer> points = new HashMap<>();      // encoded point -> count
    private final Map<Integer, Map<Integer, Integer>> rows = new HashMap<>();  // y -> (x -> count)

    public DetectSquares() {}

    private long key(int x, int y) {
        return ((long) x << 32) ^ (y & 0xffffffffL);
    }

    public void add(int[] point) {
        int x = point[0], y = point[1];
        points.merge(key(x, y), 1, Integer::sum);
        rows.computeIfAbsent(y, k -> new HashMap<>()).merge(x, 1, Integer::sum);
    }

    public int count(int[] point) {
        int x = point[0], y = point[1];
        Map<Integer, Integer> row = rows.get(y);
        if (row == null) return 0;

        int total = 0;
        for (Map.Entry<Integer, Integer> e : row.entrySet()) {
            int col = e.getKey();
            if (col == x) continue;                     // needs a real side length
            int freq = e.getValue();
            int side = col - x;

            total += freq
                   * points.getOrDefault(key(x, y + side), 0)
                   * points.getOrDefault(key(col, y + side), 0);
            total += freq
                   * points.getOrDefault(key(x, y - side), 0)
                   * points.getOrDefault(key(col, y - side), 0);
        }
        return total;
    }
}
// Time: add O(1), count O(k) for points on the same row, Space: O(n)
```

#### 191. [Number of 1 Bits](https://leetcode.com/problems/number-of-1-bits/) [E]

```java
            count++;

    }
}
```

#### 190. [Reverse Bits](https://leetcode.com/problems/reverse-bits/) [E]

Description: Reverse the bit order in a fixed-width 32-bit integer.

Idea: Shift the result left while reading bits off the bottom of `n`, 32 times. Use `>>>` (logical shift) so the sign bit does not smear — Java handles the 32-bit boundary natively, which Python needed masking for.

```java
class Solution {
    public int reverseBits(int n) {
        int res = 0;
        for (int i = 0; i < 32; i++) {
            res = (res << 1) | (n & 1);
            n >>>= 1;                      // LOGICAL shift, not >>
        }
        return res;
    }
}
// Time: O(1) (32 iterations), Space: O(1)
```

Built-in: `Integer.reverse(n)`.

#### 371. [Sum of Two Integers](https://leetcode.com/problems/sum-of-two-integers/) [M]

Description: Compute the sum of two integers without the `+` operator.

Idea: `a ^ b` is the sum without carries; `(a & b) << 1` is the carry. Repeat until there is no carry left. Java's `int` already wraps at 32 bits, so the `0xFFFFFFFF` masking the Python version needed disappears entirely.

```java
class Solution {
    public int getSum(int a, int b) {
        while (b != 0) {
            int carry = (a & b) << 1;
            a = a ^ b;
            b = carry;
        }
        return a;
    }
}
// Time: O(1) (bounded by word size), Space: O(1)
```

#### 7. [Reverse Integer](https://leetcode.com/problems/reverse-integer/) [M]

Description: Reverse the digits of a signed 32-bit integer, returning 0 on overflow.

Idea: Pop digits with `% 10` and push with `* 10`. Java cannot detect overflow after the fact, so check **before** each multiply. Working with the value as-is (rather than `abs`) avoids the `Integer.MIN_VALUE` trap, since Java's `%` keeps the sign.

```java
class Solution {
    public int reverse(int x) {
        int ans = 0;
        while (x != 0) {
            int digit = x % 10;                     // keeps the sign in Java
            x /= 10;

            if (ans > Integer.MAX_VALUE / 10 || (ans == Integer.MAX_VALUE / 10 && digit > 7)) {
                return 0;
            }
            if (ans < Integer.MIN_VALUE / 10 || (ans == Integer.MIN_VALUE / 10 && digit < -8)) {
                return 0;
            }
            ans = ans * 10 + digit;
        }
        return ans;
    }
}
// Time: O(log10 n), Space: O(1)
```
