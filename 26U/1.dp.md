#### 416. [Partition Equal Subset Sum](https://leetcode.com/problems/partition-equal-subset-sum/) [M]  
Decide whether nums can be split into two subsets with equal sum.  
`dp` `0/1 knapsack` `subset sum`

Idea: An equal split needs an even total, and then a subset summing to exactly `sum / 2`.  
That is 0/1 knapsack with the sum as the capacity and reachability as the value.

##### Approach 1: 1D DP (rolling row)

`dp[s]` = can some subset of the items seen so far reach exactly `s`.  
The inner loop runs **backwards** so each item is used at most once — a forward loop would read `dp[s - num]` that this same item already updated, which is the unbounded-knapsack recurrence.

```python
class Solution:
    def canPartition(self, nums: list[int]) -> bool:
        ttl = sum(nums)
        if ttl % 2:
            return False
        target = ttl // 2
        dp = [False] * (target + 1)
        dp[0] = True
        for num in nums:
            for s in range(target, num - 1, -1):
                dp[s] = dp[s] or dp[s - num]
        return dp[target]
# Time: O(n * target), Space: O(target)
```

##### Approach 2: 2D DP (explicit table)

`dp[i][s]` = can the first `i` items reach exactly `s`; each item is either skipped (`dp[i-1][s]`) or taken (`dp[i-1][s-num]`).  
Same recurrence, one row per item, which makes the "each item used once" property visible — the derivation to write first if asked to explain before optimizing.

```python
class Solution:
    def canPartition(self, nums: list[int]) -> bool:
        ttl = sum(nums)
        if ttl % 2:
            return False
        target = ttl // 2
        n = len(nums)
        dp = [[False] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = True                  # sum 0 is always reachable (take nothing)
        for i in range(1, n + 1):
            num = nums[i - 1]
            for s in range(target + 1):
                dp[i][s] = dp[i - 1][s]      # skip
                if s >= num:
                    dp[i][s] = dp[i][s] or dp[i - 1][s - num]   # take
        return dp[n][target]
# Time: O(n * target), Space: O(n * target)
```
