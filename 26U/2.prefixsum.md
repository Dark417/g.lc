#### 560. [和为 K 的子数组](https://leetcode.com/problems/subarray-sum-equals-k/) [M]
Count contiguous subarrays whose sum equals `k`.  
`array` `hash-table` `prefix-sum`

##### Approach 1: Prefix Sum Frequencies

If the current prefix sum is `prefix`, every earlier prefix equal to `prefix - k` starts a valid subarray. Store frequencies rather than only indices because multiple earlier prefixes can produce different subarrays.

```python
from collections import defaultdict
from typing import List


class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = defaultdict(int)
        count[0] = 1
        prefix = answer = 0

        for num in nums:
            prefix += num
            answer += count[prefix - k]
            count[prefix] += 1

        return answer

# Time: O(n), Space: O(n)
```

#### 209. [长度最小的子数组](https://leetcode.com/problems/minimum-size-subarray-sum/) [M]
Find the minimum length of a positive-integer subarray whose sum is at least `target`.  
`array` `binary-search` `prefix-sum` `sliding-window`

##### Approach 1: Prefix Sum + Binary Search

Positive numbers make the prefix-sum array strictly increasing. For every left boundary, binary-search the first prefix at least `prefix[left] + target`.

```python
from bisect import bisect_left
from typing import List


class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        prefix = [0]
        for num in nums:
            prefix.append(prefix[-1] + num)

        answer = len(nums) + 1
        for left in range(len(nums)):
            right = bisect_left(prefix, prefix[left] + target, left + 1)
            if right <= len(nums):
                answer = min(answer, right - left)

        return 0 if answer == len(nums) + 1 else answer

# Time: O(n log n), Space: O(n)
```

##### Approach 2: Sliding Window

Because all values are positive, expanding can only increase the sum and shrinking can only decrease it.

```python
from typing import List


class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        left = window_sum = 0
        answer = len(nums) + 1

        for right, num in enumerate(nums):
            window_sum += num
            while window_sum >= target:
                answer = min(answer, right - left + 1)
                window_sum -= nums[left]
                left += 1

        return 0 if answer == len(nums) + 1 else answer

# Time: O(n), Space: O(1)
```

#### 238. [除了自身以外数组的乘积](https://leetcode.com/problems/product-of-array-except-self/) [M]
Return the product of every element except `nums[i]` without division.  
`array` `prefix-sum`

##### Approach 1: Prefix and Suffix Products

Write the product to the left into the answer, then multiply in the product to the right during a reverse pass.

```python
from typing import List


class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        answer = [1] * len(nums)

        prefix_product = 1
        for i, num in enumerate(nums):
            answer[i] = prefix_product
            prefix_product *= num

        suffix_product = 1
        for i in range(len(nums) - 1, -1, -1):
            answer[i] *= suffix_product
            suffix_product *= nums[i]

        return answer

# Time: O(n), Space: O(1) auxiliary (excluding output)
```

#### 1004. [最大连续 1 的个数 III](https://leetcode.com/problems/max-consecutive-ones-iii/) [M]
Find the longest subarray containing at most `k` zeros.  
`array` `binary-search` `prefix-sum` `sliding-window`

##### Approach 1: Zero Prefix Sum + Binary Search

Prefix sums count zeros. For each right boundary, binary-search the earliest prefix whose removal leaves at most `k` zeros.

```python
from bisect import bisect_left
from typing import List


class Solution:
    def longestOnes(self, nums: List[int], k: int) -> int:
        zeros = [0]
        for num in nums:
            zeros.append(zeros[-1] + (num == 0))

        answer = 0
        for right in range(1, len(zeros)):
            left = bisect_left(zeros, zeros[right] - k, 0, right)
            answer = max(answer, right - left)
        return answer

# Time: O(n log n), Space: O(n)
```

##### Approach 2: Sliding Window

Keep at most `k` zeros in the window and move `left` only when that invariant is broken.

```python
from typing import List


class Solution:
    def longestOnes(self, nums: List[int], k: int) -> int:
        left = zeros = 0

        for right, num in enumerate(nums):
            zeros += num == 0
            if zeros > k:
                zeros -= nums[left] == 0
                left += 1

        return len(nums) - left

# Time: O(n), Space: O(1)
```

#### 525. [连续数组](https://leetcode.com/problems/contiguous-array/) [M]
Find the maximum length of a contiguous subarray with equal numbers of zeros and ones.  
`array` `hash-table` `prefix-sum`

##### Approach 1: Balanced Prefix Sum

Treat zero as `-1` and one as `+1`. Equal prefix balances at two positions mean the elements between them sum to zero; retain only the earliest index for each balance.

```python
from typing import List


class Solution:
    def findMaxLength(self, nums: List[int]) -> int:
        first_index = {0: -1}
        balance = answer = 0

        for i, num in enumerate(nums):
            balance += 1 if num == 1 else -1
            if balance in first_index:
                answer = max(answer, i - first_index[balance])
            else:
                first_index[balance] = i

        return answer

# Time: O(n), Space: O(n)
```

#### 1878. [矩阵中最大的三个菱形和](https://leetcode.com/problems/get-biggest-three-rhombus-sums-in-a-grid/) [M]
Return the three largest distinct sums of rhombus borders in the grid.  
`array` `math` `matrix` `prefix-sum`

##### Approach 1: Diagonal Prefix Sums

Precompute sums on both diagonal directions. Each of the four rhombus edges is then an O(1) range query; subtract the four corners once because adjacent edges count them twice.

```python
from typing import List


class Solution:
    def getBiggestThree(self, grid: List[List[int]]) -> List[int]:
        rows, cols = len(grid), len(grid[0])
        down_right = [[0] * (cols + 1) for _ in range(rows + 1)]
        down_left = [[0] * (cols + 1) for _ in range(rows + 1)]

        for r in range(rows):
            for c in range(cols):
                down_right[r + 1][c + 1] = down_right[r][c] + grid[r][c]
            for c in range(cols - 1, -1, -1):
                down_left[r + 1][c] = down_left[r][c + 1] + grid[r][c]

        def sum_down_right(r1: int, c1: int, r2: int, c2: int) -> int:
            return down_right[r2 + 1][c2 + 1] - down_right[r1][c1]

        def sum_down_left(r1: int, c1: int, r2: int, c2: int) -> int:
            return down_left[r2 + 1][c2] - down_left[r1][c1 + 1]

        best = set()
        for top_r in range(rows):
            for center_c in range(cols):
                best.add(grid[top_r][center_c])
                max_radius = min((rows - 1 - top_r) // 2, center_c, cols - 1 - center_c)
                for radius in range(1, max_radius + 1):
                    middle_r = top_r + radius
                    bottom_r = top_r + 2 * radius
                    left_c = center_c - radius
                    right_c = center_c + radius
                    border = (
                        sum_down_left(top_r, center_c, middle_r, left_c)
                        + sum_down_right(top_r, center_c, middle_r, right_c)
                        + sum_down_right(middle_r, left_c, bottom_r, center_c)
                        + sum_down_left(middle_r, right_c, bottom_r, center_c)
                        - grid[top_r][center_c]
                        - grid[middle_r][left_c]
                        - grid[middle_r][right_c]
                        - grid[bottom_r][center_c]
                    )
                    best.add(border)

        return sorted(best, reverse=True)[:3]

# Time: O(m * n * min(m, n)), Space: O(m * n)
```

#### 253. [会议室 II](https://leetcode.com/problems/meeting-rooms-ii/) [M]
Return the minimum number of rooms required to schedule all meetings.  
`greedy` `array` `two-pointers` `prefix-sum`

##### Approach 1: Difference Events + Prefix Sum

Add one room at each start and release one at each end. Sorting equal-time deltas together correctly allows a meeting ending at time `t` to share a room with one starting at `t`.

```python
from collections import defaultdict
from typing import List


class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        delta = defaultdict(int)
        for start, end in intervals:
            delta[start] += 1
            delta[end] -= 1

        rooms = answer = 0
        for time in sorted(delta):
            rooms += delta[time]
            answer = max(answer, rooms)
        return answer

# Time: O(n log n), Space: O(n)
```

#### 713. [乘积小于 K 的子数组](https://leetcode.com/problems/subarray-product-less-than-k/) [M]
Count contiguous subarrays whose product is strictly less than `k`.  
`array` `binary-search` `prefix-sum` `sliding-window`

##### Approach 1: Prefix Products + Binary Search

For each right prefix product, binary-search the first left prefix satisfying `prefix[left] * k > prefix[right]`. This is exact, but prefix products can grow very large, so the sliding-window alternative is preferable in an interview.

```python
from typing import List


class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k <= 1:
            return 0

        prefix = [1]
        for num in nums:
            prefix.append(prefix[-1] * num)

        answer = 0
        for right in range(1, len(prefix)):
            lo, hi = 0, right
            while lo < hi:
                mid = (lo + hi) // 2
                if prefix[mid] * k > prefix[right]:
                    hi = mid
                else:
                    lo = mid + 1
            answer += right - lo
        return answer

# Time: O(n log n), Space: O(n)
```

##### Approach 2: Sliding Window

All values are positive, so shrink from the left until the product is valid. Every subarray ending at `right` and starting inside the final window is valid.

```python
from typing import List


class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k <= 1:
            return 0

        left = answer = 0
        product = 1
        for right, num in enumerate(nums):
            product *= num
            while product >= k:
                product //= nums[left]
                left += 1
            answer += right - left + 1
        return answer

# Time: O(n), Space: O(1)
```

#### 1423. [可获得的最大点数](https://leetcode.com/problems/maximum-points-you-can-obtain-from-cards/) [M]
Take exactly `k` cards from the two ends and maximize their total score.  
`array` `prefix-sum` `sliding-window`

##### Approach 1: Left and Right Prefix Sums

Try every split: take `left_count` cards from the front and the remaining cards from the back.

```python
from typing import List


class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        left_prefix = [0]
        right_prefix = [0]
        for i in range(k):
            left_prefix.append(left_prefix[-1] + cardPoints[i])
            right_prefix.append(right_prefix[-1] + cardPoints[-1 - i])

        return max(
            left_prefix[left_count] + right_prefix[k - left_count]
            for left_count in range(k + 1)
        )

# Time: O(k), Space: O(k)
```

##### Approach 2: Fixed Complement Window

Taking `k` end cards is equivalent to leaving one contiguous window of length `n - k`; minimize that window's sum.

```python
from typing import List


class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        window_size = len(cardPoints) - k
        if window_size == 0:
            return sum(cardPoints)

        window_sum = sum(cardPoints[:window_size])
        min_window = window_sum
        for right in range(window_size, len(cardPoints)):
            window_sum += cardPoints[right] - cardPoints[right - window_size]
            min_window = min(min_window, window_sum)
        return sum(cardPoints) - min_window

# Time: O(n), Space: O(1)
```

#### 3070. [元素和小于等于 k 的子矩阵的数目](https://leetcode.com/problems/count-submatrices-with-top-left-element-and-sum-less-than-k/) [M]
Count submatrices anchored at the grid's top-left corner whose sums are at most `k`.  
`array` `matrix` `prefix-sum`

##### Approach 1: 2D Prefix Sum

The prefix sum at `(r, c)` is exactly the sum of the required top-left-anchored submatrix. Build it with inclusion-exclusion and count values at most `k`.

```python
from typing import List


class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        rows, cols = len(grid), len(grid[0])
        prefix = [[0] * (cols + 1) for _ in range(rows + 1)]
        answer = 0

        for r in range(1, rows + 1):
            for c in range(1, cols + 1):
                prefix[r][c] = (
                    grid[r - 1][c - 1]
                    + prefix[r - 1][c]
                    + prefix[r][c - 1]
                    - prefix[r - 1][c - 1]
                )
                answer += prefix[r][c] <= k
        return answer

# Time: O(m * n), Space: O(m * n)
```

#### 1314. [矩阵区域和](https://leetcode.com/problems/matrix-block-sum/) [M]
For every cell, sum the matrix block within distance `k`, clipped to the matrix.  
`array` `matrix` `prefix-sum`

##### Approach 1: 2D Prefix Sum

Build a padded prefix matrix, then answer each rectangular block with four prefix lookups using inclusion-exclusion.

```python
from typing import List


class Solution:
    def matrixBlockSum(self, mat: List[List[int]], k: int) -> List[List[int]]:
        rows, cols = len(mat), len(mat[0])
        prefix = [[0] * (cols + 1) for _ in range(rows + 1)]

        for r in range(rows):
            for c in range(cols):
                prefix[r + 1][c + 1] = (
                    mat[r][c]
                    + prefix[r][c + 1]
                    + prefix[r + 1][c]
                    - prefix[r][c]
                )

        answer = [[0] * cols for _ in range(rows)]
        for r in range(rows):
            for c in range(cols):
                top, left = max(0, r - k), max(0, c - k)
                bottom, right = min(rows - 1, r + k), min(cols - 1, c + k)
                answer[r][c] = (
                    prefix[bottom + 1][right + 1]
                    - prefix[top][right + 1]
                    - prefix[bottom + 1][left]
                    + prefix[top][left]
                )
        return answer

# Time: O(m * n), Space: O(m * n)
```

#### 1094. [拼车](https://leetcode.com/problems/car-pooling/) [M]
Determine whether the car can complete every trip without exceeding capacity.  
`array` `prefix-sum` `sorting` `simulation`

##### Approach 1: Difference Array + Prefix Sum

Record passenger deltas at pickup and drop-off positions. The running prefix sum is the number of passengers currently in the car.

```python
from typing import List


class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        last_position = max(end for _, _, end in trips)
        delta = [0] * (last_position + 1)

        for passengers, start, end in trips:
            delta[start] += passengers
            delta[end] -= passengers

        current = 0
        for change in delta:
            current += change
            if current > capacity:
                return False
        return True

# Time: O(n + U), Space: O(U), where U is the farthest position
```

#### 523. [连续的子数组和](https://leetcode.com/problems/continuous-subarray-sum/) [M]
Return whether a subarray of length at least two has a sum divisible by `k`.  
`array` `hash-table` `math` `prefix-sum`

##### Approach 1: Earliest Prefix Remainder

Equal prefix remainders imply that their difference is divisible by `k`. Keep the earliest index for each remainder so the length check has the best chance to pass.

```python
from typing import List


class Solution:
    def checkSubarraySum(self, nums: List[int], k: int) -> bool:
        first_index = {0: -1}
        remainder = 0

        for i, num in enumerate(nums):
            remainder = (remainder + num) % k
            if remainder in first_index:
                if i - first_index[remainder] >= 2:
                    return True
            else:
                first_index[remainder] = i
        return False

# Time: O(n), Space: O(min(n, k))
```

#### 528. [按权重随机选择](https://leetcode.com/problems/random-pick-with-weight/) [M]
Randomly pick an index with probability proportional to its positive weight.  
`array` `math` `binary-search` `prefix-sum` `randomized`

##### Approach 1: Prefix Weights + Binary Search

Map every integer ticket in `[1, total_weight]` to the first cumulative weight covering it. The interval length assigned to each index equals its weight.

```python
import random
from bisect import bisect_left
from typing import List


class Solution:
    def __init__(self, w: List[int]):

            self.prefix.append(total)
```

#### 3364. [最小正和子数组](https://leetcode.com/problems/minimum-positive-sum-subarray/) [E]

`array` `prefix-sum` `sliding-window`

##### Approach 1: Prefix Sum Range Queries

Build a padded prefix array and enumerate every permitted start and length. Each candidate sum is an O(1) prefix difference.

```python
from typing import List


class Solution:
    def minimumSumSubarray(self, nums: List[int], l: int, r: int) -> int:
        prefix = [0]
        for num in nums:
            prefix.append(prefix[-1] + num)

        answer = float("inf")
        for left in range(len(nums)):
            for length in range(l, r + 1):
                right = left + length
                if right > len(nums):
                    break
                current = prefix[right] - prefix[left]
                if current > 0:
                    answer = min(answer, current)
        return -1 if answer == float("inf") else answer

```
