## 3. Oracle signature: design-style + concurrency coding

- LRU Cache ★★★ — treat as mandatory
  → HashMap + doubly linked list, O(1) get/put
  → Follow-up: thread-safe version
  ◆ Coarse: `synchronized` on get/put — simple, correct, contended
  ◆ Better: `ReentrantReadWriteLock` — reads still mutate recency, so RW lock buys little
  ◆ Java-idiomatic: `LinkedHashMap(cap, 0.75f, true)` + `removeEldestEntry` wrapped in a lock
  ◆ Defeater: "lock-free LRU" is a research topic; say sharded/striped locks instead
- Design Browser History ★
- Music player LLD ★; Logging file system ★; Parking lot / meeting-room style
- Hit counter / rate limiter (sliding window, token bucket) — ties to `2.system-design.md`
- Factory pattern; refactor-to-SOLID given a class ★
- Concurrency
  → Print odd/even alternately from two threads (wait/notify or `Semaphore`) ★
  → Write and run a deadlock, then fix with lock ordering ★
  → Thread-safe LRU (above)
  → Producer/consumer with `BlockingQueue`

## 5. Live-round protocol (HackerRank)

```
0–2 min  restate + clarify    →  2–5 min approach + complexity
5–25 min code (talk)          →  25–35 min run tests + fix
35–40 min edge cases + optimize discussion
```

- Clarify (score bucket #1)
  → Input size / value range → drives O(n²) vs O(n log n)
  → Sorted? duplicates? negatives? nulls/empties?
  → Return type on invalid input — throw vs sentinel
  → Can I use library sort / collections?
- Approach
  → State brute force + its complexity in one sentence
  → State target approach + complexity; pick and go
- Code
  → Compiling Java; real names; helper methods
  → Narrate at decision points, not every line
- Tests (score bucket #3)
  → Run the provided tests first
  → Add: empty, single, all-same, max size, the naive-breaker
  → Say "this test guards the off-by-one on the right boundary"
- Stuck
  → Say what you'd search / who you'd ask; ask interviewer a directed question
  → Recruiter: they _want_ to guide — following guidance is scored positively
- Setup before Round 1
  → HackerRank account, Java 17 template with `Scanner`/`BufferedReader` boilerplate memorized
  → Practice 5 problems inside HackerRank's editor — different keybindings than LC

## 6. Java snippets to have cold

```java
// LRU via LinkedHashMap (access-order)
class LRU<K,V> extends LinkedHashMap<K,V> {
  private final int cap;
  LRU(int cap){ super(cap, 0.75f, true); this.cap = cap; }
  @Override protected boolean removeEldestEntry(Map.Entry<K,V> e){ return size() > cap; }
}
```

```java
// Odd/even alternating printer
class Printer {
  private int n = 1; private final int max;
  Printer(int max){ this.max = max; }
  synchronized void print(boolean odd) throws InterruptedException {
    while (n <= max) {
      if ((n % 2 == 1) != odd) { wait(); continue; }
      System.out.println(Thread.currentThread().getName() + " " + n++);
      notifyAll();
    }
  }
}
```
