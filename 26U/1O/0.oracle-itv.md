## 2. Loop structure

```
[Round 1] HackerRank live, 1 hr, 1 engineer
   │  ~10–15 min resume/behavioral  +  ~40–45 min coding
   ▼
[Final] 4 rounds (recruiter) — reports say 4–5
   ├─ Engineer #1: coding / LLD / tech discussion + behavioral slice
   ├─ Engineer #2: same mix (sometimes HLD, sometimes debug/SOLID refactor)
   ├─ Hiring manager: project deep-dive + behavioral (occasionally coding)
   └─ Key interviewer ("bartender"): outside team, OCI values, mediates debrief
   ▼
[Debrief] within 48 hrs → offer
```

- Round 1 (your Friday Sept 4, 11am)
  → Expect **compiling, running code** that passes interviewer-provided tests
  → Usually 1 problem; sometimes 2 shorter ones
  → Difficulty: LC Medium, occasionally Hard
  → Short resume walkthrough first — have a 90-second JPMC pitch ready
  → Email recruiter next day (their explicit instruction)
- Engineer rounds
  → Mix of coding (often 2 mediums), LLD/HLD, deep tech discussion
  → Some rounds: given a class, refactor to SOLID / find the bug
  → Behavioral slice at start or end
- Hiring manager round
  → Draw your architecture, defend every decision under "why X not Y"
  → Behavioral on OCI values
- Key interviewer / bartender round
  → From a different team/org, not your hiring team
  → Purely behavioral, or behavioral + curveball puzzle (one report: Josephus, 10-min timer)
  → Goes resume point-by-point; probes job changes, stakeholder conflict, design justification
  → Reported as the toughest round; also mediates your debrief
- Competencies
  → Recruiter sends assigned competencies (OCI values, technical, role) once final is scheduled
  → Ask for them if not received

## 3. Scoring — what earns points

- Three explicit buckets (recruiter)
  → Qualifying questions before coding — quality of your questions
  → The solution — correctness, then complexity
  → Test cases you write and run yourself
- Implicit buckets (candidate reports)
  → Think-aloud; treat interviewer as a senior peer you'd ask for guidance
  → If you don't know, say so + name what resource you'd use
  → Brute force → iterate is acceptable; incomplete "perfect" solution is not
- 🗣 Opening script for every coding problem
  → "Before I code: input size? duplicates? sorted? nulls/empties? expected return on invalid input? memory constraint?"
  → "Approach: X, O(n log n) time, O(n) space. Alternative: Y. I'll start with X."
  → After coding: "Let me add three tests: empty, single element, the edge that breaks naive."

## 4. Timeline & process reality

- Round 1 result: 2 days to ~3 weeks
- Final: back-to-back, 2 rounds/day over 1–2 days, or one ~5-hr block
- Full process: ~1–1.5 months
- Reported friction (largely Oracle-side)
  → Long silences, ghosting, no-shows, reschedules
  → Down-leveling IC4 → IC3 after loop, with lower package
  → Rule: silence ≠ rejection; recruiter said reach out within 48 hrs if no feedback
- Keep other loops alive; H-1B clock still runs (see project instructions)

## 5. Level calibration (IC2 / IC3 / IC4)

| OCI level | Rough title | Yrs (reported) | Amazon/Google analog |
|---|---|---|---|
| IC2 | MTS | 0–2 / Master's | SDE1 / L3 |
| IC3 | SMTS | ~2–7 (wide band) | high SDE1 – SDE2 / L4 |
| IC4 | PMTS / "Principal" branded | 5+ | SDE2+ – Senior / L5-leaning |

- Req 338588 = IC4
  → With 4 yrs you will be calibrated between IC3 and IC4
  → Depth on ops, design tradeoffs, and ownership is what separates the two
- Ask recruiter explicitly: "Is the loop targeting IC3 or IC4?"
- Down-level is a one-way door — same principle as the Microsoft note in project memory

## 6. Rejection patterns

- Coding
  → Jumped to code without clarifying → lost the "questions" bucket
  → Code didn't compile / didn't pass provided tests on HackerRank
  → Weak complexity analysis; couldn't optimize after a hint
  → No self-written test cases
- Design / HM
  → Couldn't defend tech choices under pressure
  → Shallow on concurrency, consistency, scaling, security
- Behavioral
  → Generic stories, no STAR structure, no metric at the end
  → No on-call / ops / cross-team conflict examples
  → Weak "why Oracle / why cloud / why platform team"
- Level
  → Enough signal for IC3, not IC4 → offer down-leveled

## 7. Negotiation notes

- Don't anchor comp low; candidates report a low stated number "biting back"
- Push for IC4 given the req; have evidence: ownership of infra delivery, RCA, mentoring
- Recruiter promised decision within a week — use competing timelines explicitly
- H-1B: filing before Aug 21 was optimal path (passed); now grace period until Oct 20 → mention urgency early and factually
