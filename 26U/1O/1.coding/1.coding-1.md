#### 56. [Merge Intervals](https://leetcode.com/problems/merge-intervals/) [M] ★★★ (S)

Description: Given `intervals[i] = [start, end]`, merge all overlapping intervals and return the non-overlapping result.

Idea: Sort by start. Walk once: if the current interval starts at or before the last merged end, extend that end; otherwise push a new interval.

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    out = []
    for s, e in intervals:
        if out and s <= out[-1][1]:
            out[-1][1] = max(out[-1][1], e)
        else:
            out.append([s, e])
    return out
# Time: O(n log n), Space: O(n) output
```

⚠️ `s <= out[-1][1]` — touching intervals `[1,4],[4,5]` merge. Ask whether touching counts.

#### 33. [Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/) [M] ★★

Description: A sorted distinct array was rotated at an unknown pivot. Return the index of `target` or `-1` in O(log n).

Idea: At every midpoint exactly one half is sorted. Check whether `target` lies inside that sorted half; if so shrink to it, otherwise go to the other half.

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:                   # left half sorted
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                       # right half sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
# Time: O(log n), Space: O(1)
```

#### 54. [Spiral Matrix](https://leetcode.com/problems/spiral-matrix/) [M] ★★

Description: Return all elements of an `m × n` matrix in clockwise spiral order.

Idea: Keep four boundaries. Consume top row, right column, bottom row, left column, shrinking each boundary after use. Guard the bottom/left passes so a single remaining row or column is not emitted twice.

```python
def spiralOrder(matrix):
    out = []
    top, bot = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    while top <= bot and left <= right:
        for c in range(left, right + 1):
            out.append(matrix[top][c])
        top += 1
        for r in range(top, bot + 1):
            out.append(matrix[r][right])
        right -= 1
        if top <= bot:
            for c in range(right, left - 1, -1):
                out.append(matrix[bot][c])
            bot -= 1
        if left <= right:
            for r in range(bot, top - 1, -1):
                out.append(matrix[r][left])
            left += 1
    return out
# Time: O(mn), Space: O(1) extra
```

#### 108. [Convert Sorted Array to Binary Search Tree](https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/) [E] ★★

Description: Build a height-balanced BST from a sorted ascending array.

Idea: The middle element becomes the root; recurse on the left and right halves. Using indices avoids slicing copies.

```python
def sortedArrayToBST(nums):
    def build(lo, hi):
        if lo > hi:
            return None
        mid = (lo + hi) // 2
        node = TreeNode(nums[mid])
        node.left = build(lo, mid - 1)
        node.right = build(mid + 1, hi)
        return node
    return build(0, len(nums) - 1)
# Time: O(n), Space: O(log n) recursion
```

#### ⟂ Longest Subarray with Sum Zero [M] ★

Description: Given an integer array (positives and negatives), return the length of the longest contiguous subarray whose sum is 0.

Idea: Prefix sums. If `prefix[j] == prefix[i]` then `nums[i+1..j]` sums to 0. Store the **first** index each prefix value was seen; the distance to the current index is a candidate.

```python
def longestZeroSum(nums):
    first = {0: -1}                  # prefix 0 "seen" before index 0
    best = run = 0
    for i, v in enumerate(nums):
        run += v
        if run in first:
            best = max(best, i - first[run])
        else:
            first[run] = i
    return best
# Time: O(n), Space: O(n)
```

#### 628. [Maximum Product of Three Numbers](https://leetcode.com/problems/maximum-product-of-three-numbers/) [E] ★

Description: Return the maximum product of any three numbers in the array (may contain negatives).

Idea: Either the three largest, or the two most negative times the largest. One pass tracking top-3 max and bottom-2 min avoids the sort.

```python
def maximumProduct(nums):
    mx1 = mx2 = mx3 = float('-inf')
    mn1 = mn2 = float('inf')
    for v in nums:
        if v > mx1:   mx1, mx2, mx3 = v, mx1, mx2
        elif v > mx2: mx2, mx3 = v, mx2
        elif v > mx3: mx3 = v
        if v < mn1:   mn1, mn2 = v, mn1
        elif v < mn2: mn2 = v
    return max(mx1 * mx2 * mx3, mn1 * mn2 * mx1)
# Time: O(n), Space: O(1)
```

#### 1428. [Leftmost Column with at Least a One](https://leetcode.com/problems/leftmost-column-with-at-least-a-one/) [M] ★

Description: Each row of a binary matrix is sorted (all 0s then all 1s). Return the leftmost column index containing a 1, or `-1`.

Idea: Start at the top-right. A `1` means the answer is at this column or further left — move left; a `0` means this row is exhausted — move down. Each step retires a row or a column.

```python
def leftMostColumnWithOne(grid):
    rows, cols = len(grid), len(grid[0])
    r, c = 0, cols - 1
    ans = -1
    while r < rows and c >= 0:
        if grid[r][c] == 1:
            ans = c
            c -= 1
        else:
            r += 1
    return ans
# Time: O(rows + cols), Space: O(1)
```

#### 1664. [Ways to Make a Fair Array](https://leetcode.com/problems/ways-to-make-a-fair-array/) [M] ★

Description: Count indices `i` such that removing `nums[i]` makes the sum of even-indexed elements equal the sum of odd-indexed elements (indices re-numbered after removal).

Idea: After removing `i`, elements to its right flip parity. So `even_total = left_even + right_odd`, `odd_total = left_odd + right_even`. Keep running left sums; right sums are totals minus left minus current.

```python
def waysToMakeFair(nums):
    even = sum(nums[0::2]); odd = sum(nums[1::2])
    le = lo = 0                                   # left even / odd sums
    count = 0
    for i, v in enumerate(nums):
        if i % 2 == 0: even -= v
        else:          odd -= v
        # right-side sums now exclude i: even, odd are "right even / right odd"
        if le + odd == lo + even:
            count += 1
        if i % 2 == 0: le += v
        else:          lo += v
    return count
# Time: O(n), Space: O(1)
```

#### 209. [Minimum Size Subarray Sum](https://leetcode.com/problems/minimum-size-subarray-sum/) [M]

Description: Positive integers; return the minimal length of a contiguous subarray with sum ≥ `target`, else 0.

Idea: Sliding window. Expand right; while the window sum ≥ target, record the length and shrink from the left. Positivity makes shrinking monotone.

```python
def minSubArrayLen(target, nums):
    best = float('inf')
    left = run = 0
    for right, v in enumerate(nums):
        run += v
        while run >= target:
            best = min(best, right - left + 1)
            run -= nums[left]
            left += 1
    return 0 if best == float('inf') else best
# Time: O(n), Space: O(1)
```

#### ⟂ Subarray with Size ≥ M and Sum ≥ K [M] ★

Description (Nov 2025 report): positive integers; does a contiguous subarray of length **at least** `M` with sum **at least** `K` exist? (Variant: return its minimal length.)

Idea: If a longer subarray helps only when values are positive, the best candidate ending at `right` with length ≥ M is the one starting at `right - M + 1` **or earlier** — so track the max sum of any window of length ≥ M ending here: `maxSum(right) = window_M(right) + max(0, maxSum(right - M))`.

```python
def existsSubarray(nums, M, K):
    n = len(nums)
    if n < M:
        return False
    prefix = [0] * (n + 1)
    for i, v in enumerate(nums):
        prefix[i + 1] = prefix[i] + v
    # subarray [i, right] has length >= M  <=>  i <= right - M + 1
    # sum = prefix[right+1] - prefix[i]  → maximize by minimizing prefix[i] over allowed i
    min_prefix = float('inf')
    for right in range(M - 1, n):
        min_prefix = min(min_prefix, prefix[right - M + 1])
        if prefix[right + 1] - min_prefix >= K:
            return True
    return False
# Time: O(n), Space: O(n)
```

What to say aloud: "the constraint only caps how *late* the start can be; the best start is the smallest prefix among the allowed ones." Works with negatives too. For the *minimal length* variant with positives, run a sliding window from `left` but never shrink below `M`.

#### 792. [Number of Matching Subsequences](https://leetcode.com/problems/number-of-matching-subsequences/) [M] ★ (S)

Description: Count how many `words` are subsequences of `s` (`s` up to 5·10⁴, up to 5·10³ words).

Idea: Scan `s` once. Bucket each word (as an iterator) under the next character it needs. When that character appears, advance every waiting iterator and re-bucket; an exhausted iterator is a match.

```python
from collections import defaultdict

def numMatchingSubseq(s, words):
    waiting = defaultdict(list)
    for w in words:
        waiting[w[0]].append(iter(w[1:]))      # each entry waits for w[0]
    count = 0
    for ch in s:
        for it in waiting.pop(ch, ()):
            nxt = next(it, None)
            if nxt is None:
                count += 1
            else:
                waiting[nxt].append(it)
    return count
# Time: O(len(s) + sum(len(w))), Space: O(#words)
```

#### 206. [Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/) [E] ★★★

Description: Reverse a singly linked list; return the new head. Do it iteratively **and** recursively.

Idea: Iterative — three pointers, flip one `next` per step. Recursive — reverse the tail, then hook `head` onto the end of it via `head.next.next = head`.

```python
def reverseList(head):
    prev, cur = None, head
    while cur:
        cur.next, prev, cur = prev, cur, cur.next
    return prev
# Time: O(n), Space: O(1)


def reverseListRec(head):
    if head is None or head.next is None:
        return head
    new_head = reverseListRec(head.next)
    head.next.next = head
    head.next = None
    return new_head
# Time: O(n), Space: O(n) stack
```

#### 2. [Add Two Numbers](https://leetcode.com/problems/add-two-numbers/) [M] ★★

Description: Two non-empty lists store non-negative integers with digits in reverse order. Return the sum as a list.

Idea: Walk both with a carry; a dummy head avoids the first-node special case. Loop while any of `l1`, `l2`, `carry` remain.

```python
def addTwoNumbers(l1, l2):
    dummy = tail = ListNode(0)
    carry = 0
    while l1 or l2 or carry:
        s = carry
        if l1: s += l1.val; l1 = l1.next
        if l2: s += l2.val; l2 = l2.next
        carry, digit = divmod(s, 10)
        tail.next = ListNode(digit)
        tail = tail.next
    return dummy.next
# Time: O(max(m, n)), Space: O(max(m, n))
```

#### 150. [Evaluate Reverse Polish Notation](https://leetcode.com/problems/evaluate-reverse-polish-notation/) [M]

Description: Evaluate tokens in postfix form, e.g. `["2","1","+","3","*"]` → 9. Division truncates toward zero.

Idea: Push numbers; on an operator pop two, apply, push. `int(a / b)` truncates toward zero, `a // b` does not.

```python
def evalRPN(tokens):
    st = []
    for t in tokens:
        if t in '+-*/':
            b, a = st.pop(), st.pop()
            if t == '+':   st.append(a + b)
            elif t == '-': st.append(a - b)
            elif t == '*': st.append(a * b)
            else:          st.append(int(a / b))
        else:
            st.append(int(t))
    return st[0]
# Time: O(n), Space: O(n)
```

#### 227. [Basic Calculator II](https://leetcode.com/problems/basic-calculator-ii/) [M]

Description: Evaluate a string with non-negative integers and `+ - * /` (no parentheses), respecting precedence.

Idea: Keep a stack of signed terms. On `+`/`-` push the number with its sign; on `*`/`/` pop the last term and combine immediately. The answer is the sum of the stack.

```python
def calculate(s):
    st, num, op = [], 0, '+'
    for i, ch in enumerate(s):
        if ch.isdigit():
            num = num * 10 + int(ch)
        if ch in '+-*/' or i == len(s) - 1:
            if op == '+':   st.append(num)
            elif op == '-': st.append(-num)
            elif op == '*': st.append(st.pop() * num)
            else:           st.append(int(st.pop() / num))
            op, num = ch, 0
    return sum(st)
# Time: O(n), Space: O(n)
```

#### ⟂ Evaluate Token Expression `[3, '+', 4, '*', 5]` [M] ★

Description (Oracle report): tokens alternate number, operator, number… in **infix** order. Return the value with normal precedence (→ 23, not 35).

Idea: Same as 227 but the tokens are already split. Defer `+`/`-` by pushing signed terms; resolve `*`/`/` against the stack top immediately.

```python
def evalTokens(tokens):
    st = [tokens[0]]
    for i in range(1, len(tokens), 2):
        op, num = tokens[i], tokens[i + 1]
        if op == '+':   st.append(num)
        elif op == '-': st.append(-num)
        elif op == '*': st.append(st.pop() * num)
        else:           st.append(int(st.pop() / num))
    return sum(st)
# Time: O(n), Space: O(n)
```

#### ⟂ Prefix → Postfix [M] ★

Description: Convert a prefix expression (e.g. `*+AB-CD`) to postfix (`AB+CD-*`). Single-letter operands.

Idea: Scan **right to left**. Operands push as strings. An operator pops two operands (first popped is the left one) and pushes `left + right + op`.

```python
def prefixToPostfix(expr):
    st = []
    for ch in reversed(expr):
        if ch.isalnum():
            st.append(ch)
        else:
            a, b = st.pop(), st.pop()        # a = left operand
            st.append(a + b + ch)
    return st[-1]
# Time: O(n²) worst string concat, O(n) tokens, Space: O(n)
```

Prefix → infix is the same with `'(' + a + ch + b + ')'`; postfix → prefix scans left-to-right and pushes `ch + a + b` with `b` popped first.

#### 844. [Backspace String Compare](https://leetcode.com/problems/backspace-string-compare/) [E] ★

Description: `#` is a backspace. Are `s` and `t` equal after typing?

Idea: Build each with a stack — O(n) space. Follow-up O(1): walk both from the end, skipping characters that backspaces would delete, comparing one surviving char at a time.

```python
def backspaceCompare(s, t):
    def build(x):
        st = []
        for ch in x:
            if ch == '#':
                if st: st.pop()
            else:
                st.append(ch)
        return st
    return build(s) == build(t)
# Time: O(n), Space: O(n)


def backspaceCompareO1(s, t):
    def next_valid(x, i):
        skip = 0
        while i >= 0:
            if x[i] == '#':   skip += 1
            elif skip > 0:    skip -= 1
            else:             break
            i -= 1
        return i
    i, j = len(s) - 1, len(t) - 1
    while i >= 0 or j >= 0:
        i, j = next_valid(s, i), next_valid(t, j)
        if i >= 0 and j >= 0 and s[i] != t[j]:
            return False
        if (i >= 0) != (j >= 0):
            return False
        i -= 1; j -= 1
    return True
# Time: O(n), Space: O(1)
```

#### ⟂ Minimum Chairs from a C/R/L/U String [M] ★

Description (Oracle report; LC 3168 is the E/L version): a string of events — `C` customer arrives (sits), `L` customer leaves, `R`/`U` are non-seating events (e.g. `R` reserve — occupies a chair until the matching `U` unreserves). Return the minimum number of chairs so nobody ever lacks one.

Idea: Running occupancy counter; the answer is its maximum. Treat each letter as `+1`/`-1`/`0` per the interviewer's rules — ask which letters occupy.

```python
def maxPathSum(root):

        if not node:
            return 0

        r = max(gain(node.right), 0)
        best = max(best, node.val + l + r)
        return node.val + max(l, r)

    return best
```

#### 767. [Reorganize String](https://leetcode.com/problems/reorganize-string/) [M] ★

Description: Rearrange `s` so no two adjacent characters are equal; return `""` if impossible.

Idea: Max-heap by count. Pop the most frequent, append it, and hold it back one round (push the *previous* char back only after placing the current). Impossible iff a count exceeds `(n+1)//2`.

```python
import heapq
from collections import Counter

def reorganizeString(s):
    cnt = Counter(s)
    if max(cnt.values()) > (len(s) + 1) // 2:
        return ""
    heap = [(-c, ch) for ch, c in cnt.items()]
    heapq.heapify(heap)
    out = []
    prev = None                                   # (count, char) held back
    while heap:
        c, ch = heapq.heappop(heap)
        out.append(ch)
        if prev and prev[0] < 0:
            heapq.heappush(heap, prev)
        prev = (c + 1, ch)                        # c is negative
    return ''.join(out)
# Time: O(n log k), Space: O(k) — k distinct chars
```

#### ⟂ Top-K Most Expensive Stocks in a Time Window (stream) [M] ★ (S)

Description (round-1 report): a stream of `(timestamp, symbol, price)` arrives in time order. Support `add(ts, sym, price)` and `topK(now, k)` = the `k` highest-priced distinct symbols among ticks within the last `W` seconds.

Idea: Deque of ticks in time order; evict the front while older than `now - W`. Keep a per-symbol latest price for ticks still in the window (a dict with counts so eviction can forget symbols). Query = `heapq.nlargest(k)` over live symbols — O(m log k).

```python
import heapq
from collections import deque

class StockTopK:
    def __init__(self, window):
        self.W = window
        self.ticks = deque()               # (ts, sym, price)
        self.latest = {}                   # sym -> (ts, price) of newest tick in window
        self.live = {}                     # sym -> #ticks in window

    def _evict(self, now):
        while self.ticks and self.ticks[0][0] < now - self.W:
            ts, sym, _ = self.ticks.popleft()
            self.live[sym] -= 1
            if self.live[sym] == 0:
                del self.live[sym]; del self.latest[sym]

    def add(self, ts, sym, price):
        self.ticks.append((ts, sym, price))
        self.live[sym] = self.live.get(sym, 0) + 1
        self.latest[sym] = (ts, price)     # stream is time-ordered → newest wins
        self._evict(ts)

    def topK(self, now, k):
        self._evict(now)
        return heapq.nlargest(k, self.latest.items(), key=lambda kv: kv[1][1])
# Time: add O(1) amortized, topK O(m log k) for m live symbols, Space: O(ticks in window)
```

#### 127. [Word Ladder](https://leetcode.com/problems/word-ladder/) [H] ★

Description: Shortest transformation length from `beginWord` to `endWord`, changing one letter at a time, each intermediate in `wordList`.

Idea: BFS. Neighbours via wildcard buckets: `"h*t"` → all words matching. Precompute once so each word expands in O(L) lookups.

```python
from collections import defaultdict, deque

def ladderLength(beginWord, endWord, wordList):
    words = set(wordList)
    if endWord not in words:
        return 0
    L = len(beginWord)
    buckets = defaultdict(list)
    for w in words:
        for i in range(L):
            buckets[w[:i] + '*' + w[i + 1:]].append(w)
    q = deque([(beginWord, 1)])
    seen = {beginWord}
    while q:
        w, d = q.popleft()
        if w == endWord:
            return d
        for i in range(L):
            for nb in buckets[w[:i] + '*' + w[i + 1:]]:
                if nb not in seen:
                    seen.add(nb)
                    q.append((nb, d + 1))
    return 0
# Time: O(N · L²), Space: O(N · L)
```

#### 126. [Word Ladder II](https://leetcode.com/problems/word-ladder-ii/) [H]

Description: Return **all** shortest transformation sequences.

Idea: BFS level by level, recording `parents[word]` only for words first reached at the *next* level (words are removed from the pool per level, not per node, so multiple parents survive). Then DFS backwards from `endWord` to build the paths.

```python
from collections import defaultdict

def findLadders(beginWord, endWord, wordList):
    words = set(wordList)
    if endWord not in words:
        return []
    L = len(beginWord)
    parents = defaultdict(set)
    level = {beginWord}
    words.discard(beginWord)
    found = False
    while level and not found:
        nxt = set()
        for w in level:
            for i in range(L):
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    nb = w[:i] + c + w[i + 1:]
                    if nb in words:
                        nxt.add(nb)
                        parents[nb].add(w)
                        if nb == endWord:
                            found = True
        words -= nxt                                # remove per level, not per node
        level = nxt
    if not found:
        return []
    out = []
    def back(w, path):
        if w == beginWord:
            out.append(path[::-1]); return
        for p in parents[w]:
            back(p, path + [p])
    back(endWord, [endWord])
    return out
# Time: O(N · L · 26) BFS + output size, Space: O(N · L)
```

#### 743. [Network Delay Time](https://leetcode.com/problems/network-delay-time/) (Dijkstra template) [M] ★

Description: Directed weighted edges `(u, v, w)`, `n` nodes, source `k`. Time for the signal to reach every node, or `-1`.

Idea: Dijkstra with a min-heap of `(dist, node)`; skip stale entries. Common "modifications": max-edge instead of sum (`nd = max(d, w)`), k-stops limit (state = `(node, stops)`), probability product (negate logs / use max-heap).

```python
import heapq
from collections import defaultdict

def networkDelayTime(times, n, k):
    adj = defaultdict(list)
    for u, v, w in times:
        adj[u].append((v, w))
    dist = {}
    heap = [(0, k)]
    while heap:
        d, u = heapq.heappop(heap)
        if u in dist:
            continue                              # stale entry
        dist[u] = d
        for v, w in adj[u]:
            if v not in dist:
                heapq.heappush(heap, (d + w, v))
    return max(dist.values()) if len(dist) == n else -1
# Time: O(E log E), Space: O(V + E)
```

```python
            return True
        if m * m < x: lo = m + 1
```

#### 29. [Divide Two Integers](https://leetcode.com/problems/divide-two-integers/) [M] ★★ (S)

```python
def divide(dividend, divisor):
    INT_MAX, INT_MIN = 2**31 - 1, -2**31
    if dividend == INT_MIN and divisor == -1:
        return INT_MAX
    neg = (dividend < 0) != (divisor < 0)
    a, b = abs(dividend), abs(divisor)
    q = 0
    for k in range(31, -1, -1):
        if (b << k) <= a:
            a -= b << k
            q += 1 << k
    return -q if neg else q

```

Idea: Fisher–Yates: for `i` from `n-1` down to 1, swap `a[i]` with `a[j]`, `j` uniform in `[0, i]`. Each of the `n!` permutations is equally likely. The naive "swap with any index" is **not** uniform.

```python

class ShuffleArray:

        self.orig = list(nums)

    def reset(self):
        return self.orig

    def shuffle(self):
        a = list(self.orig)
        for i in range(len(a) - 1, 0, -1):
            j = random.randint(0, i)
            a[i], a[j] = a[j], a[i]
        return a

```

```python
    def idx(mmyyyy):
        return int(mmyyyy[2:]) * 12 + int(mmyyyy[:2]) - 1
    totals = defaultdict(int)
    bounds = [idx(s) for s, _ in periods] + [idx(end) + 1]
    for i, (_, pay) in enumerate(periods):
        for m in range(bounds[i], bounds[i + 1]):
            totals[m // 12] += pay
    return dict(sorted(totals.items()))
# Time: O(months), Space: O(years)
```

#### 1472. [Design Browser History](https://leetcode.com/problems/design-browser-history/) [M] ★

Description: `visit(url)` clears forward history; `back(steps)` / `forward(steps)` move up to `steps` and return the current url.

Idea: One list plus a cursor — `visit` truncates everything after the cursor. O(1) for all ops.

```python
class BrowserHistory:
    def __init__(self, homepage):
        self.hist = [homepage]
        self.cur = 0

    def visit(self, url):
        del self.hist[self.cur + 1:]
        self.hist.append(url)
        self.cur += 1

    def back(self, steps):
        self.cur = max(0, self.cur - steps)
        return self.hist[self.cur]

    def forward(self, steps):
        self.cur = min(len(self.hist) - 1, self.cur + steps)
        return self.hist[self.cur]
# Time: O(1) amortized, Space: O(n)
```

#### 362. [Design Hit Counter](https://leetcode.com/problems/design-hit-counter/) [M]

Description: `hit(ts)` records a hit; `getHits(ts)` returns hits in the past 300 seconds. Timestamps arrive non-decreasing.

Idea: Deque of `(ts, count)`; evict the front while older than `ts - 300`. Ring buffer of 300 slots if memory must be O(1).

```python
from collections import deque

class HitCounter:
    def __init__(self, window=300):
        self.W = window
        self.q = deque()               # (ts, count)
        self.total = 0

    def _evict(self, ts):
        while self.q and self.q[0][0] <= ts - self.W:
            self.total -= self.q.popleft()[1]

    def hit(self, ts):
        if self.q and self.q[-1][0] == ts:
            self.q[-1] = (ts, self.q[-1][1] + 1)
        else:
            self.q.append((ts, 1))
        self.total += 1
        self._evict(ts)

    def getHits(self, ts):
        self._evict(ts)
        return self.total
# Time: O(1) amortized, Space: O(window)
```

#### ⟂ Rate Limiter — sliding-window log + token bucket [M]

Description: `allow(client_id, now)` → bool. (a) At most `N` requests per rolling `W` seconds per client. (b) Token bucket: capacity `C`, refill `r` tokens/sec.

Idea: (a) per-client deque of timestamps; evict old, compare length. Exact but O(N) memory per client. (b) store `(tokens, last_ts)`; refill lazily on each call — O(1) memory, allows bursts up to `C`. See `2.system-design.md` for the distributed version.

```python
from collections import deque, defaultdict

class SlidingWindowLimiter:
    def __init__(self, limit, window):
        self.N, self.W = limit, window
        self.logs = defaultdict(deque)

    def allow(self, client, now):
        q = self.logs[client]
        while q and q[0] <= now - self.W:
            q.popleft()
        if len(q) < self.N:
            q.append(now)
            return True
        return False
# Time: O(1) amortized, Space: O(N) per client


class TokenBucket:
    def __init__(self, capacity, rate):
        self.C, self.r = capacity, rate
        self.state = {}                 # client -> [tokens, last_ts]

    def allow(self, client, now, cost=1):
        tokens, last = self.state.get(client, (self.C, now))
        tokens = min(self.C, tokens + (now - last) * self.r)
        if tokens >= cost:
            self.state[client] = [tokens - cost, now]
            return True
        self.state[client] = [tokens, now]
        return False
# Time: O(1), Space: O(1) per client
```

#### 635. [Design Log Storage System](https://leetcode.com/problems/design-log-storage-system/) [M] ★

Description: `put(id, "Year:Month:Day:Hour:Minute:Second")`; `retrieve(start, end, granularity)` returns ids whose timestamp, truncated to the granularity, lies in `[start, end]`.

Idea: Timestamps are fixed-width, so string comparison works. Truncate all three to the granularity's prefix length and compare lexicographically.

```python
class LogSystem:
    PREFIX = {'Year': 4, 'Month': 7, 'Day': 10, 'Hour': 13, 'Minute': 16, 'Second': 19}

    def __init__(self):
        self.logs = []                       # (timestamp, id)

    def put(self, id, timestamp):
        self.logs.append((timestamp, id))

    def retrieve(self, start, end, granularity):
        n = self.PREFIX[granularity]
        s, e = start[:n], end[:n]
        return [i for ts, i in self.logs if s <= ts[:n] <= e]
# Time: put O(1), retrieve O(n), Space: O(n)
```

Follow-up: sorted list + `bisect` on the truncated prefix for O(log n + k) retrieval.

### LRU Cache — hand-rolled (HashMap + doubly linked list) ★★★

```java
class LRUCache {
    private static class Node {
        int key, val; Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }
    private final int cap;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);   // sentinels

    LRUCache(int capacity) { cap = capacity; head.next = tail; tail.prev = head; }

    public int get(int key) {
        Node n = map.get(key);
        if (n == null) return -1;
        unlink(n); pushFront(n);
        return n.val;
    }

    public void put(int key, int value) {
        Node n = map.get(key);
        if (n != null) { n.val = value; unlink(n); pushFront(n); return; }
        if (map.size() == cap) {
            Node lru = tail.prev;
            unlink(lru); map.remove(lru.key);
        }
        n = new Node(key, value);
        map.put(key, n); pushFront(n);
    }

    private void unlink(Node n) { n.prev.next = n.next; n.next.prev = n.prev; }
    private void pushFront(Node n) {
        n.next = head.next; n.prev = head;
        head.next.prev = n; head.next = n;
    }
}
// Time: O(1) get/put, Space: O(capacity)
```

### Thread-safe LRU — the follow-up

- Coarse lock — correct, simple, contended. Reads mutate recency, so `ReadWriteLock` buys nothing.
- Say aloud: "lock-free LRU is a research topic; production answer is striping / `Caffeine`."

```java
class ConcurrentLRU<K, V> {
    private final LinkedHashMap<K, V> map;
    private final ReentrantLock lock = new ReentrantLock();

    ConcurrentLRU(int cap) {
        map = new LinkedHashMap<>(cap, 0.75f, true) {
            @Override protected boolean removeEldestEntry(Map.Entry<K, V> e) { return size() > cap; }
        };
    }

    public V get(K k) {
        lock.lock();
        try { return map.get(k); } finally { lock.unlock(); }
    }

    public void put(K k, V v) {
        lock.lock();
        try { map.put(k, v); } finally { lock.unlock(); }
    }
}
```

```java
// Striped: N independent LRU shards, key hashed to a shard → N-way less contention.
class StripedLRU<K, V> {
    private final ConcurrentLRU<K, V>[] shards;
    @SuppressWarnings("unchecked")
    StripedLRU(int cap, int n) {
        shards = new ConcurrentLRU[n];
        for (int i = 0; i < n; i++) shards[i] = new ConcurrentLRU<>(Math.max(1, cap / n));
    }
    private ConcurrentLRU<K, V> shard(K k) { return shards[(k.hashCode() & 0x7fffffff) % shards.length]; }
    public V get(K k)         { return shard(k).get(k); }
    public void put(K k, V v) { shard(k).put(k, v); }
}
```

Trade-off to state: striping makes the *global* LRU order approximate (each shard evicts its own LRU).

### Odd / even alternating printer — two threads ★

```java
// (a) wait / notify on a shared monitor
class Printer {
    private int n = 1;
    private final int max;
    Printer(int max) { this.max = max; }

    synchronized void print(boolean odd) throws InterruptedException {
        while (n <= max) {

            System.out.println(Thread.currentThread().getName() + " " + n++);
            notifyAll();
        }
    }

    public static void main(String[] a) throws Exception {
        Printer p = new Printer(10);
        Thread t1 = new Thread(() -> { try { p.print(true);  } catch (InterruptedException ignored) {} }, "odd");
        Thread t2 = new Thread(() -> { try { p.print(false); } catch (InterruptedException ignored) {} }, "even");

    }
}
```

### Deadlock — write it, run it, fix it ★

```java
class Deadlock {
    static final Object A = new Object(), B = new Object();

    public static void main(String[] args) {
        Thread t1 = new Thread(() -> { synchronized (A) { sleep(50); synchronized (B) { System.out.println("t1"); } } });
        Thread t2 = new Thread(() -> { synchronized (B) { sleep(50); synchronized (A) { System.out.println("t2"); } } });
        t1.start(); t2.start();          // hangs: t1 holds A wants B, t2 holds B wants A
    }
    static void sleep(long ms) { try { Thread.sleep(ms); } catch (InterruptedException ignored) {} }
}
```

Fix 1 — **lock ordering**: every thread acquires `A` then `B` (order by `System.identityHashCode` when locks are dynamic).

```java
Thread t2 = new Thread(() -> { synchronized (A) { sleep(50); synchronized (B) { System.out.println("t2"); } } });
```

Fix 2 — **`tryLock` with timeout + back-off** (when ordering cannot be guaranteed):

```java
class Transfer {
    static boolean transfer(ReentrantLock from, ReentrantLock to, Runnable work) throws InterruptedException {
        while (true) {
            if (from.tryLock(50, TimeUnit.MILLISECONDS)) {
                try {
                    if (to.tryLock(50, TimeUnit.MILLISECONDS)) {
                        try { work.run(); return true; } finally { to.unlock(); }
                    }
                } finally { from.unlock(); }
            }
            Thread.sleep(ThreadLocalRandom.current().nextInt(5, 20));   // back-off, then retry
        }
    }
}
```

Diagnose in prod: `jstack <pid>` prints "Found one Java-level deadlock"; `ThreadMXBean.findDeadlockedThreads()` programmatically. Four Coffman conditions — break *circular wait* (ordering) or *hold-and-wait* (tryLock).

### Producer / consumer — `BlockingQueue`

```java
class ProducerConsumer {
    public static void main(String[] args) throws InterruptedException {
        BlockingQueue<Integer> q = new ArrayBlockingQueue<>(10);     // bounded → back-pressure
        final int POISON = -1;

        Thread producer = new Thread(() -> {
            try {
                for (int i = 0; i < 100; i++) q.put(i);              // blocks when full
                q.put(POISON);
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        });
        Thread consumer = new Thread(() -> {
            try {
                for (int v; (v = q.take()) != POISON; )              // blocks when empty
                    System.out.println("consumed " + v);
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        });
        producer.start(); consumer.start();
        producer.join(); consumer.join();
    }
}
```

### Hit Counter — Java (ring buffer, O(1) memory)

```java
class HitCounter {
    private final int W = 300;
    private final int[] times = new int[W], hits = new int[W];

    public void hit(int ts) {
        int i = ts % W;
        if (times[i] != ts) { times[i] = ts; hits[i] = 0; }   // slot is stale → reset
        hits[i]++;
    }

    public int getHits(int ts) {
        int total = 0;
        for (int i = 0; i < W; i++) if (ts - times[i] < W) total += hits[i];
        return total;
    }
}
// hit O(1), getHits O(300) = O(1); thread-safe: wrap both in synchronized or use AtomicIntegerArray
```

### Token bucket — Java, thread-safe

```java
class TokenBucket {
    private final double capacity, refillPerSec;
    private double tokens;
    private long last = System.nanoTime();

    TokenBucket(double capacity, double refillPerSec) {
        this.capacity = capacity; this.refillPerSec = refillPerSec; this.tokens = capacity;
    }

    public synchronized boolean tryAcquire(int cost) {
        long now = System.nanoTime();
        tokens = Math.min(capacity, tokens + (now - last) / 1e9 * refillPerSec);
        last = now;
        if (tokens < cost) return false;
        tokens -= cost;
        return true;
    }
}
```

### Factory + refactor-to-SOLID ★

Given: a `Notifier` with `if (type.equals("email")) … else if ("sms") …` inside `send()`.

- Smell: **OCP** violation — every new channel edits `send()`; **SRP** — one class knows every transport.
- Fix: interface + one class per channel + factory (or registry map) that picks the implementation.

```java
interface Notifier { void send(String to, String msg); }

class EmailNotifier implements Notifier { public void send(String to, String msg) { /* smtp */ } }
class SmsNotifier   implements Notifier { public void send(String to, String msg) { /* sms gw */ } }

class NotifierFactory {
    private static final Map<String, Supplier<Notifier>> REGISTRY = Map.of(
        "email", EmailNotifier::new,
        "sms",   SmsNotifier::new);

    static Notifier create(String type) {
        Supplier<Notifier> s = REGISTRY.get(type);
        if (s == null) throw new IllegalArgumentException("unknown notifier: " + type);
        return s.get();
    }
}
// Adding "push" = one new class + one registry line; send() never changes.
```
