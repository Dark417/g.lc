#### ⟂ [First-Login Only-Once User Tracker — O(1) worst-case](https://www.1point3acres.com/interview/problems/company/oracle/first-unique-login-tracker) [M] P1 · bank + OJ

`design` `hashmap` `linked-list`
Description: `record(userId)` logs a login; `firstUnique()` returns the earliest-logged-in user whose lifetime login count is exactly one (else -1). Both ops O(1) **worst-case**, not amortized. Workload: few logins, many queries. OCI phone screen (2025-12-01) where the interviewer iteratively tightened the prompt from "any unique user" → "earliest unique, O(1)".

Example: `login(1) login(2) login(1) firstUser()` → `2`.

Idea: Same shape as LRU — map userId → DLL node for the still-unique users in login order, plus a set for users seen ≥ 2 times. Second login unlinks the node in O(1); `firstUnique` reads the list head. Lock the requirement with a concrete example before coding — the reported failure mode was chasing a drifting prompt, not the algorithm.

```python
class _Node:
    __slots__ = ('key', 'prev', 'next')
    def __init__(self, key=None):
        self.key = key
        self.prev = self.next = None

class FirstUniqueLogin:
    def __init__(self):
        self.node = {}                 # userId -> node (currently unique)
        self.dup = set()               # userIds seen more than once
        self.head, self.tail = _Node(), _Node()
        self.head.next, self.tail.prev = self.tail, self.head

    def record(self, user):
        if user in self.dup:
            return
        n = self.node.get(user)
        if n:                          # second login: unlink, mark duplicate
            n.prev.next, n.next.prev = n.next, n.prev
            del self.node[user]
            self.dup.add(user)
            return
        n = _Node(user)                # first login: append at tail
        n.prev, n.next = self.tail.prev, self.tail
        self.tail.prev.next = n
        self.tail.prev = n
        self.node[user] = n

    def first_unique(self):
        return self.head.next.key if self.head.next is not self.tail else -1
# Time: O(1) worst-case per op, Space: O(users)
```

#### ⟂ [Trie-Based Autocomplete](https://www.1point3acres.com/interview/problems/company/oracle/trie-autocomplete) [M] P2 · bank

`trie` `dfs` `design`
Description: Dictionary given once at construction; per prefix query return all matching words. Interviewer requirements: Trie class separated from the orchestrator, dictionary initialized once in the constructor (they explicitly probed "do you rebuild per call?"). Follow-up: rank results by past-query frequency. 30 min coding + 15 follow-ups.

Idea: Build Trie once (O(total chars)); query = walk to prefix node (O(|prefix|)) + DFS subtree collecting words. Frequency ranking: per-word counter in the terminal node; top-K via small max-heap instead of a full sort if the dictionary is large. Trie core from `trie.md#lc-0208` (dict-children form).

```python
import heapq

class TrieNode:
    __slots__ = ('children', 'word', 'count')
    def __init__(self):
        self.children = {}
        self.word = None                   # set on terminal nodes
        self.count = 0                     # times this word was selected

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.children.setdefault(ch, TrieNode())
        node.word = word

    def find_prefix(self, prefix):
        node = self.root
        for ch in prefix:
            node = node.children.get(ch)
            if node is None:
                return None
        return node

class Autocomplete:
    def __init__(self, dictionary):
        self.trie = Trie()                 # built once, in the constructor
        for w in dictionary:
            self.trie.insert(w)

    def record_query(self, word):
        node = self.trie.find_prefix(word)
        if node and node.word:
            node.count += 1

    def suggest(self, prefix, k=None):
        start = self.trie.find_prefix(prefix)
        if start is None:
            return []
        found = []                         # (count, word)
        stack = [start]
        while stack:
            node = stack.pop()
            if node.word is not None:
                found.append((node.count, node.word))
            stack.extend(node.children.values())
        if k is None:
            return [w for _, w in sorted(found, key=lambda t: (-t[0], t[1]))]
        top = heapq.nlargest(k, found, key=lambda t: (t[0], t[1]))
        return [w for _, w in top]
# Time: build O(total chars); query O(|prefix| + matches); Space: O(total chars)
```

#### 232. [Implement a Queue Using Two Stacks](https://www.1point3acres.com/interview/problems/2001e299-bab6-59fb-8991-0b97260848c6) [E] P2 · OJ

`stack` `design`
Description: FIFO queue from two stacks; PUSH / POP / PEEK / EMPTY, amortized O(1) each. OJ form reads q ≤ 2·10⁵ operations from stdin.

Copied from `1.ds-design.md#lc-0232`.

```python
class MyQueue:
    def __init__(self):
        self.in_st = []
        self.out_st = []

    def push(self, x):
        self.in_st.append(x)

    def _move(self):
        if not self.out_st:
            while self.in_st:
                self.out_st.append(self.in_st.pop())

    def pop(self):
        self._move()
        return self.out_st.pop()

    def peek(self):
        self._move()
        return self.out_st[-1]

    def empty(self):
        return not self.in_st and not self.out_st
# Time: amortized O(1) per op, Space: O(n)
```

#### ⟂ [List All LRU Cache Possibilities](https://www.1point3acres.com/interview/problems/8783a1ff-f1f9-404a-b4d1-d006ae36d2a1) [M] P3 · OJ

`design` `backtracking`
Description: Given capacity n (≤ 5), output all possible LRU cache states after n items are added sequentially — n! orderings. Example n=3 → the 6 permutations of [1,2,3].

Idea: Once the cache holds items 1..n, any recency ordering is reachable by a sequence of `get`s, so the state space is exactly the permutations. Implement LRU (above), then emit permutations.

```python
def lru_possibilities(n):
    items = list(range(1, n + 1))
    res, path, used = [], [], [False] * n
    def dfs():
        if len(path) == n:
            res.append(path[:])
            return
        for i in range(n):
            if not used[i]:
                used[i] = True
                path.append(items[i])
                dfs()
                path.pop()
                used[i] = False
    dfs()
    return res
# Time: O(n * n!), Space: O(n)
```

#### 11. [Container With Most Water](https://www.1point3acres.com/interview/problems/company/oracle/container-with-most-water) [M] P1 · bank

`two-pointer`
Description: Max area `(j - i) * min(h[i], h[j])` over all pairs. Asked verbatim in an OCI phone screen (2026-01-06), doubled as a behavioural probe ("how do you approach unfamiliar problems") — narrate the pointer rule out loud. Brute force O(n²) TLEs.

Copied from `0.blind75.md#lc-0011`.

```python
class Solution:
    def maxArea(self, height):
        l, r = 0, len(height) - 1
        best = 0

        while l < r:
            best = max(best, (r - l) * min(height[l], height[r]))
            if height[l] < height[r]:
                l += 1
            else:
                r -= 1

        return best
# Time: O(n), Space: O(1)
```

- Correctness in one paragraph: the shorter side caps the height; moving the taller side can only shrink width without raising the cap, so advancing the shorter side is the only potentially improving move. Prep LC 42 as the follow-up.

#### 73. [Set Matrix Zeros (in-place)](https://www.1point3acres.com/interview/problems/company/oracle/set-matrix-zeros-inplace) [M] P2 · bank (free preview)

`array` `grid`
Description: For every original zero at (i, j), zero out row i and column j **in place** (parallel output matrix rejected). OCI IC4 phone screen (2025-09-11) with two follow-ups: (a) ragged rows — don't cache `len(arr[0])`; recompute `len(arr[i])` per row; (b) generalize to `char[][]` / generic `T` with an arbitrary marker — algorithm unchanged, lift `0` into a parameter.

Example: `[[5,6,8],[2,9,1],[3,0,7]]` → `[[5,0,8],[2,0,1],[0,0,0]]`.

Copied from `0.blind75.md#lc-0073` (O(1)-space marker approach; the two-set version is the expected first answer).

```python
class Solution:
    def setZeroes(self, matrix):
        R, C = len(matrix), len(matrix[0])
        first_row_zero = any(matrix[0][c] == 0 for c in range(C))
        first_col_zero = any(matrix[r][0] == 0 for r in range(R))

        for r in range(1, R):
            for c in range(1, C):
                if matrix[r][c] == 0:
                    matrix[r][0] = 0
                    matrix[0][c] = 0

        for r in range(1, R):
            for c in range(1, C):
                if matrix[r][0] == 0 or matrix[0][c] == 0:
                    matrix[r][c] = 0

        if first_row_zero:
            for c in range(C):
                matrix[0][c] = 0
        if first_col_zero:
            for r in range(R):
                matrix[r][0] = 0
# Time: O(R*C), Space: O(1)
```

```python
def set_zeros_ragged(arr, marker=0):
    zero_rows, zero_cols = set(), set()
    for i in range(len(arr)):
        for j in range(len(arr[i])):           # ragged-safe: per-row length
            if arr[i][j] == marker:
                zero_rows.add(i)
                zero_cols.add(j)
    for i in range(len(arr)):
        for j in range(len(arr[i])):
            if i in zero_rows or j in zero_cols:
                arr[i][j] = marker
# Time: O(cells), Space: O(m + n)
```

#### ⟂ [Valid 5-Card Poker Straight](https://www.1point3acres.com/interview/problems/company/oracle/valid-poker-straight) [E] P2 · bank

`set`
Description: Five ranks from {A, 2..10, J, Q, K} (suits irrelevant); are they five consecutive ranks? J/Q/K = 11/12/13; Ace plays low (A-2-3-4-5) or high (10-J-Q-K-A); duplicates → false. Oracle Health phone screen (2025-10-22), 5 BQs + this one problem — clean code beats cleverness.

Idea: Set check: straight ⟺ 5 distinct values with max − min == 4; try Ace = 1, retry Ace = 14.

```python
def is_straight(cards):
    rank = {'A': 1, 'J': 11, 'Q': 12, 'K': 13}
    vals = [rank[c] if c in rank else int(c) for c in cards]

    def consecutive(v):
        s = set(v)
        return len(s) == 5 and max(s) - min(s) == 4

    if consecutive(vals):
        return True
    if 1 in vals:
        return consecutive([14 if v == 1 else v for v in vals])
    return False
# Time: O(1) (five cards), Space: O(1)
```

- Trace both trick cases aloud: `[A,2,3,4,5]` and `[10,J,Q,K,A]` → true.

#### 152. [Maximum Product Subarray in O(n)](https://www.1point3acres.com/interview/problems/7b99193e-c69f-4941-a0be-8ccf49a291c8) [M] P2 · OJ

`dp`
Description: Largest product of a contiguous subarray; O(n) required. `[2,3,-2,4]` → 6; `[-2,0,-1]` → 0.

Copied from `0.blind75.md#lc-0152`.

```python
class Solution:
    def maxProduct(self, nums):
        cur_max = cur_min = ans = nums[0]

        for x in nums[1:]:
            if x < 0:
                cur_max, cur_min = cur_min, cur_max
            cur_max = max(x, cur_max * x)
            cur_min = min(x, cur_min * x)
            ans = max(ans, cur_max)

        return ans
# Time: O(n), Space: O(1)
```

#### 57. [Insert Intervals (with Set)](https://www.1point3acres.com/interview/problems/c7b0a764-6082-4594-b239-e18448718a1c) [M] P2 · OJ

`intervals`
Description: Insert `newInterval` into sorted non-overlapping `intervals`, merging as needed. `[[1,3],[6,9]] + [2,5]` → `[[1,5],[6,9]]`. The OJ phrasing mentions a self-sorting set — in Java, a `TreeMap` works; the linear three-phase scan is cleaner.

Copied from `0.blind75.md#lc-0057`.

```python
class Solution:
    def insert(self, intervals, newInterval):
        res = []
        i = 0
        n = len(intervals)
        start, end = newInterval

        while i < n and intervals[i][1] < start:
            res.append(intervals[i])
            i += 1

        while i < n and intervals[i][0] <= end:
            start = min(start, intervals[i][0])
            end = max(end, intervals[i][1])
            i += 1
        res.append([start, end])

        while i < n:
            res.append(intervals[i])
            i += 1

        return res
# Time: O(n), Space: O(n) for output
```

#### 167. [Two Sum II — Sorted Input](https://www.1point3acres.com/interview/problems/9bc68058-8904-40c4-a4c6-d16a67b418f4) [E] P2 · OJ ("Leetcode Two Pointers Original Question")

Description: Sorted ascending array; return 1-based indices of the pair summing to target. Constant extra space + O(n) required; exactly one solution.

```python
def two_sum_sorted(numbers, target):
    l, r = 0, len(numbers) - 1
    while l < r:
        s = numbers[l] + numbers[r]
        if s == target:
            return [l + 1, r + 1]
        if s < target:
            l += 1
        else:
            r -= 1
    return []
# Time: O(n), Space: O(1)
```

#### ⟂ [Maximum on Both Sides](https://www.1point3acres.com/interview/problems/f547b32a-e42e-4a0e-899e-a8d686990998) [M] P2 · OJ · ambiguous spec

`sliding-window` `ambiguous-spec`
Description (as scraped, internally inconsistent): "Given an array and a sliding window size k, find the maximum on both sides of each sliding window; output left/right maxima per position." Test case: `[1,3,-1,-3,5,3,6,7], k=3` → `[(1,-3),(3,5),(5,6),(6,7)]` — the stated pairs don't line up with any standard reading (n−k+1 = 6 windows, 4 outputs). Treat like the site's other `ambiguous-spec` questions: reconstruct the rule from the example with the interviewer before coding.

Idea: Every plausible interpretation reduces to two standard tools — drill both:

```python
from collections import deque

def sliding_window_max(nums, k):
    dq = deque()                       # indices, values decreasing
    out = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            out.append(nums[dq[0]])
    return out
# Time: O(n), Space: O(k)


def prefix_suffix_max(nums):
    n = len(nums)
    pre, suf = nums[:], nums[:]
    for i in range(1, n):
        pre[i] = max(pre[i - 1], pre[i])
    for i in range(n - 2, -1, -1):
        suf[i] = max(suf[i + 1], suf[i])
    return pre, suf                    # max left-of / right-of any split in O(1)
# Time: O(n), Space: O(n)
```

#### 88. [Merge 2 Sorted Arrays](https://www.1point3acres.com/interview/problems/oracle-merge-arrays) [E] P3 · OJ legacy

`two-pointer`
Description: Merge two sorted arrays into one non-decreasing array. `[1,2,3] + [2,5,5]` → `[1,2,2,3,5,5]`. (In-place tail-merge variant solved in `0.Tiktok.md` §88.)

```python
def merge_arrays(a, b):
    i = j = 0
    out = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    out.extend(a[i:])
    out.extend(b[j:])
    return out
# Time: O(m + n), Space: O(m + n)
```

#### ⟂ [Minimum Difference Sum](https://www.1point3acres.com/interview/problems/oracle-min-diff) [E] P3 · OJ legacy

`math` `greedy`
Description: Rearrange the array to minimize the sum of absolute differences of adjacent elements; return that sum. `[1,3,3,2,4]` → 3.

Idea: Sorted order is optimal (any inversion can be uncrossed without increasing the sum), and then the telescoping sum of adjacent gaps is just `max − min`.


Idea: One pass with a stack of effective group signs; each variable emits with `group_sign * pending_sign`.

```python
def simplify(expr):
    out = []
    signs = [1]                    # effective sign of enclosing groups
    sign = 1                       # sign attached to the next token
    for ch in expr:
        if ch == '+':
            sign = 1
        elif ch == '-':
            sign = -1
        elif ch == '(':
            signs.append(signs[-1] * sign)
            sign = 1
        elif ch == ')':
            signs.pop()
        elif ch != ' ':
            eff = signs[-1] * sign
            if out or eff < 0:
                out.append('-' if eff < 0 else '+')
            out.append(ch)
            sign = 1
    return ''.join(out)
# Time: O(n), Space: O(depth)
```

```python
            return

        remaining -= node.val
        if not node.left and not node.right and remaining == 0:
```

```python
def forest_order(courses, prereq):       # prereq: course -> its single prereq or None
    children = {c: [] for c in courses}
    roots = []
    for c in courses:
        p = prereq.get(c)
        if p is None:
            roots.append(c)
        else:
            children[p].append(c)
    out = []
    for r in sorted(roots):
        stack = [r]
        while stack:
            u = stack.pop()
            out.append(u)
            stack.extend(sorted(children[u], reverse=True))
    return out
# Time: O(n log n), Space: O(n)


def all_orders(n, prereqs):              # OJ variant: every topological order
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in prereqs:                 # b before a
        adj[b].append(a)
        indeg[a] += 1
    res, path = [], []
    used = [False] * n
    def dfs():
        if len(path) == n:
            res.append(path[:])
            return
        for u in range(n):               # ascending → paths come out sorted
            if not used[u] and indeg[u] == 0:
                used[u] = True
                path.append(u)
                for v in adj[u]:
                    indeg[v] -= 1
                dfs()
                for v in adj[u]:
                    indeg[v] += 1
                path.pop()
                used[u] = False
    dfs()
    return res
# Time: O(n! * n) worst-case, Space: O(n)
```

```python
    def find(x):
        parent.setdefault(x, x)
        size.setdefault(x, 1)
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    last = 0

        if q == 'Friend':

                if size[ra] < size[rb]:
                    ra, rb = rb, ra
                parent[rb] = ra
                size[ra] += size[rb]
        else:

    return last
```

#### ⟂ [Minimum Sum After K Halvings (Max-Heap)](https://www.1point3acres.com/interview/problems/company/oracle/min-sum-after-k-halvings) [M] P1 · bank

`heap` `greedy`
Description: Non-negative array; an operation replaces one element with `ceil(x / 2)`; at most k operations; minimize the final sum. Oracle Health AI VO round 3 (2025-08-06) — the reporting candidate TLE'd on hidden tests, suspecting zero handling. LC 1962 shape.

Idea: Greedy — always halve the current max (removes `x - ceil(x/2)` ≈ x/2, the largest possible drop). Skip zeros and stop at all-ones/empty so the loop can't spin uselessly. Python ceil-halve without imports: `(x + 1) // 2`; Java: `(x + 1) >> 1`.

```python
import heapq

def min_sum_after_k_halvings(nums, k):
    total = sum(nums)
    heap = [-x for x in nums if x > 1]     # 0s and 1s can't shrink
    heapq.heapify(heap)
    for _ in range(k):
        if not heap:
            break
        x = -heapq.heappop(heap)
        half = (x + 1) // 2                # ceiling division
        total -= x - half
        if half > 1:
            heapq.heappush(heap, -half)
    return total
# Time: O(n + k log n), Space: O(n)
```

```python
from abc import ABC, abstractmethod

class PriceCalculator(ABC):
    @abstractmethod
    def line_items(self, shopping_list): ...

class DiscountCalculator(PriceCalculator):
    def __init__(self, items, discounts):
        self.price = dict(items)
        self.discount = dict(discounts)          # item -> fraction off

    def line_items(self, shopping_list):
        out = []
        for item in shopping_list:
            p = self.price[item]
            out.append((item, p, p * (1 - self.discount.get(item, 0.0))))
        return out
# Time: O(n), Space: O(items)
```

#### ⟂ [REST API: Medical Records by Age](https://www.1point3acres.com/interview/problems/company/oracle/rest-api-medical-records-by-age) [M] P1 · bank + OJ

`api` `ambiguous-spec`
Description: `getRecordsByAgeGroup(ageStart, ageEnd, bpDiff) -> int[]`. Paginated GET `<base_url>?page=N` (`page/per_page/total/total_pages/data`); each record: id, UTC-ms timestamp, userDob `DD-MM-YYYY`, vitals with diastolic/systolic BP. Keep records where the patient's **age at record creation** ∈ [ageStart, ageEnd] AND the BP predicate holds; return IDs ascending, `[-1]` if none. Phone screen 2026-07-31, AI assistance banned. ⚠ The prompt contradicts itself on the BP rule — filter text says `diastole - systole > bpDiff`, function text says "difference … less than bpDiff": **clarify before coding** (OJ judge uses `diastole - systole > bpDiff`). Example: `(28, 30, 63)` → `[31]`.

Idea: Fetch page 1, read total_pages, fetch the rest; compute age against the record's UTC date (year diff minus one if before the birthday); isolate the ambiguous predicate in ONE helper so the resolved rule can't drift.

```python
import json
import urllib.request
from datetime import datetime, timezone

def get_records_by_age_group(base_url, age_start, age_end, bp_diff):
    ids = []
    page, total_pages = 1, 1
    while page <= total_pages:
        with urllib.request.urlopen(f"{base_url}?page={page}") as resp:
            body = json.load(resp)
        total_pages = body["total_pages"]
        for rec in body["data"]:
            created = datetime.fromtimestamp(rec["timestamp"] / 1000, tz=timezone.utc)
            dob = datetime.strptime(rec["userDob"], "%d-%m-%Y")
            age = created.year - dob.year - (
                (created.month, created.day) < (dob.month, dob.day))
            v = rec["vitals"]
            if age_start <= age <= age_end and bp_matches(v, bp_diff):
                ids.append(rec["id"])
        page += 1
    return sorted(ids) if ids else [-1]

def bp_matches(vitals, bp_diff):       # the ONE place the clarified rule lives
    return vitals["bloodPressureDiastole"] - vitals["bloodPressureSystole"] > bp_diff
# Time: O(R + K log K) + page requests, Space: O(K)
```

- Test the birthday boundary (day before / on / after) and a leap-day birth in a non-leap year; don't infer completion from a short page — trust `total_pages`.

#### ⟂ [ML Coding — Handwritten MHA + Sparse Matmul](https://www.1point3acres.com/interview/problems/company/oracle/ml-coding-mha-sparse-matmul) [M] P2 · bank (MLE loops only)

`numpy` `ml`
Description: 90-min phone screen, Oracle AI org Senior Principal MLE (2026-01-22). (1) `multi_head_attention(Q, K, V, num_heads, mask=None)` from scratch — no `nn.MultiheadAttention` / `F.scaled_dot_product_attention`; shapes (batch, seq, d_model), causal mask optional. (2) Sparse matmul over (row, col, value) triples, beating dense O(n·m·p).

```python
import numpy as np

def multi_head_attention(Q, K, V, num_heads, mask=None):
    B, S, D = Q.shape
    dk = D // num_heads

    def split(x):                          # (B, S, D) -> (B, H, S, dk)
        return x.reshape(B, S, num_heads, dk).transpose(0, 2, 1, 3)

    q, k, v = split(Q), split(K), split(V)
    scores = q @ k.transpose(0, 1, 3, 2) / np.sqrt(dk)     # (B, H, S, S)
    if mask is not None:                   # e.g. causal: lower-triangular True
        scores = np.where(mask, scores, -1e9)
    scores = scores - scores.max(axis=-1, keepdims=True)   # stable softmax
    w = np.exp(scores)
    w = w / w.sum(axis=-1, keepdims=True)
    out = w @ v                                            # (B, H, S, dk)
    return out.transpose(0, 2, 1, 3).reshape(B, S, D)
# Time: O(B*H*S^2*dk), Space: O(B*H*S^2)


def sparse_matmul(a_triples, b_triples):
    b_rows = {}
    for r, c, v in b_triples:
        b_rows.setdefault(r, []).append((c, v))
    out = {}
    for r, c, v in a_triples:              # a_col must equal b_row
        for c2, v2 in b_rows.get(c, []):
            out[(r, c2)] = out.get((r, c2), 0) + v * v2
    return [(r, c, v) for (r, c), v in out.items() if v]
# Time: O(nnz(A) * avg_row_density(B)), Space: O(nnz(C))
```

- MHA bug list from the report: dropped 1/√dk scaling, softmax over the wrong axis, forgetting to merge heads before the output projection. Sparse edges: shape mismatch, duplicate triples (sum first), zero rows.
- With real weights, add four `nn.Linear(D, D)` projections for Q/K/V/out.

#### ⟂ [Multithreading — Print Thread IDs in Order](https://www.1point3acres.com/interview/problems/2543c618-5a05-4ba0-b994-dfc0a7596470) [E] P2 · OJ

`concurrency`
Description: Python; 5 threads; each prints `Thread i: i`; output must come out in order 1..5.

```python
import threading

def worker(tid):
    print(f"Thread {tid}: {tid}")

def run_sequential():
    for i in range(1, 6):              # trivially correct: start+join serializes
        t = threading.Thread(target=worker, args=(i,))
        t.start()
        t.join()

def run_semaphore_chain():             # all started up front, order enforced
    sems = [threading.Semaphore(0) for _ in range(7)]
    def gated(tid):
        sems[tid].acquire()
        worker(tid)
        sems[tid + 1].release()
    threads = [threading.Thread(target=gated, args=(i,)) for i in range(1, 6)]
    for t in threads:
        t.start()
    sems[1].release()                  # open the chain
    for t in threads:
        t.join()
# Time: O(n), Space: O(n)
```

- Say the trade-off: start+join has no real concurrency; the semaphore chain runs all threads and serializes only the print — that's the version that shows you know synchronization. GIL caveat if asked. Java odd/even printer twin: `1o/1.coding/1.coding-1.md#java-odd-even`.
