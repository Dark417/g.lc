#### 146. [LRU Cache + TTL Expiration](https://www.1point3acres.com/interview/problems/company/oracle/lru-cache-with-expiration) [M] P1 · bank + OJ ×2

`design` `hashmap` `linked-list` `ttl`  
Description: `get(key)` / `put(key, value)` in O(1); evict the least-recently-used key when over capacity. Oracle follow-up: per-entry expiration (TTL) — an expired entry must read as absent on `get`, even before capacity eviction. Last asked 2026-04-14, onsite. OJ also lists it as "Design a Cache" (fixed size, LRU/LFU/FIFO strategy, put/get/delete in O(1), 1000-entry limit).

Idea: Hash map key → node in a doubly linked list ordered by recency; sentinels remove null checks. For TTL, store `expires_at` per node and check lazily on access; contrast with active eviction (background sweeper) before coding.

Base copied from `1o/1.coding/1.coding-1.md#lc-0146`; TTL extension added.

```python
import time

class Node:
    __slots__ = ('key', 'val', 'expires_at', 'prev', 'next')
    def __init__(self, key=0, val=0, expires_at=None):
        self.key, self.val, self.expires_at = key, val, expires_at
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.map = {}
        self.head, self.tail = Node(), Node()      # head.next = most recent
        self.head.next, self.tail.prev = self.tail, self.head

    def _unlink(self, n):
        n.prev.next, n.next.prev = n.next, n.prev

    def _push_front(self, n):
        n.next, n.prev = self.head.next, self.head
        self.head.next.prev = n
        self.head.next = n

    def get(self, key):
        n = self.map.get(key)
        if n is None:
            return -1
        if n.expires_at is not None and time.time() >= n.expires_at:
            self._unlink(n)                        # lazy TTL eviction
            del self.map[key]
            return -1
        self._unlink(n); self._push_front(n)
        return n.val

    def put(self, key, value, ttl=None):
        n = self.map.get(key)
        if n:
            n.val = value
            n.expires_at = time.time() + ttl if ttl else None
            self._unlink(n); self._push_front(n)
            return
        if len(self.map) == self.cap:
            lru = self.tail.prev
            self._unlink(lru)
            del self.map[lru.key]
        n = Node(key, value, time.time() + ttl if ttl else None)
        self.map[key] = n
        self._push_front(n)
# Time: O(1) get/put, Space: O(capacity)
```

- Say the `OrderedDict` version exists (`move_to_end` / `popitem(last=False)`), then write the linked list.
- Lazy vs active expiration: lazy keeps O(1) worst-case but dead entries occupy capacity until touched; active needs a background sweeper or a min-heap on expiry (O(log n)). Redis does both — lazy on access + sampled active eviction.
- Thread-safe follow-up: coarse `synchronized`/lock first, then striped locks — full Java versions in `1.coding-1.md#java-lru-ts` and `1.ds-design-java.md` S2/S4.

#### Concurrent Task Processor (Java LLD) [M] P1

`concurrency` `design`  
Description: 从 input channel 收 integer tasks, 并发处理 (print), 单任务失败不影响其他, 结果存储, 可扩展任意任务数. 报告人用裸 Thread 被挑 — 面试官要线程池级别的并发词汇.

```java
class TaskProcessor {
    private final ExecutorService pool = Executors.newFixedThreadPool(
            Runtime.getRuntime().availableProcessors());
    private final Queue<Integer> results = new ConcurrentLinkedQueue<>();
    private final Queue<Integer> failed = new ConcurrentLinkedQueue<>();

    void submit(int task) {
        CompletableFuture
            .supplyAsync(() -> process(task), pool)   // 并发执行
            .whenComplete((r, ex) -> {                // 失败被 per-task future 隔离
                if (ex == null) results.add(r);
                else failed.add(task);
            });
    }

    private int process(int task) {
        System.out.println(task);
        return task;
    }

    void shutdown() throws InterruptedException {
        pool.shutdown();
        pool.awaitTermination(1, TimeUnit.MINUTES);
    }
}
```

- 说点: Thread → ExecutorService 的理由 (复用/背压/上限); channel 语义接 BlockingQueue producer-consumer (`1.coding-1.md#java-prod-cons`); 存储用并发容器.

#### Replicated Active–Passive Hashmap (LLD) [M] P1

`design` `concurrency` `replication`  
Description: 一写一读的 hashmap; 写操作同步复制到 passive 副本, 复制失败则整个写失败 (fail-fast, 不留分叉). OCI IC4 onsite LLD 轮.

```java
class ReplicatedMap<K, V> {
    private final Map<K, V> active = new ConcurrentHashMap<>();
    private final Replica<K, V> passive;           // secondary copy

    ReplicatedMap(Replica<K, V> passive) { this.passive = passive; }

    synchronized void put(K key, V value) {        // single writer -> coarse lock ok
        V old = active.get(key);
        active.put(key, value);
        try {
            passive.replicate(key, value);         // synchronous; blocks the writer
        } catch (Exception e) {
            if (old == null) active.remove(key);   // rollback: write is atomic
            else active.put(key, old);
            throw new IllegalStateException("replication failed", e);
        }
    }

    V get(K key) { return active.get(key); }       // reader hits active only
}
```

- 讨论点: 同步复制的延迟代价 vs 强一致; rollback 保证 active/passive 不分叉; failover (提升 passive) + fencing; 多写者时换 per-key lock 或版本号 CAS.

#### 200. [Number of Islands + Max Height of Each Island](https://www.1point3acres.com/interview/problems/company/oracle/number-of-islands) [M] P1 · bank + OJ variant

`dfs` `graph`  
Description: Count 4-directionally connected islands of '1's; interviewer asks time AND space right after tests pass (recursive DFS worst-case stack is O(m·n)). Phone screen, last 2026-04-14, run on HackerRank. OJ variant "[Maximum Height of Each Island](https://www.1point3acres.com/interview/problems/712ca994-03d3-589e-9d9b-9ea213f907da)": grid of heights (0 = water); output each island's max height in row-major first-encounter order; m, n ≤ 500.

Copied from `0.blind75.md#lc-0200`.

```python
class Solution:
    def numIslands(self, grid):
        if not grid:
            return 0

        rows, cols = len(grid), len(grid[0])
        islands = 0

        def dfs(r, c):
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != "1":
                return
            grid[r][c] = "0"
            dfs(r + 1, c)
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == "1":
                    islands += 1
                    dfs(r, c)

        return islands
# Time: O(R*C), Space: O(R*C) recursion stack worst-case
```

Variant — max height per island, scan order (iterative to survive 500×500):

```python
def island_max_heights(heights):
    m, n = len(heights), len(heights[0])
    seen = [[False] * n for _ in range(m)]
    res = []
    for r in range(m):
        for c in range(n):
            if heights[r][c] and not seen[r][c]:
                best = 0
                stack = [(r, c)]
                seen[r][c] = True
                while stack:
                    i, j = stack.pop()
                    best = max(best, heights[i][j])
                    for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        x, y = i + di, j + dj
                        if 0 <= x < m and 0 <= y < n and heights[x][y] and not seen[x][y]:
                            seen[x][y] = True
                            stack.append((x, y))
                res.append(best)
    return res
# Time: O(m*n), Space: O(m*n)
```

#### 121. [Best Time to Buy and Sell Stock — Single Transaction](https://www.1point3acres.com/interview/problems/company/oracle/single-transaction-stock-profit) [E] P1 · bank + OJ ×2

`array`  
Description: One buy then one later sell; return max profit, 0 if none. Last asked 2026-08-19 onsite; appears three times across the page (bank + two OJ listings) — highest-signal easy in the set. n ≤ 2·10⁵.

Example: `7 1 5 3 6 4` → `5`.

Copied from `0.blind75.md#lc-0121`.

```python
class Solution:
    def maxProfit(self, prices):
        min_price = float("inf")
        best = 0

        for p in prices:
            min_price = min(min_price, p)
            best = max(best, p - min_price)

        return best
# Time: O(n), Space: O(1)
```

- Invariant in two sentences: `min_price` is the cheapest valid buy at or before today, so every candidate profit sells after its buy. Never-rising prices → 0 (no trade).

Follow-up — 不限交易次数 (LC 122): 吃掉所有上涨段:

```python
def maxProfitUnlimited(prices):
    return sum(max(0, b - a) for a, b in zip(prices, prices[1:]))
# Time: O(n), Space: O(1)
```

#### [Max Completable Tasks / Deploy Packages in Dependency Order](https://www.1point3acres.com/interview/problems/company/oracle/course-prerequisites-task-count) [M] P1 · bank (2 reports) + OJ ×2

`topo` `graph`  
Description: Tasks with prerequisites; cycles make tasks (and everything depending on them) impossible. Three return shapes have been asked — **confirm which before coding** (a reported candidate solved the algorithm but returned the wrong shape):

- Count of completable tasks (`n=4, [[1,0],[2,1],[3,2]]` → 4; `n=2, [[1,0],[0,1]]` → 0) — this round.
- Boolean all-completable (LC 207).
- Ordered deployment list, empty on cycle (LC 210 — the OJ "Deploy Packages" form, n ≤ 2·10⁵, m ≤ 5·10⁵).

Idea: Kahn's algorithm covers all three: count pops / compare to n / return the pop order. From `1o/1.coding/1.coding-1.md#lc-0207`.

```python
from collections import deque

def max_completable(n, prerequisites):
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in prerequisites:           # b before a
        adj[b].append(a)
        indeg[a] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return len(order)                    # LC 207: == n ; LC 210: order or []
# Time: O(V + E), Space: O(V + E)
```

- Edge cases: no-prereq tasks always completable; a self-loop is a 1-node cycle.
- The HackerRank I/O interface was the reported time sink — pin the output format in the first 3 minutes.

#### 253. [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/) [M] P1

`intervals` `heap`  
Description: 最少会议室数. "类似 meeting room 的 interval 题" 与 "最小进程数" 都按此准备. 同族备齐: 56 Merge Intervals, 57 Insert Interval, 252.

⧉ Copied from `0.blind75.md#lc-0253`.

```python
import heapq

class Solution:
    def minMeetingRooms(self, intervals):
        if not intervals:
            return 0

        intervals.sort(key=lambda x: x[0])
        heap = []

        for start, end in intervals:
            if heap and heap[0] <= start:
                heapq.heapreplace(heap, end)
            else:
                heapq.heappush(heap, end)

        return len(heap)
# Time: O(n log n), Space: O(n)
```

```python
        events.append((s, 1))
        events.append((e, -1))

    for _, d in events:
        rooms += d
```

#### FPS Event Throttling (359 family) [M] P1

`design` `hashmap` `rate-limiting`  
Description: 游戏按键事件 (shoot/reload/grenade) — 同一 event type 在 delay 期内只触发一次, 期内重复忽略, 各 type 独立. delay=5, [("shoot",1),("shoot",2),("reload",3),("shoot",6)] → [true,false,true,true]. = 359 Logger Rate Limiter 形态; Senior 电面.

```java
public class EventThrottler {
    private final Map<String, Long> last = new ConcurrentHashMap<>();
    private final long delay;

    public EventThrottler(long delay) { this.delay = delay; }

    public boolean shouldTrigger(String event, long now) {
        long[] fired = {0};
        last.compute(event, (k, prev) -> {   // atomic per-key: no check-then-act race
            if (prev == null || now - prev >= delay) { fired[0] = 1; return now; }
            return prev;
        });
        return fired[0] == 1;
    }
}
// Time: O(1) per event, Space: O(distinct event types)
```

- 说点: timestamp 作参数 (可测试, 匹配题面逻辑时间); 裸 ConcurrentHashMap 仍有 check-then-act race, 用 `compute` 原子化; event type 无界时要清理 (定期 sweep / LRU 上限).

#### [Simplified Redis-Like KV / List Store](https://www.1point3acres.com/interview/problems/company/oracle/simplified-redis-kv-store) [M] P2 · bank

`design` `in-memory-db`  
Description: OCI screening problem (2026-02-04, asked in Go). Implement: `set(key, value)` (string, override); `list_push(key, value)` (push to head, auto-create); `get(key)` (returns string or list); `list_remove(key, value, count)` — count > 0: first `count` matches from head; count < 0: last `|count|` from tail; count == 0: all matches. TTL explicitly deferred as follow-up.

Idea: Dict with tagged values (kind + payload); type mismatch on `list_push` over a string is a Redis WRONGTYPE error — confirm. Single RW lock is the right concurrency start.

```python
class MiniRedis:
    def __init__(self):
        self.store = {}                    # key -> ('str', s) | ('list', [..])

    def set(self, key, value):
        self.store[key] = ('str', value)

    def list_push(self, key, value):
        kind, lst = self.store.get(key, ('list', []))
        if kind != 'list':
            raise TypeError('WRONGTYPE')
        lst.insert(0, value)               # deque for O(1) in production
        self.store[key] = ('list', lst)

    def get(self, key):
        entry = self.store.get(key)
        return entry[1] if entry else None

    def list_remove(self, key, value, count):
        entry = self.store.get(key)
        if not entry or entry[0] != 'list':
            return 0
        lst = entry[1]
        removed = 0
        idxs = range(len(lst)) if count >= 0 else range(len(lst) - 1, -1, -1)
        limit = abs(count) if count else len(lst)
        keep = [True] * len(lst)
        for i in idxs:
            if removed == limit:
                break
            if lst[i] == value:
                keep[i] = False
                removed += 1
        self.store[key] = ('list', [x for i, x in enumerate(lst) if keep[i]])
        return removed
# Time: O(n) list_remove, O(1) set/get, Space: O(total entries)
```

- TTL follow-up: lazy expiration on access + optional background sweeper (real Redis adds sampled active eviction).
- Edge cases to confirm: `list_push` on a string key (error vs overwrite), `list_remove` on missing key (no-op).

Description: OCI virtual-onsite hybrid (2026-02-04, 60 min). 1,000 doctors, 9 AM–5 PM in 15-minute slots → 32 slots per doctor-day. `POST /appointments {doctorId, date}` books the first available slot for that doctor/date, returns the slot or an error when full; state persists across calls.

Idea: `(doctorId, date) → 32-bit mask`; first free slot = lowest zero bit; O(1) per booking. The point is the concurrency + persistence story, not scale: per-doctor lock or CAS on the bitset; DB schema `appointments(doctor_id, date, slot_index, ...)` with a unique constraint on `(doctor_id, date, slot_index)`.

```python
class AppointmentBooker:
    SLOTS = 32                              # 9:00-17:00 in 15-min slots

    def __init__(self):
        self.booked = {}                    # (doctor_id, date) -> bitmask

    def book(self, doctor_id, date):
        mask = self.booked.get((doctor_id, date), 0)
        if mask == (1 << self.SLOTS) - 1:
            return None                     # 409: no availability
        slot = (~mask & (mask + 1)).bit_length() - 1   # lowest zero bit
        self.booked[(doctor_id, date)] = mask | (1 << slot)
        h, m = divmod(slot * 15, 60)
        return f"{9 + h:02d}:{m:02d}-{9 + (slot + 1) * 15 // 60:02d}:{(slot + 1) * 15 % 60:02d}"
# Time: O(1) per booking, Space: O(doctor-days touched)
```

```python
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
```

```python
    adj = {}
    owner = {}
    for name, *emails in accounts:
        for e in emails:
            owner[e] = name
            adj.setdefault(e, set()).update(emails)

            comp.append(cur)
```

```python
def isqrt(x):
    if x < 2:
        return x
    lo, hi = 1, x // 2
    while lo <= hi:
        mid = (lo + hi) // 2
        if mid * mid <= x:
            lo = mid + 1
        else:
            hi = mid - 1
    return hi
# Time: O(log x), Space: O(1)


def sqrt_below_one(x, eps=1e-9):

            lo = mid
        else:
            hi = mid
    return lo
```

Idea: The answer is always a suffix (extending right never hurts: a longer string beats its own prefix). LC 1163 two-pointer champion scan finds the best suffix start in O(n): candidate i vs challenger j with matched length k.

```python
def last_substring(s):
    n = len(s)
    i, j, k = 0, 1, 0                  # i best suffix, j challenger, k matched
    while j + k < n:
        if s[i + k] == s[j + k]:
            k += 1
        elif s[i + k] > s[j + k]:
            j = j + k + 1              # challenger loses; skip past mismatch
            k = 0
        else:
            i = max(i + k + 1, j)      # champion loses
            j = i + 1
            k = 0
    return s[i:]
# Time: O(n), Space: O(1)
```

```python
def all_paths(grid):
    m, n = len(grid), len(grid[0])
    res, path = [], []
    def dfs(r, c):
        if r == m - 1 and c == n - 1:
            res.append(''.join(path))
            return

            dfs(r, c + 1)
            path.pop()
    if grid[0][0]:
        dfs(0, 0)
```

```python
from collections import deque

def bottom_view(root):
    if not root:
        return []
    view = {}                            # col -> val, last write wins
    q = deque([(root, 0)])
    while q:
        node, col = q.popleft()
        view[col] = node.val
        if node.left:
            q.append((node.left, col - 1))
        if node.right:
            q.append((node.right, col + 1))
```

#### [Merge K Sorted (Key, Value) Lists with Later Override](https://www.1point3acres.com/interview/problems/company/oracle/merge-k-sorted-key-value-lists) [M] P1 · bank + OJ

Description: k linked lists of (key, value) pairs, each sorted ascending by key, keys unique within a list. On key collision across lists, the **highest list index wins**. Return one merged sorted list. OCI Consultant Engineer phone screen (2025-11-20); the interviewer probed heap polarity (min-heap on key is correct — override resolution is separate).

Example: `l0=[(1,70),(3,20),(5,30)] l1=[(2,40),(3,50)] l2=[(1,15),(4,80),(5,90)]` → `[(1,15),(2,40),(3,50),(4,80),(5,90)]`.

Idea: LC 23 heap merge from `1o/1.coding/1.coding-1.md#lc-0023`, plus: after popping a key, drain every heap entry with the same key and keep the value from the largest list index.

```python
import heapq

class KVNode:
    def __init__(self, key, val, nxt=None):
        self.key, self.val, self.next = key, val, nxt

def merge_kv_lists(lists):
    heap = [(node.key, i, node) for i, node in enumerate(lists) if node]
    heapq.heapify(heap)
    dummy = tail = KVNode(0, 0)
    while heap:
        key, i, node = heapq.heappop(heap)
        best_i, best_val = i, node.val
        if node.next:
            heapq.heappush(heap, (node.next.key, i, node.next))
        while heap and heap[0][0] == key:       # drain same-key entries
            _, j, dup = heapq.heappop(heap)
            if j > best_i:
                best_i, best_val = j, dup.val
            if dup.next:
                heapq.heappush(heap, (dup.next.key, j, dup.next))
        tail.next = KVNode(key, best_val)
        tail = tail.next
    return dummy.next
# Time: O(N log k), Space: O(k)
```

- Follow-up asked: huge k, short lists — no asymptotic win without structural assumptions; the log k pop factor is the floor.

```python
from collections import Counter

def findAnagrams(s, p):
    if len(p) > len(s):
        return []
    need = Counter(p)
    window = Counter(s[:len(p)])
    res = [0] if window == need else []
    for i in range(len(p), len(s)):
        window[s[i]] += 1
        left = s[i - len(p)]
        window[left] -= 1
        if window[left] == 0:
            del window[left]
        if window == need:
            res.append(i - len(p) + 1)
    return res
# Time: O(26 * n), Space: O(26)
```

#### 1309. [Decrypt String from Alphabet to Integer Mapping](https://leetcode.com/problems/decrypt-string-from-alphabet-to-integer-mapping/) [E] P1 · 补充

`string` `parsing`  
Description: `'1'`-`'9'` map to `a`-`i`; `'10#'`-`'26#'` map to `j`-`z`; decode the string. `"10#11#12"` → `"jkl"`. Neighbor of the decode family (394). (Old solution also in `24_G` 2020 files.)

```python
def freqAlphabets(s):
    out = []
    i = 0
    while i < len(s):
        if i + 2 < len(s) and s[i + 2] == '#':
            out.append(chr(ord('a') + int(s[i:i + 2]) - 1))
            i += 3
        else:
            out.append(chr(ord('a') + int(s[i]) - 1))
            i += 1
    return ''.join(out)
# Time: O(n), Space: O(n)
```

#### 134. [Gas Station](https://leetcode.com/problems/gas-station/) [M] P1 · 补充

`greedy` `array`  
Description: Circular route; `gas[i]` fuel at station i, `cost[i]` to reach i+1. Return the start index that completes the circuit, or -1.

Idea: If total gas ≥ total cost an answer exists; whenever the running tank goes negative, no station in that prefix can be the start — reset start to the next station.

⧉ Copied from `0.nc150.md` §134.

```python
class Solution:
    def canCompleteCircuit(self, gas, cost):
        if sum(gas) < sum(cost):
            return -1

        start = 0
        tank = 0
        for i in range(len(gas)):
            tank += gas[i] - cost[i]
            if tank < 0:
                tank = 0
                start = i + 1

        return start
# Time: O(n), Space: O(1)
```
