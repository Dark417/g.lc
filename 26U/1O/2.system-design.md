## 1. How Oracle runs SD rounds

```
"Design X" (often vague) → you scope → simple v1 → interviewer adds requirement → scale → add another → tradeoffs
```

- Start simple, iterate — they explicitly reward "grungy solution now" (Act now, iterate)
- Ambiguous prompts on purpose: they watch how you scope and what you ask
- Expect API + schema + HLD in one round for LLD-flavored prompts
- Expect "give me two approaches to the locking problem" — always have an alternative
- HM round: draw *your* system, then defend under "why not Y"

## 3. What interviewers probe

- Scoping: FRs, non-goals, scale numbers you *ask for*
- Data model + API contracts; REST idempotence; pagination
- Caching + invalidation; stampede
- Concurrency / locking — two approaches (optimistic vs pessimistic; lease vs lock)
- Consistency model per store; what breaks under partition
- Security: OAuth2, mTLS, authz per tenant, audit
- Bottleneck identification; benchmarks; "what breaks at 10×"
- For platform/control-plane roles specifically
  → control vs data plane separation, static stability
  → blast radius: FD/AD/region, cells, canaries
  → consensus / leader election where a single writer is needed
  → operational readiness: dashboards, alarms, runbook, rollback

## 5. Team-aligned designs — highest ROI (do these fully)

1. **Distributed job scheduler**
   → Crux: exactly-once-ish execution with at-least-once delivery; leader per shard; lease + fencing
   → Anchor: SQS/Lambda + idempotency keys from JPMC pipeline
2. **Rate limiter** (recruiter-flagged)
   → Token bucket vs sliding window log/counter; distributed via Redis Lua; local + global tiers
   → Existing knowledge file — refresh
3. **Certificate management service** (the team)
   → API: create CA, issue cert, rotate, revoke, get bundle
   → Control plane: strong consistency, HSM-signed, audited; data plane: LB caches cert, survives CP outage
   → Hard parts: rotation overlap window, CRL freshness, root-key blast radius (two-tier)
4. **Distributed cache** (Redis-like)
   → Consistent hashing, replication, eviction, hot key, cache-aside vs write-through
5. **Control-plane work-request service**
   → Async API: 202 + work-request id; state machine; idempotent retries; per-tenant quotas; audit
   → Anchor: JPMC admin/preview/correct APIs
6. **URL shortener** (quick — it's reported ★★★ and easy)
