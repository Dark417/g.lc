#### 219. [Contains Duplicate II](https://leetcode.com/problems/contains-duplicate-ii/) [E]

Return whether there are two equal values whose indices differ by at most `k`.  
`array` `hash table` `sliding window`

##### Approach 1: Fixed-size window set

```python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        window = set()

        for i, n in enumerate(nums):
            if n in window:
                return True

            window.add(n)
            if i >= k:
                window.remove(nums[i - k])

        return False
# Time: O(n), Space: O(min(n, k))
```

##### Approach 2: Last seen index

```python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        last_seen = {}

        for i, n in enumerate(nums):
            if n in last_seen and i - last_seen[n] <= k:
                return True
            last_seen[n] = i

        return False
# Time: O(n), Space: O(n)
```

#### 643. [Maximum Average Subarray I](https://leetcode.com/problems/maximum-average-subarray-i/) [E]

Return the maximum average value over every contiguous subarray of length `k`.  
`array` `sliding window`

##### Approach 1: Fixed-size running sum

```python
class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        window_sum = sum(nums[:k])
        best = window_sum

        for i in range(k, len(nums)):
            window_sum += nums[i] - nums[i - k]
            best = max(best, window_sum)

        return best / k
# Time: O(n), Space: O(1)
```

#### 1984. [Minimum Difference Between Highest and Lowest of K Scores](https://leetcode.com/problems/minimum-difference-between-highest-and-lowest-of-k-scores/) [E]

Return the minimum possible difference between the highest and lowest scores among any `k` selected students.  
`array` `sorting` `sliding window`

##### Approach 1: Sort and scan fixed-size groups

```python
class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        nums.sort()

        return min(nums[i + k - 1] - nums[i] for i in range(len(nums) - k + 1))
# Time: O(n log n), Space: O(1)
```
