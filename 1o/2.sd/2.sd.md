## Plain-language companions

- A companion named `{oldname}1.md` teaches the question that `{oldname}.md` compresses.
  - The source file stays the interview answer: dense, fast to revise, written in the vocabulary.
  - The companion quotes each source line, restates it in plain words, says what breaks without it, and works an example with real numbers.
  - Every section ends with a `Term | Plain meaning | Why it appears here` table, so no jargon is left undefined.
  - Naming and structure rule — [AGENTS.md](AGENTS.md#question-file-structure).
- Use the companion to learn the material and the source to revise it the night before.
- **Coverage.** A companion that is not yet complete carries a status banner naming the sections still to write.
  - A companion is never authoritative for a section it does not contain; read the source file for those.
  - `s1.01`–`s1.04` are complete and carry no banner.
