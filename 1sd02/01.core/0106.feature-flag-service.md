# Design a Feature Flag Service

Design a service that lets operators define targeting rules and lets applications evaluate flags with very low latency and controlled propagation.

## Scope decisions to make

- Server-side and SDK evaluation; defer experimentation analytics.
- Boolean and multivariate flags with tenant/environment boundaries.
- Operator control plane separated from the high-volume evaluation data plane.
- Decide fail-open/fail-closed behavior by flag class.

## Non-functionals to pin down

- Evaluation QPS and p99 overhead added to an application request.
- Configuration propagation SLA and stale-read tolerance.
- Availability, audit retention, tenant isolation, and rollback requirements.

## The estimation that decides something

Estimate evaluations per request and per-process flag-set size. This should decide whether evaluation is local in SDK memory or requires a network hop.

## Skeleton diagram

```text
Operator -> control API -> source of truth -> change stream
                                              |-> regional relay -> SDK cache -> local evaluation
                                              `-> audit/history
```

## The hard part

Make configuration changes fast, ordered, auditable, and safe without putting the control plane on the request path. Define versioning, bootstrap, reconnect, rollback, and stale SDK behavior.

## Tradeoffs to defend

- Local SDK evaluation versus centralized evaluation.
- Streaming propagation versus polling.
- Rule expressiveness versus deterministic, safe execution.
- Immediate global convergence versus availability during partition.

## Top failure mode

A bad or partially propagated rule causes inconsistent behavior across the fleet. Cover immutable versions, validation, staged rollout, kill switches, last-known-good state, and convergence signals.

## Pushback ladder

1. How does an SDK know it has a complete, ordered configuration?
2. A reconnect storm follows a regional outage. How is the control plane protected?
3. Security flags must fail closed and converge immediately. What changes?
