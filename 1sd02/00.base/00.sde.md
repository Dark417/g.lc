# 00.base — System Design Concept Index

This directory is the transferable concept layer. Learn it in interview order, then apply it to questions in [`../1index.md`](../1index.md). Product-specific answer packets belong in `1AX/` or a domain folder, not here.

## Learning contract

For every concept, be able to explain:

1. the problem and mechanism;
2. owned state, keys, and lifecycle;
3. the property it creates and the condition that defeats it;
4. the decision variable, rejected alternative, and flip condition;
5. the primary failure mode, signal, degraded behavior, and recovery;
6. one L4 application and one legitimate L5 extension.

Use [`../build.md`](../build.md) as the content quality gate and [`../0flow.md`](../0flow.md) to place the concept in a 45-minute answer.

## Study passes

- **Pass 1 — Structure:** Steps 1–5 quickly; produce one cold-open per day.
- **Pass 2 — Mechanisms:** Steps 6–10; pair each topic with one core question.
- **Pass 3 — Production:** Steps 11–14; add failure tables and premise-reversal drills.
- **Pass 4 — Defense:** explain the weakest concept in 90 seconds, then answer mechanism, scale/failure, and flip-condition pushbacks.

Do not mark a concept “learned” because its document was read. Mark it learned when it survives an unseen application and one premise reversal.
